## Что внутри

- **2681 HTML-страница** и **1508 ноутбуков** из официального комплекта.
- Переведены руководства, описания функций, параметры и пояснения к примерам.
- Код, формулы, имена API и ссылки сохранены. Русские пояснения к английским комментариям и подписям рисунков расположены рядом.
- Поиск понимает русский язык и работает при локальном открытии файлов.

Перевод подготовлен с помощью машинного черновика и последующей редакторской проверки с сопоставлением оригиналу. Проверены все **34 321 уникальный фрагмент**: **31 108 текстовых** и **3213 формальных элементов** — имён API, типов, путей и служебных подписей. Выявленные неточности оригинала объяснены отдельными примечаниями переводчика.

Это **неофициальный перевод**, не связанный с командой NumPy. Оригинал: [numpy.org/doc/2.5](https://numpy.org/doc/2.5/).

## Читать без интернета

Скачайте репозиторий через **Code → Download ZIP**, распакуйте и откройте `index.html` в браузере. Устанавливать Python, NumPy или модель перевода для чтения не нужно.

Для интерактивных примеров JupyterLite может понадобиться интернет. При локальном запуске откройте терминал в папке документации и выполните:

```bash
python -m http.server 8000 --bind 127.0.0.1
```

Затем откройте <http://127.0.0.1:8000/>.
