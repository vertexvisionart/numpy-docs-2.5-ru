GitHub Codespaces#

GitHub Codespaces — сервис облачных сред разработки: вам не нужно устанавливать что-либо на локальный компьютер или заниматься настройкой.

Что такое codespace?#

Пространство codespace — это экземпляр Codespaces, то есть облачная среда разработки. Каждое такое пространство работает на виртуальной машине GitHub. Тип машины можно выбрать в зависимости от необходимых ресурсов. Доступны разные конфигурации, начиная с двухъядерного процессора, 4 ГБ оперативной памяти и 32 ГБ дискового пространства. Подключиться к codespace можно из браузера, Visual Studio Code, приложения JetBrains Gateway или через GitHub CLI.

Создание форка репозитория NumPy#

Участнику, желающему работать над кодом NumPy, лучше сначала создать форк репозитория.

  1. Откройте репозиторий NumPy на GitHub и создайте свой форк.

  2. Откройте свой форк. Его URL будет похож на inessapawson/numpy, но вместо inessapawson в нём будет ваше имя пользователя GitHub.

Запуск GitHub Codespaces #

Можно создать Codespace зелёной кнопкой «<> Code» на главной странице репозитория, выбрав вкладку Codespaces, либо открыть по этой ссылке.

Краткий обзор рабочей среды#

Разрабатывать код в среде Codespaces можно с помощью инструмента на ваш выбор:

  • командная оболочка через соединение SSH, инициированное с помощью GitHub CLI._

  • одна из IDE JetBrains через JetBrains Gateway._

  • настольное приложение Visual Studio Code._

  • браузерная версия Visual Studio Code._

В этом кратком руководстве редактором служит настольное приложение VSCode. Если вы им ещё не пользовались, ознакомьтесь с разделом начала работы в документации VSCode.

FAQ и устранение неполадок #

Как долго codespace остаётся активным, если им не пользоваться? Если оставить codespace работающим без взаимодействия или выйти, не остановив его явно, по умолчанию он остановится после 30 минут бездействия. Для новых создаваемых codespace этот период ожидания можно настроить.

Можно ли вернуться в ранее созданную среду Codespaces? Жизненный цикл среды начинается при её создании и заканчивается при удалении. Можно отключаться от активной среды и подключаться снова, не влияя на запущенные процессы. Среду также можно останавливать и перезапускать без потери изменений в проекте.
