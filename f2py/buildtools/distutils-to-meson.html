1 Миграция в meson #

Согласно графику, изложенному в документе «Статус numpy.distutils и рекомендации по миграции», distutils удалён. На этой странице собраны типичные рабочие процессы.

Примечание

Этот документ постоянно развивается; мы приветствуем pull request!

1.1 Базовый уровень#

Начнём со слегка осовремененного варианта классического генератора последовательности Фибоначчи.

! fib.f90
subroutine fib(a, n)
  use iso_c_binding
   integer(c_int), intent(in) :: n
   integer(c_int), intent(out) :: a(n)
   do i = 1, n
      if (i .eq. 1) then
         a(i) = 0.0d0
      elseif (i .eq. 2) then
         a(i) = 1.0d0
      else
         a(i) = a(i - 1) + a(i - 2)
      end if
   end do
end
Комментарии к примеру на русском
  • fib.f90

Это не принесет никаких наград, но может стать хорошей отправной точкой.

1.2 Параметры компиляции#

1.2.1 Базовое использование #

python -m numpy.f2py -c fib.f90 -m fib

1.2.2 Укажите бэкенд#

python -m numpy.f2py -c fib.f90 -m fib

Это единственный вариант. Ранее существовал бэкенд distutils, но его удалили в NumPy 2.5.0.

1.2.3 Передайте имя компилятора#

FC=gfortran python -m numpy.f2py -c fib.f90 -m fib

Можно также использовать файлы native.

Аналогично в обоих случаях через CC можно выбрать компилятор C. Поскольку переменные среды во многом общие для обоих подходов, ниже приведён небольшой пример.

Примечание

В Windows эти способы могут быть ненадёжны, поэтому лучше использовать файлы native либо непосредственную 1.3 Настройку сборки.

1.2.4 Зависимости #

python -m numpy.f2py -c fib.f90 -m fib --dep lapack

Это соответствует dependency("lapack") и подходит для широкого круга зависимостей. Можно дополнительно настроить поиск зависимостей через CMake или другие системы.

1.2.5 Библиотеки #

meson поддерживает компоновку с библиотеками.

python -m numpy.f2py -c fib.f90 -m fib -lmylib -L/path/to/mylib

1.3 Настройка сборки #

python -m numpy.f2py -c fib.f90 -m fib --build-dir blah

Полученную сборку можно настроить, следуя практическому руководству Meson по сборке. Более того, полученный набор файлов можно непосредственно сохранить в репозитории и использовать как подпроект Meson в другом проекте.
