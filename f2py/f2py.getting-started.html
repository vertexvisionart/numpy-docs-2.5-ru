Три способа создания обёрток: начало работы#

Создание обёрток для функций Fortran или C с помощью F2PY для вызова из Python состоит из следующих этапов:

  • Создание так называемого файла сигнатур, содержащего описания обёрток функций Fortran или C, также называемые сигнатурами функций. Для подпрограмм Fortran F2PY может создать начальный файл сигнатур, просканировав исходный код и собрав всю информацию, необходимую для создания функций-обёрток.

    • При необходимости файлы сигнатур, созданные F2PY, можно отредактировать для оптимизации функций-обёрток, сделав их «умнее» и естественнее для Python.

  • F2PY читает файл сигнатур и создаёт модуль Python C/API со связями между Fortran, C и Python.

  • F2PY компилирует все исходные файлы и создаёт модуль расширения с обёртками.

    • Для сборки модулей расширения F2PY использует meson. О других системах сборки см. F2PY и системы сборки.

Примечание

  • В зависимости от ОС заголовки разработки Python с файлом Python.h может потребоваться установить отдельно. В дистрибутивах Linux на основе Debian пакет обычно называется python3-dev, на основе Fedora — python3-devel. В macOS ситуация зависит от способа установки Python. В Windows заголовки обычно уже установлены; см. F2PY и Windows.

Примечание

F2PY поддерживает все операционные системы, на которых тестируется SciPy, поэтому раздел системных зависимостей SciPy — полезный справочный материал.

В зависимости от ситуации эти действия могут выполняться одной составной командой или поэтапно; в этом случае некоторые шаги можно пропустить или объединить с другими.

Ниже описаны три типичных подхода к использованию F2PY с Fortran 77. Они представлены в порядке возрастания трудозатрат и подходят для разных уровней доступа к коду Fortran в зависимости от возможности свободно его изменять.

Для иллюстрации используется следующий пример кода Fortran 77. Сохраните его в файле fib1.f:

C FILE: FIB1.F
      SUBROUTINE FIB(A,N)
C
C     CALCULATE FIRST N FIBONACCI NUMBERS
C
      INTEGER N
      REAL*8 A(N)
      DO I=1,N
         IF (I.EQ.1) THEN
            A(I) = 0.0D0
         ELSEIF (I.EQ.2) THEN
            A(I) = 1.0D0
         ELSE 
            A(I) = A(I-1) + A(I-2)
         ENDIF
      ENDDO
      END
C END FILE FIB1.F

Примечание

F2PY разбирает сигнатуры Fortran/C и создаёт функции-обёртки для Python. Однако это не компилятор: он не проверяет исходный код на дополнительные ошибки и не реализует языковые стандарты полностью. Некоторые ошибки могут остаться незамеченными или вызвать только предупреждение; пользователь должен проверить их самостоятельно.

Быстрый путь #

Самый быстрый способ обернуть подпрограмму FIB на Фортране для использования в Python — запустить

python -m numpy.f2py -c fib1.f -m fib1

или, альтернативно, если доступен инструмент командной строки f2py,

f2py -c fib1.f -m fib1

Примечание

Поскольку команда f2py может быть доступна не во всех системах, особенно в Windows, в этом руководстве мы будем использовать команду python -m numpy.f2py.

Эта команда компилирует файл fib1.f и создаёт для него обёртку (-c), формируя в текущем каталоге модуль расширения fib1.so (-m). Список параметров командной строки можно посмотреть, выполнив python -m numpy.f2py. Теперь подпрограмма Fortran FIB доступна в Python через fib1.fib:

>>> import numpy as np
>>> import fib1
>>> print(fib1.fib.__doc__)
fib(a,[n])

Wrapper for ``fib``.

Parameters
----------
a : input rank-1 array('d') with bounds (n)

Other parameters
----------------
n : input int, optional
    Default: len(a)

>>> a = np.zeros(8, 'd')
>>> fib1.fib(a)
>>> print(a)
[  0.   1.   1.   2.   3.   5.   8.  13.]

Примечание

  • F2PY определил, что второй аргумент n задаёт размер первого аргумента-массива a. Поскольку по умолчанию все аргументы используются только для ввода, F2PY считает n необязательным со значением по умолчанию len(a).

  • Можно использовать разные значения для необязательного n:

    >>> a1 = np.zeros(8, 'd')
>>> fib1.fib(a1, 6)
>>> print(a1)
[ 0.  1.  1.  2.  3.  5.  0.  0.]

    но если оно несовместимо с входным массивом a, возникает исключение:

    >>> fib1.fib(a, 10)
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
fib.error: (len(a)>=n) failed for 1st keyword n: fib:n=10
>>>

    F2PY реализует основные проверки совместимости между соответствующими аргументами, чтобы избежать неожиданных сбоев.

  • Если в качестве входного аргумента передан массив NumPy в порядке Fortran, непрерывно расположенный в памяти, и его dtype соответствует ожидаемому типу Fortran, указатель C на данные передаётся в Fortran напрямую.

    Иначе F2PY создаёт непрерывно расположенную в памяти копию входного массива с нужным dtype и передаёт указатель C на неё в подпрограмму Fortran. Поэтому изменения копии не затрагивают исходный аргумент, как показано ниже:

    >>> a = np.ones(8, 'i')
>>> fib1.fib(a)
>>> print(a)
[1 1 1 1 1 1 1 1]

    Это неожиданно, поскольку Fortran обычно передаёт аргументы по ссылке. То, что пример выше работал с dtype=float, считается случайностью.

    F2PY предоставляет атрибут intent(inplace), гарантирующий копирование изменений обратно во входной аргумент. Например, при указании директивы intent(inplace) a (подробнее см. раздел Атрибуты) приведённый выше пример примет вид:

    >>> a = np.ones(8, 'i')
>>> fib1.fib(a)
>>> print(a)
[  0.   1.   1.   2.   3.   5.   8.  13.]

    Однако рекомендуемый способ передать в Python изменения, сделанные подпрограммой Fortran, — использовать атрибут intent(out). Этот подход эффективнее и даёт более ясный интерфейс.

  • Использование fib1.fib в Python похоже на FIB в Fortran. Однако выходные аргументы, изменяемые на месте, в Python считаются плохим стилем: нет встроенных механизмов защиты от неверных типов аргументов. В Fortran или C несоответствия обнаруживает компилятор, а в Python типы нужно проверять во время выполнения. Поэтому выходные аргументы, изменяемые на месте, могут приводить к трудноуловимым ошибкам; вдобавок необходимые проверки типов снижают читаемость кода.

Хотя рассмотренный подход к созданию обёрток подпрограмм Fortran для Python прост, у него есть несколько недостатков (см. замечания выше). Они связаны с тем, что F2PY не может определить истинное назначение аргументов: входные и выходные аргументы не всегда можно однозначно различить. Поэтому по умолчанию F2PY считает все аргументы входными.

Неоднозначность можно устранить способами, описанными ниже: достаточно «объяснить» F2PY действительное назначение аргументов функций. Тогда F2PY сможет создавать более явные и удобные обёртки функций Fortran, при использовании которых легче избежать ошибок.

Умный способ #

Чтобы точнее управлять тем, как F2PY создаёт интерфейс к нашему коду на Fortran, можно выполнять этапы создания обёртки по отдельности.

  • Сначала создадим файл сигнатур из fib1.f следующей командой:

    python -m numpy.f2py fib1.f -m fib2 -h fib1.pyf

    Файл сигнатур сохраняется в fib1.pyf (см. флаг -h); его содержимое приведено ниже.

    !    -*- f90 -*-
python module fib2 ! in 
    interface  ! in :fib2
        subroutine fib(a,n) ! in :fib2:fib1.f
            real*8 dimension(n) :: a
            integer optional,check(len(a)>=n),depend(a) :: n=len(a)
        end subroutine fib
    end interface 
end python module fib2

  • Далее укажем F2PY, что n — входной аргумент (атрибутом intent(in)), а результат, то есть содержимое a после вызова функции Fortran FIB, нужно вернуть в Python (атрибутом intent(out)). Кроме того, массив a должен создаваться динамически, а его размер определяется входным аргументом n; эта зависимость указывается атрибутом depend(n).

    Содержимое модифицированной версии fib1.pyf (сохраняется как fib2.pyf) выглядит следующим образом:

    !    -*- f90 -*-
python module fib2 
    interface
        subroutine fib(a,n)
            real*8 dimension(n),intent(out),depend(n) :: a
            integer intent(in) :: n
        end subroutine fib
    end interface 
end python module fib2

  • Наконец, мы создаем модуль расширения, выполняя:

    python -m numpy.f2py -c fib2.pyf fib1.f

В Python:

>>> import fib2
>>> print(fib2.fib.__doc__)
a = fib(n)

Wrapper for ``fib``.

Parameters
----------
n : input int

Returns
-------
a : rank-1 array('d') with bounds (n)

>>> print(fib2.fib(8))
[  0.   1.   1.   2.   3.   5.   8.  13.]

Примечание

  • Сигнатура fib2.fib теперь лучше соответствует назначению подпрограммы Fortran FIB: по заданному числу n функция fib2.fib возвращает первые n чисел Фибоначчи в виде массива NumPy. Новая сигнатура Python fib2.fib также исключает неожиданное поведение fib1.fib.

  • Обратите внимание, что по умолчанию использование одного intent(out) также подразумевает intent(hide). Аргументы, которые имеют указанный атрибут intent(hide), не будут перечислены в списке аргументов функции обертки.

Подробнее см. «Файл сигнатур».

Умный и быстрый способ #

Описанный выше «умный способ» создания обёрток Fortran подходит, например, для стороннего кода Fortran, исходники которого нежелательно или невозможно менять.

Если допустимо редактировать код Fortran, в большинстве случаев можно обойтись без промежуточного файла сигнатур. Атрибуты F2PY можно вставлять прямо в исходный код Fortran с помощью директив F2PY. Это специальные строки комментариев, начинающиеся, например, с Cf2py или !f2py, которые компиляторы Fortran игнорируют, а F2PY интерпретирует как обычные строки.

Рассмотрим модифицированную версию предыдущего кода на Фортране с директивами F2PY, сохраненную как fib3.f:

C FILE: FIB3.F
      SUBROUTINE FIB(A,N)
C
C     CALCULATE FIRST N FIBONACCI NUMBERS
C
      INTEGER N
      REAL*8 A(N)
Cf2py intent(in) n
Cf2py intent(out) a
Cf2py depend(n) a
      DO I=1,N
         IF (I.EQ.1) THEN
            A(I) = 0.0D0
         ELSEIF (I.EQ.2) THEN
            A(I) = 1.0D0
         ELSE 
            A(I) = A(I-1) + A(I-2)
         ENDIF
      ENDDO
      END
C END FILE FIB3.F

Сборку модуля расширения теперь можно выполнить одной командой:

python -m numpy.f2py -c -m fib3 fib3.f

Обратите внимание: полученная обёртка для FIB столь же «умна» (не допускает неоднозначности), как и в предыдущем случае:

>>> import fib3
>>> print(fib3.fib.__doc__)
a = fib(n)

Wrapper for ``fib``.

Parameters
----------
n : input int

Returns
-------
a : rank-1 array('d') with bounds (n)

>>> print(fib3.fib(8))
[  0.   1.   1.   2.   3.   5.   8.  13.]
