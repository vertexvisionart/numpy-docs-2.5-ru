Использование привязок F2PY в Python#

На этой странице приведены полное описание и несколько типичных примеров использования F2PY с Python и различными типами аргументов. Дополнительные примеры и варианты применения см. в разделе Примеры F2PY.

Объекты типа Fortran #

Все обёртки процедур Fortran/C, общих блоков и данных модулей Fortran 90, созданные F2PY, доступны в Python как объекты типа fortran. Обёртки процедур — вызываемые объекты типа fortran, а обёртки данных Fortran имеют атрибуты, ссылающиеся на объекты данных.

Все объекты типа fortran имеют атрибут _cpointer, который содержит PyCapsule, относящийся к указателю C соответствующей функции Fortran/C или переменной на уровне C. Такие объекты PyCapsule могут использоваться в качестве аргументов обратного вызова для функций, генерируемых F2PY, чтобы обойти уровень Python C/API для вызова функций Python из Fortran или C. Это может быть полезно, когда вычислительные аспекты таких функций реализованы в C или Fortran и обернуты F2PY (или любым другим инструментом, способным обеспечить PyCapsule, содержащий функцию).

Рассмотрим файл Fortran 77 `ftype.f:

C FILE: FTYPE.F
      SUBROUTINE FOO(N)
      INTEGER N
Cf2py integer optional,intent(in) :: n = 13
      REAL A,X
      COMMON /DATA/ A,X(3)
C     PRINT*, "IN FOO: N=",N," A=",A," X=[",X(1),X(2),X(3),"]"
      END
C END OF FTYPE.F

  • Оператор PRINT выводит значения N, A и первых трёх элементов X внутри FOO.
  • КОНЕЦ ФАЙЛА FTYPE.F

и обёртка, собранная командой f2py -c ftype.f -m ftype.

В Python можно посмотреть типы foo и data и способы доступа к отдельным объектам кода Fortran, для которого создана обёртка.

Скалярные аргументы#

Скалярным аргументом функции-обёртки F2PY может быть обычный скаляр Python — целое, вещественное или комплексное число — либо произвольная последовательность скаляров: список, кортеж, массив или строка. Во втором случае процедуре Fortran передаётся первый элемент последовательности как скалярный аргумент.

Примечание

  • Если при необходимом приведении типа возможна потеря информации из-за сужения, например при преобразовании float в целый тип или комплексного типа во float, F2PY не возбуждает исключение.

    • При приведении комплексного типа к вещественному используется только действительная часть комплексного числа.

  • Скалярные аргументы intent(inout) считаются объектами массивов, чтобы изменения на месте вступали в силу. Рекомендуется использовать массивы подходящего типа, хотя другие типы тоже работают. Подробнее об атрибуте intent.

Рассмотрим следующий код Fortran 77:

C FILE: SCALAR.F
      SUBROUTINE FOO(A,B)
      REAL*8 A, B
Cf2py intent(in) a
Cf2py intent(inout) b
      PRINT*, "    A=",A," B=",B
      PRINT*, "INCREMENT A AND B"
      A = A + 1D0
      B = B + 1D0
      PRINT*, "NEW A=",A," B=",B
      END
C END OF FILE SCALAR.F

и создайте обёртку командой f2py -c -m scalar scalar.f.

Строковые аргументы#

Созданные F2PY функции-обёртки принимают почти любой объект Python как строковый аргумент: к нестроковым объектам применяется str. Исключение — массивы NumPy: при передаче как строкового аргумента их код типа должен быть 'S1' или 'b' (соответственно устаревшие коды 'c' или '1'). Подробнее об этих кодах см. в разделе Скаляры.

Строка, передаваемая строковым аргументом функции-обёртке F2PY, может иметь произвольную длину. Если она длиннее ожидаемого, она обрезается без предупреждения. Если короче, выделяется дополнительная память и заполняется \0.

Поскольку строки Python неизменяемы, аргумент intent(inout) ожидает строку в виде массива, чтобы изменения на месте сохранялись.

Рассмотрим следующий код Fortran 77:

C FILE: STRING.F
      SUBROUTINE FOO(A,B,C,D)
      CHARACTER*5 A, B
      CHARACTER*(*) C,D
Cf2py intent(in) a,c
Cf2py intent(inout) b,d
      PRINT*, "A=",A
      PRINT*, "B=",B
      PRINT*, "C=",C
      PRINT*, "D=",D
      PRINT*, "CHANGE A,B,C,D"
      A(1:1) = 'A'
      B(1:1) = 'B'
      C(1:1) = 'C'
      D(1:1) = 'D'
      PRINT*, "A=",A
      PRINT*, "B=",B
      PRINT*, "C=",C
      PRINT*, "D=",D
      END
C END OF FILE STRING.F

Аргументы-массивы#

Как правило, функции-обёртки, сгенерированные F2PY, принимают в качестве аргументов-массивов произвольные последовательности, преобразуемые в массивы NumPy. Есть два важных исключения:

  • Массивы-аргументы с intent(inout) должны быть непрерывно расположены в памяти и иметь совместимый dtype, иначе возникает исключение.

  • Аргументы-массивы с intent(inplace) должны быть массивами. Если их порядок или размер несовместимы с требуемыми, передаётся преобразованная копия, которая при выходе копируется обратно в исходный массив. Подробнее см. описание intent(inplace) в разделе атрибутов.

Обычно массив NumPy передаётся непосредственно оборачиваемой функции Fortran/C, если он непрерывно расположен в памяти в нужном порядке и имеет подходящий тип. Иначе создаётся поэлементная копия с нужными расположением и типом, которая передаётся как аргумент-массив.

Обычно не нужно беспокоиться о расположении массивов в памяти и о том, какой порядок ожидают функции C или Fortran, для которых созданы обёртки. F2PY автоматически передаёт аргументы в нужном порядке хранения и создаёт копии только при крайней необходимости. Однако при очень больших многомерных входных массивах, по размеру близких к объёму физической памяти компьютера, важно заранее обеспечить подходящее непрерывное расположение и нужный тип аргументов.

Чтобы перед передачей в процедуры Fortran преобразовать входные массивы к порядку хранения по столбцам, используйте функцию numpy.asfortranarray.

Рассмотрим следующий код Fortran 77:

C FILE: ARRAY.F
      SUBROUTINE FOO(A,N,M)
C
C     INCREMENT THE FIRST ROW AND DECREMENT THE FIRST COLUMN OF A
C
      INTEGER N,M,I,J
      REAL*8 A(N,M)
Cf2py intent(in,out,copy) a
Cf2py integer intent(hide),depend(a) :: n=shape(a,0), m=shape(a,1)
      DO J=1,M
         A(1,J) = A(1,J) + 1D0
      ENDDO
      DO I=1,N
         A(I,1) = A(I,1) - 1D0
      ENDDO
      END
C END OF FILE ARRAY.F

Аргументы обратного вызова #

F2PY поддерживает вызов функций Python из кодов Fortran или C.

Рассмотрим следующий код Fortran 77:

C FILE: CALLBACK.F
      SUBROUTINE FOO(FUN,R)
      EXTERNAL FUN
      INTEGER I
      REAL*8 R, FUN
Cf2py intent(out) r
      R = 0D0
      DO I=-5,5
         R = R + FUN(I)
      ENDDO
      END
C END OF FILE CALLBACK.F
Комментарии к примеру на русском
  • ФАЙЛ: CALLBACK.F
  • КОНЕЦ ФАЙЛА CALLBACK.F

и создайте обёртку командой f2py -c -m callback callback.f.

В Python:

>>> import callback
>>> print(callback.foo.__doc__)
r = foo(fun,[fun_extra_args])

Wrapper for ``foo``.

Parameters
----------
fun : call-back function

Other Parameters
----------------
fun_extra_args : input tuple, optional
    Default: ()

Returns
-------

Notes
-----
Call-back functions::

  def fun(i): return r
  Required arguments:
    i : input int
  Return objects:

>>> def f(i): return i*i
...

>>> print(callback.foo(lambda i:1))

В приведённом выше примере F2PY удалось правильно определить сигнатуру функции обратного вызова. Однако иногда F2PY не может установить нужную сигнатуру; в таких случаях её необходимо явно задать в файле сигнатур.

Для этого файлы сигнатур могут содержать специальные модули (с подстрокой __user__ в имени), определяющие сигнатуры функций обратного вызова. Аргументы обратного вызова в сигнатурах подпрограмм имеют атрибут external (см. также intent(callback) в разделе атрибуты). Для связи аргумента обратного вызова с его сигнатурой в блоке модуля __user__ можно использовать оператор use, как показано ниже. На одну сигнатуру аргумента обратного вызова можно ссылаться из разных сигнатур подпрограмм.

Используем тот же код Fortran 77, что и в предыдущем примере, но предположим, что F2PY неверно определил сигнатуры аргументов функций обратного вызова. Сначала создадим исходный файл сигнатур callback2.pyf с помощью F2PY:

f2py -m callback2 -h callback2.pyf callback.f

Затем измените его следующим образом

!    -*- f90 -*-
python module __user__routines 
    interface
        function fun(i) result (r)
            integer :: i
            real*8 :: r
        end function fun
    end interface
end python module __user__routines

python module callback2
    interface
        subroutine foo(f,r)
            use __user__routines, f=>fun
            external f
            real*8 intent(out) :: r
        end subroutine foo
    end interface 
end python module callback2

Наконец, мы создаем модуль расширения с использованием f2py -c callback2.pyf callback.f.

Пример сеанса Python для этого фрагмента совпадёт с предыдущим примером, отличаться будут лишь имена аргументов.

Иногда пакет Fortran может потребовать, чтобы пользователи предоставили процедуры, которые будет использовать пакет. F2PY может создать интерфейс для таких процедур, чтобы функции Python могли быть вызваны из Fortran.

Рассмотрим следующую подпрограмму Fortran 77, принимающую массив и применяющую функцию func к его элементам.

      subroutine calculate(x,n)
cf2py intent(callback) func
      external func
c     The following lines define the signature of func for F2PY:
cf2py real*8 y
cf2py y = func(y)
c
cf2py intent(in,out,copy) x
      integer n,i
      real*8 x(n), func
      do i=1,n
         x(i) = func(x(i))
      end do
      end
Комментарии к примеру на русском
  • Следующие строки задают сигнатуру func для F2PY:

Код Fortran предполагает, что функция func определена извне. Чтобы использовать функцию Python в качестве func, нужно задать атрибут intent(callback) перед оператором external.

Наконец, соберите модуль расширения командой f2py -c -m foo calculate.f

В Python:

>>> import foo
>>> foo.calculate(range(5), lambda x: x*x)
array([  0.,   1.,   4.,   9.,  16.])
>>> import math
>>> foo.calculate(range(5), math.exp)
array([  1.        ,   2.71828183,   7.3890561,  20.08553692,  54.59815003])

Функция передаётся как аргумент при вызове подпрограммы Fortran из Python, хотя её нет в списке аргументов подпрограммы Fortran. Ключевое слово external относится к функции C, созданной f2py, а не к самой функции Python. По сути, функция Python передаётся функции C.

Функцию обратного вызова также можно явно задать в модуле. Тогда передавать её аргументом функции Fortran не требуется. Это может быть удобно, если функция Fortran, вызывающая функцию обратного вызова Python, сама вызывается другой функцией Fortran.

Рассмотрим следующую подпрограмму Fortran 77:

      subroutine f1()
         print *, "in f1, calling f2 twice.."
         call f2()
         call f2()
         return
      end
      
      subroutine f2()
cf2py    intent(callback, hide) fpy
         external fpy
         print *, "in f2, calling f2py.."
         call fpy()
         return
      end

и создайте обёртку командой f2py -c -m pfromf extcallback.f.

Примечание

Если поведение кода Fortran изменено через callstatement или другие директивы, функцию Python с обёрткой нужно вызывать как функцию обратного вызова; иначе будет использована только исходная подпрограмма Fortran. Подробнее см. numpy/numpy#26681.

Разрешение аргументов для функций обратного вызова #

Интерфейсы, сгенерированные F2PY, очень гибки в отношении аргументов обратного вызова. Для каждого аргумента обратного вызова F2PY вводит дополнительный необязательный аргумент <name>_extra_args. Этот аргумент можно использовать для передачи дополнительных аргументов пользовательским функциям обратного вызова.

Если функция обертки, генерируемая F2PY, ожидает следующего аргумента обратного вызова:

def fun(a_1,...,a_n):
   ...
   return x_1,...,x_k

но следующая функция Python

def gun(b_1,...,b_m):
   ...
   return y_1,...,y_l

предоставляется пользователем, а также

fun_extra_args = (e_1,...,e_p)

используется, то применяются следующие правила, когда функция Fortran или C оценивает аргумент обратного вызова gun:

  • Если p == 0, вызывается gun(a_1, ..., a_q), где q = min(m, n).

  • Если n + p <= m, вызывается gun(a_1, ..., a_n, e_1, ..., e_p).

  • Если p <= m < n + p, вызывается gun(a_1, ..., a_q, e_1, ..., e_p), где q=m-p.

  • Если p > m, вызывается gun(e_1, ..., e_m).

  • Если n + p меньше, чем количество требуемых аргументов для gun, то возникает исключение.

Если функция gun может возвращать любое количество объектов в виде кортежа; то применяются следующие правила:

  • Если k < l, значения y_{k + 1}, ..., y_l игнорируются.

  • Если k > l , то устанавливаются только x_1, ..., x_l.

Общие блоки (COMMON)#

F2PY создаёт обёртки для блоков common, определённых в блоке сигнатуры подпрограммы. Общие блоки видны всему коду Fortran, скомпонованному с текущим модулем расширения, но не другим модулям расширения: это ограничение связано со способом импорта разделяемых библиотек в Python. В Python обёртки F2PY для блоков common представляют собой объекты типа fortran с динамическими атрибутами, соответствующими элементам данных общих блоков. Обращение к атрибутам возвращает массивы NumPy, напрямую связанные с этими элементами данных; многомерные массивы непрерывно расположены в памяти в порядке Fortran. Данные можно изменять прямым присваиванием или изменением соответствующих массивов на месте.

Рассмотрим следующий код Fortran 77:

C FILE: COMMON.F
      SUBROUTINE FOO
      INTEGER I,X
      REAL A
      COMMON /DATA/ I,X(4),A(2,3)
      PRINT*, "I=",I
      PRINT*, "X=[",X,"]"
      PRINT*, "A=["
      PRINT*, "[",A(1,1),",",A(1,2),",",A(1,3),"]"
      PRINT*, "[",A(2,1),",",A(2,2),",",A(2,3),"]"
      PRINT*, "]"
      END
C END OF COMMON.F
Комментарии к примеру на русском
  • ФАЙЛ: COMMON.F
  • КОНЕЦ ФАЙЛА COMMON.F

и создайте обёртку командой f2py -c -m common common.f.

В Python:

>>> print(common.data.__doc__)

 [   1.00000000     ,   2.00000000     ,   3.00000000     ]

 ]
>>> common.data.a[1] = 45

Данные модулей Fortran 90#

Интерфейс F2PY к данным модулей Fortran 90 похож на интерфейс к блокам COMMON Fortran 77.

Рассмотрим следующий код Fortran 90:

module mod
  integer i
  integer :: x(4)
  real, dimension(2,3) :: a
  real, allocatable, dimension(:,:) :: b 
contains
  subroutine foo
    integer k
    print*, "i=",i
    print*, "x=[",x,"]"
    print*, "a=["
    print*, "[",a(1,1),",",a(1,2),",",a(1,3),"]"
    print*, "[",a(2,1),",",a(2,2),",",a(2,3),"]"
    print*, "]"
    print*, "Setting a(1,2)=a(1,2)+3"
    a(1,2) = a(1,2)+3
  end subroutine foo
end module mod

Массивы с динамически выделяемой памятью (allocatable)#

F2PY предоставляет базовую поддержку массивов с динамически выделяемой памятью (allocatable) в модулях Fortran 90.

Рассмотрим следующий код Fortran 90:

module mod
  real, allocatable, dimension(:,:) :: b 
contains
  subroutine foo
    integer k
    if (allocated(b)) then
       print*, "b=["
       do k = 1,size(b,1)
          print*, b(k,1:size(b,2))
       enddo
       print*, "]"
    else
       print*, "b is not allocated"
    endif
  end subroutine foo
end module mod

и создайте обёртку командой f2py -c -m allocarr allocarr.f90.

В Python:

>>> import allocarr
>>> print(allocarr.mod.__doc__)
b : 'f'-array(-1,-1), not allocated
foo()

Wrapper for ``foo``.



>>> allocarr.mod.foo()  
 b is not allocated
>>> allocarr.mod.b = [[1, 2, 3], [4, 5, 6]]             # allocate/initialize b
>>> allocarr.mod.foo()
 b=[
   1.000000       2.000000       3.000000    
   4.000000       5.000000       6.000000    
 ]
>>> allocarr.mod.b                                      # b is Fortran-contiguous
array([[ 1.,  2.,  3.],
       [ 4.,  5.,  6.]], dtype=float32)
>>> allocarr.mod.b.flags.f_contiguous
True
>>> allocarr.mod.b = [[1, 2, 3], [4, 5, 6], [7, 8, 9]]  # reallocate/initialize b
>>> allocarr.mod.foo()
 b=[
   1.000000       2.000000       3.000000    
   4.000000       5.000000       6.000000    
   7.000000       8.000000       9.000000    
 ]
>>> allocarr.mod.b = None                               # deallocate array
>>> allocarr.mod.foo()
 b is not allocated
