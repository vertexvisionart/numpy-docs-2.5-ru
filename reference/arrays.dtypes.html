Объекты типа данных (dtype) #

Объект типа данных (экземпляр класса numpy.dtype) описывает, как интерпретировать байты блока памяти фиксированного размера, соответствующего одному элементу массива. Он определяет следующие характеристики данных:

  1. Тип данных (целое число, float, объект Python и т.д.)

  2. Размер данных (сколько байтов занимает, например, целое число)

  3. Порядок байтов данных: little-endian, от младшего байта к старшему, или big-endian, от старшего байта к младшему

  4. Если тип данных — структурированный тип, то есть совокупность других типов данных (например, элемент массива из целого числа и числа с плавающей запятой),

    1. какие имена имеют «поля» структуры, по которым к ним можно обращаться,

    2. каков тип данных каждого поля, и

    3. какую часть блока памяти занимает каждое поле.

  5. Если тип данных является подмассивом, то какова его форма и тип данных?

В NumPy есть несколько встроенных скалярных типов для целых чисел, чисел с плавающей точкой различной точности и т. д.. Элемент, извлечённый из массива, например индексированием, будет объектом Python, чей скалярный тип соответствует типу данных массива.

Обратите внимание, что скалярные типы не являются объектами dtype, хотя они могут использоваться вместо одного, когда требуется спецификация типа данных в NumPy.

Структурированный тип данных создаётся из полей, каждое из которых имеет собственный тип данных. У каждого поля есть имя, по которому к нему можно обратиться. Размер родительского типа должен быть достаточным для размещения всех полей. Родительский тип почти всегда основан на void, который допускает произвольный размер элемента. Поля структурированного типа также могут содержать вложенные структурированные типы и подмассивы.

Наконец, тип данных может описывать элементы, которые сами по себе являются массивами элементов другого типа данных. Однако эти подмассивы должны иметь фиксированный размер.

Если массив создается с использованием типа данных, описывающего подмассив, размеры подмассива добавляются к форме массива при создании массива. Подмассивы в поле структурированного типа ведут себя иначе, см. Доступ к полю .

Подмассивы всегда непрерывно расположены в памяти в порядке C.

Пример

Простой тип данных, содержащий 32-битное целое число с порядком байтов big-endian. Подробнее о создании см. в разделе Задание и создание типов данных.

>>> import numpy as np

>>> dt = np.dtype('>i4')
>>> dt.byteorder
'>'
>>> dt.itemsize
4
>>> dt.name
'int32'
>>> dt.type is np.int32
True

Соответствующим скалярным типом массива является int32.

Пример

Структурированный тип данных со строкой из 16 символов в поле ‘name’ и подмассивом из двух 64-битных чисел с плавающей точкой в поле ‘grades’:

>>> import numpy as np

>>> dt = np.dtype([('name', np.str_, 16), ('grades', np.float64, (2,))])
>>> dt['name']
dtype('<U16')
>>> dt['grades']
dtype(('<f8', (2,)))

Элементы массива с этим типом данных представлены объектами скалярного типа массива, у которого также есть два поля:

>>> import numpy as np

>>> x = np.array([('Sarah', (8.0, 7.0)), ('John', (6.0, 7.0))], dtype=dt)
>>> x[1]
('John', [6., 7.])
>>> x[1]['grades']
array([6.,  7.])
>>> type(x[1])
<class 'numpy.void'>
>>> type(x[1]['grades'])
<class 'numpy.ndarray'>

Задание и создание типов данных#

Когда функция или метод NumPy требует тип данных, можно передать объект dtype или объект, преобразуемый в него. Такие преобразования выполняет конструктор dtype:

dtype(dtype[, align, copy])

--

Что можно преобразовать в объект типа данных, описано ниже:

Объект dtype

Используется как есть.

None

Тип данных по умолчанию: float64.

Типы скаляров NumPy

Все 24 встроенных объекта скалярных типов NumPy преобразуются в соответствующие объекты типов данных. Это относится и к их подклассам.

Не все сведения о типе данных можно передать объектом типа: например, у типов flexible значение itemsize по умолчанию равно 0, поэтому для практического использования размер нужно задать явно.

Пример

>>> import numpy as np

>>> dt = np.dtype(np.int32)      # 32-bit integer
>>> dt = np.dtype(np.complex128) # 128-bit complex floating-point number
Комментарии к примеру на русском
  • 32-битное целое число
  • 128-битное комплексное число с плавающей точкой

Типы с .dtype

Любой объект типа с атрибутом dtype: значение атрибута используется напрямую. Оно должно быть преобразуемо в объект dtype.

Можно преобразовывать строки нескольких видов. Для указания порядка байтов перед распознаваемой строкой можно добавить '>' (от старшего байта к младшему), '<' (от младшего байта к старшему) или '=' (родной порядок оборудования, используется по умолчанию).

Односимвольные строки

У каждого встроенного типа данных есть однозначно идентифицирующий его символьный код — обновлённые коды типов Numeric.

Пример

>>> import numpy as np

>>> dt = np.dtype('b')  # byte, native byte order
>>> dt = np.dtype('>H') # big-endian unsigned short
>>> dt = np.dtype('<f') # little-endian single-precision float
>>> dt = np.dtype('d')  # double-precision floating-point number
Комментарии к примеру на русском
  • Байт, машинный порядок байтов
  • Беззнаковый short в порядке big-endian
  • Число с плавающей точкой одинарной точности в порядке little-endian
  • Число с плавающей точкой двойной точности
Строки типов протокола массива (см. Протокол интерфейса массива)

Первый символ указывает тип данных, а остальные символы определяют количество байтов на элемент, за исключением Unicode, где он интерпретируется как количество символов, и за исключением b1, который представляет логическое значение. Пример

>>> import numpy as np

>>> dt = np.dtype('i4')   # 32-bit signed integer
>>> dt = np.dtype('f8')   # 64-bit floating-point number
>>> dt = np.dtype('c16')  # 128-bit complex floating-point number
>>> dt = np.dtype('S25')  # 25-length zero-terminated bytes
>>> dt = np.dtype('U25')  # 25-character string
Комментарии к примеру на русском
  • 32-битное знаковое целое число
  • 64-битное число с плавающей точкой
  • 128-битное комплексное число с плавающей точкой
  • Байтовая строка длины 25 с нулевым завершением
  • Строка из 25 символов
Строка с полями, разделёнными запятыми

Сокращенная запись для указания формата структурированного типа данных — это строка основных форматов, разделенная запятыми.

Базовый формат здесь состоит из необязательного указания формы и следующей за ним строки типа в протоколе массивов. Для формы с несколькими измерениями обязательны круглые скобки. NumPy расширяет этот формат: тип поля можно задать любой строкой, однозначно определяющей тип данных. Созданные поля получают имена 'f0', 'f1', …, 'f<N-1>', где N (>1) — число базовых форматов в строке, разделённых запятыми. Если форма указана, тип соответствующего поля описывает подмассив.

Пример

  • поле f0, содержащее 32-битное целое число

  • поле с именем f1, содержащее подмассив формы 2 × 3 из 64-битных чисел с плавающей запятой

  • поле с именем f2, содержащее 32-битное число с плавающей запятой

    >>> import numpy as np
>>> dt = np.dtype("i4, (2,3)f8, f4")

  • Поле под названием f0, содержащее строку из 3 символов

  • поле f1 с подмассивом формы (3,), содержащим 64-битные беззнаковые целые числа

  • поле под названием f2, содержащее подмассив 3 x 4, содержащий 10-символьные строки

    >>> import numpy as np
>>> dt = np.dtype("S3, 3u8, (3,4)S10")
Строки типов

Любое строковое имя dtype NumPy, например:

Пример

>>> import numpy as np

>>> dt = np.dtype('uint32')   # 32-bit unsigned integer
>>> dt = np.dtype('float64')  # 64-bit floating-point number
Комментарии к примеру на русском
  • 32-битное беззнаковое целое число
  • 64-битное число с плавающей точкой
(flexible_dtype, itemsize)

Первый аргумент должен преобразовываться в объект типа данных переменного размера (flexible) с нулевым размером элемента; второй аргумент — целое число, задающее желаемый itemsize.

Пример

>>> import numpy as np

>>> dt = np.dtype((np.void, 10))  # 10-byte wide data block
>>> dt = np.dtype(('U', 10))   # 10-character unicode string
Комментарии к примеру на русском
  • Блок данных размером 10 байт
  • Строка Unicode из 10 символов
(fixed_dtype, shape)

Первый аргумент — любой объект, преобразуемый в объект типа данных фиксированного размера. Второй — требуемая форма этого типа. Если параметр формы равен 1, раньше полученный объект типа данных был эквивалентен исходному dtype фиксированного размера. Это поведение объявлено устаревшим в NumPy 1.17 и в будущем будет вызывать ошибку. Если shape — кортеж, новый dtype определяет подмассив заданной формы.

Пример

>>> import numpy as np

>>> dt = np.dtype((np.int32, (2,2)))          # 2 x 2 integer sub-array
>>> dt = np.dtype(('i4, (2,3)f8, f4', (2,3))) # 2 x 3 structured sub-array
Комментарии к примеру на русском
  • Целочисленный подмассив 2 x 2
  • Структурированный подмассив 2 x 3
[(field_name, field_dtype, field_shape), ...]

obj должен быть списком полей, где каждое поле описывается кортежем длиной 2 или 3. (эквивалентно элементу descr в атрибуте __array_interface__).

Первый элемент, field_name, — имя поля. Если это '', назначается стандартное имя 'f#'. Имя поля также можно задать кортежем из двух элементов: первый — дополнительное название title, то есть произвольная строка, в том числе Unicode, либо метаданные поля в виде любого объекта; второй — имя name, которое должно быть допустимым идентификатором Python. Примечание переводчика: последнее требование оригинала излишне строго — NumPy 2.5.4 допускает также строковые имена, не являющиеся идентификаторами Python, например «not an identifier».

Второй элемент, field_dtype, может быть любым, что можно интерпретировать как тип данных.

Необязательный третий элемент field_shape задаёт форму, если поле — массив типа данных, указанного вторым элементом. В оригинале указано, что кортеж из трёх элементов с третьим значением 1 эквивалентен кортежу из двух элементов. Примечание переводчика: это устаревшее поведение. В NumPy 2.5.4 третье значение 1 создаёт поле-подмассив формы (1,), отличающееся от скалярного поля без третьего элемента.

Этот способ не допускает аргумент align в конструкторе dtype, поскольку предполагается, что описание интерфейса массива полностью определяет размещение памяти.

Пример

Тип данных с полями big (32-битное целое число с порядком байтов от старшего к младшему) и little (32-битное целое число с порядком байтов от младшего к старшему):

>>> import numpy as np

>>> dt = np.dtype([('big', '>i4'), ('little', '<i4')])

Тип данных с полями R, G, B, A, каждое из которых содержит 8-битное целое число без знака:

>>> dt = np.dtype([('R','u1'), ('G','u1'), ('B','u1'), ('A','u1')])
{'names': ..., 'formats': ..., 'offsets': ..., 'titles': ..., 'itemsize': ...}

В этой форме два обязательных и три необязательных ключа. Обязательны names и formats. Их значения — списки одинаковой длины с именами и форматами полей. Имена должны быть строками, форматы — любыми объектами, принимаемыми конструктором dtype.

Если заданы необязательные ключи offsets и titles, их значения должны быть списками той же длины, что и списки names и formats. Значение offsets — список смещений каждого поля в байтах (в пределах диапазона ctypes.c_int), а titles — список заголовков полей (если заголовок для поля не нужен, можно указать None). Заголовками titles могут быть любые объекты, но для заголовка типа str в словарь fields добавляется ещё одна запись с заголовком в качестве ключа. Она ссылается на тот же кортеж описания поля, который содержит заголовок как дополнительный элемент.

Ключ itemsize задаёт общий размер dtype и должен быть целым числом, достаточным для размещения всех полей. Если создаётся выровненный dtype, itemsize должен также делиться на величину выравнивания структуры. Общий itemsize типа dtype ограничен ctypes.c_int.

Пример

Тип данных с полями r, g, b, a, каждое из которых содержит 8-битное целое число без знака:

>>> import numpy as np

>>> dt = np.dtype({'names': ['r','g','b','a'],
...                'formats': [np.uint8, np.uint8, np.uint8, np.uint8]})

Тип данных с полями r и b и заданными дополнительными названиями. Оба поля — 8-битные беззнаковые целые числа; первое имеет байтовое смещение 0 от начала записи, второе — смещение 2. Примечание переводчика: оригинал ошибочно говорит «от начала поля»; offsets задаёт смещения полей от начала содержащей их записи:

>>> dt = np.dtype({'names': ['r','b'], 'formats': ['u1', 'u1'],
...                'offsets': [0, 2],
...                'titles': ['Red pixel', 'Blue pixel']})
{'field1': ..., 'field2': ..., ...}

Этот способ не рекомендуется, поскольку он неоднозначен по отношению к другому способу создания на основе словаря. Если имеются поля с именами «names» и «formats», возникнет конфликт.

Этот способ позволяет передать атрибут fields объекта типа данных.

obj должен содержать строковые ключи или ключи Unicode, соответствующие кортежам (data-type, offset) либо (data-type, offset, title).

Пример

Тип данных, содержащий поле col1 (10-символьная строка в позиции байта 0), col2 (32-битное число с плавающей запятой в позиции байта 10) и col3 (целые числа в позиции байта 14):

>>> import numpy as np

>>> dt = np.dtype({'col1': ('U10', 0), 'col2': (np.float32, 10),
...                'col3': (int, 14)})
(base_dtype, new_dtype)

В NumPy 1.7 и более поздних версиях эта форма позволяет интерпретировать base_dtype как структурированный dtype. Массивы, созданные с таким dtype, имеют базовый тип base_dtype, а поля и флаги берутся из new_dtype. Это полезно для создания собственных структурированных типов данных, как в массивах записей.

Эта форма также позволяет задать структурированные типы с перекрывающимися полями, подобные union в C. Однако такой способ не рекомендуется: предпочтителен механизм union.

Оба аргумента должны допускать преобразование в объекты типов данных с одинаковым общим размером.

Пример

32-битное целое число, первые два байта которого интерпретируются как целое число через поле real, а следующие два байта через поле imag.

>>> import numpy as np

>>> dt = np.dtype((np.int32,{'real':(np.int16, 0),'imag':(np.int16, 2)}))

32-битное целое число, интерпретируемое как подмассив формы (4,) из 8-битных целых чисел:

>>> dt = np.dtype((np.int32, (np.int8, 4)))

32-битное целое число, содержащее поля r, g, b, a, которые интерпретируют 4 байта целого числа как четыре целых числа без знака:

>>> dt = np.dtype(('i4', [('r','u1'),('g','u1'),('b','u1'),('a','u1')]))

Проверка типа данных#

При проверке на конкретный тип данных используйте сравнение ==.

Пример

>>> import numpy as np

>>> a = np.array([1, 2], dtype=np.float32)
>>> a.dtype == np.float32
True

В отличие от типов Python, сравнение с использованием is не должно использоваться.

Во-первых, NumPy считает спецификации типов данных (всё, что можно передать конструктору dtype) эквивалентными самому объекту типа данных. Для проверки такой эквивалентности следует использовать ==, а не is.

Пример

Объект dtype равен всем спецификациям типа данных, которые ему эквивалентны.

>>> import numpy as np

>>> a = np.array([1, 2], dtype=np.float64)
>>> a.dtype == np.dtype(np.float64)
True
>>> a.dtype == np.float64
True
>>> a.dtype == float
True
>>> a.dtype == "float64"
True
>>> a.dtype == "d"
True

Во-вторых, нет гарантии, что для каждого типа данных существует единственный экземпляр объекта dtype.

Пример

Не используйте is, поскольку объекты типов данных не обязательно являются синглтонами (единственными экземплярами).

>>> import numpy as np

>>> np.dtype(float) is np.dtype(float)
True
>>> np.dtype([('a', float)]) is np.dtype([('a', float)])
False

dtype#

Описания типов данных NumPy являются экземплярами класса dtype.

Атрибуты#

Тип данных описывается следующими атрибутами dtype:

dtype.type

dtype.kind

Символьный код (один из символов «biufcmMOSTUV»), обозначающий общий вид данных.

dtype.char

Уникальный символьный код для каждого из 21 встроенного типа.

dtype.num

Уникальный номер каждого из 21 встроенного типа.

dtype.str

Строка описания этого типа данных в протоколе массивов.

Размер данных, в свою очередь, описывается:

dtype.name

Имя этого типа данных с указанием разрядности.

dtype.itemsize

Размер элемента этого объекта типа данных.

Порядок байтов этих данных:

dtype.byteorder

Символ, указывающий порядок байтов этого объекта типа данных.

Информация о вложенных типах данных в структурированном типе данных:

dtype.fields

Словарь названных полей, определенных для данного типа данных, или None.

dtype.names

Упорядоченный список имен полей или None, если полей нет.

Для типов данных, описывающих подмассивы:

dtype.subdtype

Кортеж (item_dtype, shape), если этот dtype описывает подмассив; иначе None.

dtype.shape

Кортеж формы подмассива, если этот тип данных описывает подмассив; иначе ().

Атрибуты, предоставляющие дополнительную информацию:

dtype.hasobject

Логическое значение, указывающее, содержит ли этот dtype объекты с подсчётом ссылок в каких-либо полях или вложенных типах.

dtype.flags

Бит-флаги, описывающие, как следует интерпретировать этот тип данных.

dtype.isbuiltin

Целое число, указывающее, как этот dtype относится к встроенным типам.

dtype.isnative

Логическое значение, показывающее, совпадает ли порядок байтов этого dtype с системным.

dtype.descr

Описание типа данных в формате __array_interface__.

dtype.alignment

Выравнивание этого типа данных в байтах, требуемое компилятором.

dtype.base

Возвращает dtype базового элемента подмассивов независимо от их числа измерений и формы.

Метаданные, прикрепленные пользователем:

dtype.metadata

Либо None, либо доступный только для чтения словарь метаданных (mappingproxy).

Методы #

У типов данных есть следующий метод изменения порядка байтов:

dtype.newbyteorder([new_order])

Возврат нового dtype с другим байт-порядком.

Следующие методы реализуют протокол pickle:

dtype.__reduce__

Вспомогательный метод для pickle.

dtype.__setstate__

Вспомогательный метод для аннотаций типов:

dtype.__class_getitem__(item, /)

Возвращает параметризованную обёртку над типом dtype.

Операции сравнения:

dtype.__ge__(value, /)

Возвращает self>=value.

dtype.__gt__(value, /)

Возвращает self>value.

dtype.__le__(value, /)

Возвращает self<=value.

dtype.__lt__(value, /)

Возвращает self<value.

назад

numpy.number.__class_getitem__

далее

numpy.dtype
