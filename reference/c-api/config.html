Конфигурация системы#

При сборке NumPy сведения о конфигурации системы сохраняются и становятся доступны модулям расширения, использующим C API NumPy. Эти сведения в основном определены в numpyconfig.h (подключаемом из ndarrayobject.h). Имена общедоступных символов имеют префикс NPY_*. NumPy также предоставляет функции для получения сведений об используемой платформе.

Для внутреннего использования NumPy также создаёт config.h в своём каталоге заголовочных файлов. Эти символы не экспортируются NumPy, то есть расширение Python, использующее C API NumPy, их не видит; это позволяет избежать засорения пространства имён.

Размеры типов данных #

Константы NPY_SIZEOF_{CTYPE} определены так, чтобы препроцессору была доступна информация sizeof.

NPY_SIZEOF_SHORT#

sizeof(short)

NPY_SIZEOF_INT#

sizeof(int)

NPY_SIZEOF_LONG#

sizeof(long)

NPY_SIZEOF_LONGLONG#

sizeof(longlong), где longlong определён подходящим для платформы образом.

NPY_SIZEOF_PY_LONG_LONG#
NPY_SIZEOF_FLOAT#

sizeof(float)

NPY_SIZEOF_DOUBLE#

sizeof(double)

NPY_SIZEOF_LONG_DOUBLE#
NPY_SIZEOF_LONGDOUBLE#

sizeof(longdouble)

NPY_SIZEOF_PY_INTPTR_T#

Размер указателя void * и intptr_t/Py_intptr_t.

NPY_SIZEOF_INTP#

Размер size_t на этой платформе (sizeof(size_t))

Информация о платформе#

NPY_CPU_X86#
NPY_CPU_AMD64#
NPY_CPU_IA64#
NPY_CPU_PPC#
NPY_CPU_PPC64#
NPY_CPU_SPARC#
NPY_CPU_SPARC64#
NPY_CPU_S390#
NPY_CPU_PARISC#

Архитектура процессора платформы; определена только одна из вышеперечисленных.

Определено в numpy/npy_cpu.h

NPY_LITTLE_ENDIAN#
NPY_BIG_ENDIAN#
NPY_BYTE_ORDER#

Переносимые альтернативы макросам endian.h из GNU Libc. При порядке байтов big-endian NPY_BYTE_ORDER == NPY_BIG_ENDIAN; аналогично для архитектур little-endian.

Определено в numpy/npy_endian.h.

int PyArray_GetEndianness()#

Возвращает порядок байтов текущей платформы: NPY_CPU_BIG, NPY_CPU_LITTLE или NPY_CPU_UNKNOWN_ENDIAN.

NPY_CPU_BIG#
NPY_CPU_LITTLE#
NPY_CPU_UNKNOWN_ENDIAN#

Директивы компилятора #

NPY_UNLIKELY#
