Базовая математическая библиотека NumPy #

Эта библиотека содержит большинство связанных с математикой функций C99, которые могут использоваться на платформах, где C99 не поддерживается должным образом.Основные математические функции имеют тот же API, что и у C99, за исключением префикса npy_*.

Доступные функции определены в <numpy/npy_math.h> — в случае сомнений обратитесь к этому заголовочному файлу.

Примечание

Ведётся работа по сокращению npymath (поскольку поддержка C99 компиляторами со временем улучшилась) и упрощению включения этой библиотеки в сторонние проекты либо использования только через заголовочные файлы. Это позволит избежать проблем при поставке статической библиотеки, собранной компилятором, отличным от используемого зависимым пакетом или конечным пользователем. Подробности см. в gh-20880.

Классификация чисел с плавающей точкой#

NPY_NAN#

Этот макрос задаёт NaN (не число) с гарантированно сброшенным знаковым битом, то есть «положительный» NaN. Соответствующие макросы одинарной и расширенной точности доступны с суффиксами F и L.

NPY_INFINITY#

Этот макрос определён как положительная бесконечность. Соответствующие макросы одинарной и расширенной точности доступны с суффиксами F и L.

NPY_PZERO#

Этот макрос определен как положительный ноль. Соответствующие макросы одинарной и расширенной точности доступны с суффиксами F и L.

NPY_NZERO#

Этот макрос задаёт отрицательный ноль, то есть ноль с установленным знаковым битом. Соответствующие макросы одинарной и расширенной точности имеют суффиксы F и L.

npy_isnan(x)#

Псевдоним функции isnan из C99: работает для одинарной, двойной и расширенной точности и возвращает ненулевое значение, если x — NaN.

npy_isfinite(x)#

Псевдоним функции isfinite из C99. Работает с числами одинарной, двойной и расширенной точности и возвращает ненулевое значение, если x не является ни NaN, ни бесконечностью.

npy_isinf(x)#

Это псевдоним isinf из C99: работает с одинарной, двойной и расширенной точностью и возвращает ненулевое значение, если x — положительная или отрицательная бесконечность.

npy_signbit(x)#

Псевдоним функции signbit из C99. Работает с числами одинарной, двойной и расширенной точности и возвращает ненулевое значение, если у x установлен знаковый бит (то есть число отрицательное).

npy_copysign(x, y)#

Псевдоним функции copysign из C99: возвращает x со знаком y. Работает для любых значений, включая inf и nan. Варианты одинарной и расширенной точности имеют суффиксы f и l.

Полезные математические константы#

В npy_math.h доступны следующие математические константы. Варианты одинарной и расширенной точности получаются добавлением суффиксов f и l соответственно.

NPY_E#

Основание натурального логарифма (\(e\))

NPY_LOG2E#

Двоичный логарифм числа e (\(\frac{\ln(e)}{\ln(2)}\))

NPY_LOG10E#

Десятичный логарифм числа e (\(\frac{\ln(e)}{\ln(10)}\))

NPY_LOGE2#

Натуральный логарифм 2 (\(\ln(2)\))

NPY_LOGE10#

Натуральный логарифм 10 (\(\ln(10)\))

NPY_PI#

Пи (\(\pi\))

NPY_PI_2#

Пи, делённое на 2 (\(\frac{\pi}{2}\))

NPY_PI_4#

Пи деленное на 4 ( \(\frac{\pi}{4}\) )

NPY_1_PI#

Обратная величина числа Пи ( \(\frac{1}{\pi}\) )

NPY_2_PI#

Удвоенное обратное значение числа пи (\(\frac{2}{\pi}\))

NPY_EULER#
Постоянная Эйлера

\(\lim_{n\rightarrow\infty}({\sum_{k=1}^n{\frac{1}{k}}-\ln n})\)

Низкоуровневые операции с числами с плавающей точкой#

Они могут быть полезны для точного сравнения чисел с плавающей запятой.

double npy_nextafter(double x, double y)#

Псевдоним nextafter из C99: возвращает следующее представимое число с плавающей точкой после x в направлении y. Варианты одинарной и расширенной точности доступны с суффиксами f и l.

double npy_spacing(double x)#

Функция эквивалентна встроенной функции Fortran. Возвращает расстояние от x до следующего представимого значения с плавающей точкой, например spacing(1) == eps. Для nan и +/- inf функция spacing возвращает nan. Варианты одинарной и расширенной точности доступны с суффиксами f и l.

void npy_set_floatstatus_divbyzero()#

Установить флаг исключения деления на ноль в арифметике с плавающей точкой

void npy_set_floatstatus_overflow()#

Установить флаг исключения переполнения с плавающей точкой

void npy_set_floatstatus_underflow()#

Устанавливает флаг исключения антипереполнения при вычислениях с плавающей запятой

void npy_set_floatstatus_invalid()#

Установить флаг исключения недопустимой операции с плавающей точкой

int npy_get_floatstatus()#

Получает состояние операций с плавающей запятой. Возвращает битовую маску со следующими возможными флагами:

  • NPY_FPE_DIVIDEBYZERO

  • NPY_FPE_OVERFLOW

  • NPY_FPE_UNDERFLOW

  • NPY_FPE_INVALID

Предпочтительно использовать npy_get_floatstatus_barrier: это не позволяет агрессивным оптимизациям компилятора переставлять вызов относительно кода установки состояния, что могло бы привести к неверным результатам.

int npy_get_floatstatus_barrier(char*)#

Получает флаги состояния вычислений с плавающей точкой. Указатель на локальную переменную передаётся, чтобы агрессивные оптимизации компилятора не меняли порядок этого вызова относительно кода, устанавливающего флаги: такое переупорядочение могло бы привести к неверным результатам.

Возвращает битовую маску со следующими возможными флагами:

  • NPY_FPE_DIVIDEBYZERO

  • NPY_FPE_OVERFLOW

  • NPY_FPE_UNDERFLOW

  • NPY_FPE_INVALID

int npy_clear_floatstatus()#

Сбрасывает флаги состояния вычислений с плавающей точкой. Возвращает прежнюю битовую маску состояния.

Предпочтительно использовать npy_clear_floatstatus_barrier: это не позволяет агрессивным оптимизациям компилятора переставлять вызов относительно кода установки состояния, что могло бы привести к неверным результатам.

int npy_clear_floatstatus_barrier(char*)#

Сбрасывает флаги состояния вычислений с плавающей точкой. Указатель на локальную переменную передаётся, чтобы агрессивные оптимизации компилятора не меняли порядок вызова этой функции. Возвращает прежнюю маску флагов состояния.

Поддержка комплексных чисел #

Добавлены функции для комплексных чисел, аналогичные функциям C99. Они подходят для переносимых расширений на C. Начиная с NumPy 2.0 в основе используются комплексные типы C99:

typedef double _Complex npy_cdouble;
typedef float _Complex npy_cfloat;
typedef long double _Complex npy_clongdouble;

MSVC не поддерживает сам тип _Complex, но добавил поддержку заголовка C99 complex.h, обеспечив собственную реализацию.Таким образом, в рамках MSVC будут использоваться эквивалентные типы MSVC:

typedef _Dcomplex npy_cdouble;
typedef _Fcomplex npy_cfloat;
typedef _Lcomplex npy_clongdouble;

Поскольку MSVC всё ещё не поддерживает синтаксис C99 для инициализации комплексного числа, необходимо ограничиться синтаксисом, совместимым с C90, например:

/* a = 1 + 2i \*/
npy_complex a = npy_cpack(1, 2);
npy_complex b;

b = npy_log(a);

В numpy/npy_math.h также добавлено несколько вспомогательных функций для получения или изменения действительной и мнимой частей комплексного числа:

npy_cdouble c;
npy_csetreal(&c, 1.0);
npy_csetimag(&c, 0.0);
printf("%d + %di\n", npy_creal(c), npy_cimag(c));

Изменено в версии 2.0.0: Для всех комплексных типов NumPy базовые типы C заменены комплексными типами C99. До этого комплексные типы представлялись следующим образом:

typedef struct { double real, imag; } npy_cdouble;
typedef struct { float real, imag; } npy_cfloat;
typedef struct {npy_longdouble real, imag;} npy_clongdouble;

Представление с помощью struct позволяло использовать комплексные числа на всех платформах, даже без поддержки встроенных комплексных типов. При этом вместе с NumPy приходилось поставлять статическую библиотеку, обеспечивающую совместимость с C99 для зависимых пакетов. Однако за последние годы поддержка встроенных комплексных типов значительно улучшилась: в частности, в 2019 году в MSVC появилась встроенная поддержка заголовочного файла complex.h.

Для облегчения совместимости между версиями добавлены макросы, использующие новые API установки значений.

#define NPY_CSETREAL(z, r) npy_csetreal(z, r)
#define NPY_CSETIMAG(z, i) npy_csetimag(z, i)

Уровень совместимости также предусмотрен в numpy/npy_2_complexcompat.h. Он проверяет, существуют ли макросы, и возвращается к синтаксису 1.x, если их нет.

#include <numpy/npy_math.h>

#ifndef NPY_CSETREALF
#define NPY_CSETREALF(c, r) (c)->real = (r)
#endif
#ifndef NPY_CSETIMAGF
#define NPY_CSETIMAGF(c, i) (c)->imag = (i)
#endif

Пакетам, зависящим от NumPy и нуждающимся в этой возможности, рекомендуется скопировать код слоя совместимости в свои исходные файлы и использовать его. Это позволит без проблем поддерживать NumPy 1.x и 2.x. Также обратите внимание: заголовочный файл complex.h включён в numpy/npy_common.h, поэтому complex становится зарезервированным ключевым словом.

Компоновка расширения с основной математической библиотекой#

Чтобы использовать в собственном расширении Python базовую математическую библиотеку, поставляемую с NumPy в виде статической библиотеки, нужно добавить параметры компиляции и компоновки для npymath. Конкретные действия зависят от системы сборки. Общая последовательность такова:

  1. Добавьте каталог заголовочных файлов NumPy (значение np.get_include()) в список каталогов поиска заголовков,

  2. Статическая библиотека npymath находится в каталоге lib рядом с каталогом заголовочных файлов NumPy (то есть pathlib.Path(np.get_include()) / '..' / 'lib'). Добавьте этот каталог в пути поиска библиотек,

  3. Скомпонуйте с libnpymath и libm.

Примечание

При кросс-компиляции необходимо использовать numpy для целевой платформы, а не для компьютера, на котором выполняется сборка. Иначе будет подключена статическая библиотека, собранная для другой архитектуры.

При сборке с помощью Meson используйте:

# Note that this will get easier in the future, when Meson has
# support for numpy built in; most of this can then be replaced
# by `dependency('numpy')`.
incdir_numpy = run_command(py3,
  [
    '-c',
    'import os; os.chdir(".."); import numpy; print(numpy.get_include())'
  ],
  check: true
).stdout().strip()

inc_np = include_directories(incdir_numpy)

cc = meson.get_compiler('c')
npymath_path = incdir_numpy / '..' / 'lib'
npymath_lib = cc.find_library('npymath', dirs: npymath_path)

py3.extension_module('module_name',
  ...
  include_directories: inc_np,
  dependencies: [npymath_lib],
Комментарии к примеру на русском
  • В будущем станет проще, когда Meson получит
  • встроенную поддержку NumPy: большую часть этого кода можно будет заменить
  • на `dependency('numpy')`.

Функции половинной точности#

Заголовочный файл <numpy/halffloat.h> предоставляет функции для 16-битных чисел с плавающей точкой по IEEE 754-2008. Хотя этот формат обычно не используют для численных вычислений, он удобен для хранения значений, которым нужна плавающая точка, но не высокая точность. Также он полезен для изучения погрешностей округления.

Как и для других типов, NumPy предоставляет typedef npy_half для 16-битного числа с плавающей точкой. Но в отличие от большинства других типов, его нельзя использовать в C как обычный числовой тип: это псевдоним npy_uint16. Например, значение 1.0 в C выглядит как 0x3c00, а при сравнении нулей разных знаков получится -0.0 != 0.0 (0x8000 != 0x0000), что неверно.

Поэтому NumPy предоставляет API для работы со значениями npy_half. Для доступа подключите <numpy/halffloat.h> и скомпонуйте код с npymath. Если нужные операции, например арифметические, не предоставлены напрямую, рекомендуется преобразовать значения в float или double, выполнить операцию и преобразовать обратно, как в следующем примере.

npy_half sum(int n, npy_half *array) {
    float ret = 0;
    while(n--) {
        ret += npy_half_to_float(*array++);
    }
    return npy_float_to_half(ret);
}

Преобразует число с плавающей точкой одинарной точности в число половинной точности. Округляет к ближайшему представимому значению; при равном расстоянии выбирается значение с чётным младшим битом. Если значение слишком мало или слишком велико, устанавливается системный бит underflow или overflow для арифметики с плавающей точкой.
