API даты и времени#

Внутреннее представление дат в NumPy состоит из счётчика int64 и структуры метаданных единицы времени. Разности времён представлены аналогично: числом int64 и структурой метаданных единицы времени. Описанные ниже функции облегчают преобразование между строками дат ISO 8601, значениями datetime NumPy и объектами datetime Python в коде C.

Типы данных#

Помимо псевдонимов типов npy_datetime и npy_timedelta для npy_int64, NumPy определяет ещё две структуры: для метаданных единиц времени и для представления даты и времени в виде отдельных компонентов.

type PyArray_DatetimeMetaData#

Представляет метаданные единицы измерения даты и времени.

typedef struct {
    NPY_DATETIMEUNIT base;
    int num;
} PyArray_DatetimeMetaData;
NPY_DATETIMEUNIT base#

Единица измерения даты и времени.

int num#

Умножитель для единицы.

type npy_datetimestruct#

Развёрнутое представление компонентов значения даты и времени

typedef struct {
    npy_int64 year;
    npy_int32 month, day, hour, min, sec, us, ps, as;
} npy_datetimestruct;
enum NPY_DATETIMEUNIT#

Единицы времени, поддерживаемые NumPy. «FR» в именах элементов перечисления — сокращение от frequency (частота).

Функции преобразования#

int NpyDatetime_ConvertDatetimeStructToDatetime64(PyArray_DatetimeMetaData *meta, const npy_datetimestruct *dts, npy_datetime *out)#

Преобразует дату и время из datetimestruct в значение datetime с единицами измерения, указанными в метаданных. Предполагается, что дата корректна.

Если num-член структуры метаданных большой, в этой функции может быть целочисленное переполнение.

Возвращает 0 при успехе и -1 при ошибке.

int NpyDatetime_ConvertDatetime64ToDatetimeStruct(PyArray_DatetimeMetaData *meta, npy_datetime dt, npy_datetimestruct *out)#

Преобразует значение даты и времени с единицей измерения, заданной в метаданных, в структуру с отдельными компонентами даты и времени.

Возвращает 0 при успехе и -1 при ошибке.

int NpyDatetime_ConvertPyDateTimeToDatetimeStruct(PyObject *obj, npy_datetimestruct *out, NPY_DATETIMEUNIT *out_bestunit, int apply_tzinfo)#

Проверяет и преобразует объект Python datetime.datetime или datetime.date в объект NumPy npy_datetimestruct.

out_bestunit содержит рекомендуемую единицу измерения, выбранную в зависимости от того, является ли объект экземпляром datetime.date или datetime.datetime.

Если apply_tzinfo равен 1, эта функция использует tzinfo для преобразования во время UTC, в противном случае она возвращает структуру с местным временем.

Возвращает -1 при ошибке, 0 при успехе и 1 без установки ошибки, если у obj нет необходимых атрибутов date или datetime.

int NpyDatetime_ParseISO8601Datetime(char const *str, Py_ssize_t len, NPY_DATETIMEUNIT unit, NPY_CASTING casting, npy_datetimestruct *out, NPY_DATETIMEUNIT *out_bestunit, npy_bool *out_special)#

Разбирает строки дат, (почти) соответствующие стандарту ISO 8601. Отличия таковы:

  • Дата «20100312» разбирается как год 20100312, а не как эквивалент «2010-03-12». Символы «-» в датах обязательны.

  • Дробная часть с десятичной точкой допускается только у секунд: до 18 цифр после точки, то есть максимум с точностью до аттосекунд.

  • Для разделения даты и времени можно использовать ‘T’, как в ISO 8601, либо пробел ‘ ’. Оба варианта равнозначны.

  • Не обрабатывает (пока) форматы YYYY-DDD или YYYY-Www.

  • Не обрабатывает дополнительные секунды координации (в таких случаях поле секунд имеет значение 60).

  • Не обрабатывает 24:00:00 как обозначение полуночи следующего дня (00:00:00)

  • Принимает специальные значения «NaT» (не время), «Today» (текущий день по местному времени) и «Now» (текущее время в UTC).

str должен быть строкой с завершающим нулевым байтом, а len — её длиной.

unit должен содержать -1, если единица времени неизвестна, либо используемую единицу, если она известна.

casting определяет допустимые правила преобразования единицы времени, обнаруженной в строке, к единице, заданной параметром unit.

В out записывается результат разбора даты и времени.

out_bestunit задаёт рекомендуемую единицу измерения на основе точности времени в строке или -1 для NaT.

out_special устанавливается в 1, если разобранное время задано как «today», «now», пустая строка или «NaT». Для «today» рекомендуется единица «D», для «now» — «s», для «NaT» — «Y».

Возвращает 0 при успехе и -1 при неудаче.

int NpyDatetime_GetDatetimeISO8601StrLen(int local, NPY_DATETIMEUNIT base)#

Возвращает длину строки, которая будет использоваться для преобразования объектов datetime с заданными настройками местного времени и единиц измерения в строки. Используйте это при создании строк для передачи в NpyDatetime_MakeISO8601Datetime.

int NpyDatetime_MakeISO8601Datetime(npy_datetimestruct *dts, char *outstr, npy_intp outlen, int local, int utc, NPY_DATETIMEUNIT base, int tzoffset, NPY_CASTING casting)#

Преобразует npy_datetimestruct в строку почти по ISO 8601, завершающуюся NULL. Если строка занимает всё доступное место, завершающий NULL опускается, а функция сообщает об успехе.

Отличия от ISO 8601: поддерживается строка ‘NaT’, а число цифр года может быть >= 4, а не строго 4.

Если local ненулевой, создаётся строка с местным временем и смещением часового пояса в формате +-####. Если local равен нулю, а utc ненулевой, создаётся строка, заканчивающаяся на «Z», что обозначает UTC. По умолчанию сведения о часовом поясе не добавляются.

base ограничивает вывод указанной единицей времени. Задайте base=-1, чтобы автоматически определить единицу времени, мельче которой все компоненты равны нулю.

tzoffset используется при включённом local, если tzoffset не равен -1. Он вручную задаёт используемый местный часовой пояс как смещение в минутах.

casting определяет, допускается ли потеря данных при усечении до менее точной единицы измерения. Этот параметр также связан с local: для формирования строки даты в местном времени требуется небезопасное приведение типов.

Возвращает 0 при успехе и -1 при неудаче, например если выходная строка оказалась слишком короткой.
