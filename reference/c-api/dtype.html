API типов данных#

Стандартный массив может иметь один из 25 типов данных; предусмотрена и некоторая поддержка добавления собственных типов. У каждого типа данных есть константа перечисления, символьный код и соответствующий объект скалярного типа Python, включённый в иерархию типов. Также предусмотрены стандартные определения typedef в C для удобной работы с элементами данного типа. Для числовых типов дополнительно есть определения typedef C с заданной разрядностью и именованные номера типов, упрощающие выбор нужной точности.

Предупреждение

Имена типов в коде C ближе к соглашениям языка C, а их имена в Python следуют соглашениям Python. Например, NPY_FLOAT обозначает 32-битный float в C, а numpy.float64 в Python соответствует 64-битному double. Для ясности и в Python, и в C можно использовать имена с явным указанием разрядности.

Перечисляемые типы#

enum NPY_TYPES#

Определены значения перечисления для 25 базовых типов данных и нескольких полезных обобщённых имён. Когда коду нужен номер типа, используется одно из этих значений. Их имена имеют вид NPY_{NAME}:

enumerator NPY_BOOL#

Значение перечисления для булевого типа, хранящееся в виде одного байта, может быть установлено только на значения 0 и 1.

enumerator NPY_BYTE#
enumerator NPY_INT8#

Значение перечисления для 8-битного/1-байтового целого числа со знаком.

enumerator NPY_SHORT#
enumerator NPY_INT16#

Значение перечисления для 16-разрядного (2-байтового) знакового целого числа.

enumerator NPY_INT#
enumerator NPY_INT32#

Значение перечисления для 32-битного (4-байтного) знакового целого числа.

enumerator NPY_LONG#

Эквивалент NPY_INT или NPY_LONGLONG, в зависимости от платформы.

enumerator NPY_LONGLONG#
enumerator NPY_INT64#

Значение перечисления для 64-битного (8-байтового) целого числа со знаком.

enumerator NPY_UBYTE#
enumerator NPY_UINT8#

Значение перечисления для беззнакового целого числа размером 8 бит (1 байт).

enumerator NPY_USHORT#
enumerator NPY_UINT16#

Значение перечисления для 16-битного (2-байтового) беззнакового целого числа.

enumerator NPY_UINT#
enumerator NPY_UINT32#

Значение перечисления для 32-разрядного (4-байтового) беззнакового целого числа.

enumerator NPY_ULONG#

Эквивалентно NPY_UINT или NPY_ULONGLONG, в зависимости от платформы.

enumerator NPY_ULONGLONG#
enumerator NPY_UINT64#

Значение перечисления для 64-битного (8-байтового) беззнакового целого числа.

enumerator NPY_HALF#
enumerator NPY_FLOAT16#

Значение перечисления для 16-разрядного (2-байтового) типа с плавающей запятой, совместимого с IEEE 754-2008.

enumerator NPY_FLOAT#
enumerator NPY_FLOAT32#

Значение перечисления для 32-битного (4-байтового) типа с плавающей точкой, совместимого с IEEE 754.

enumerator NPY_DOUBLE#
enumerator NPY_FLOAT64#

Значение перечисления для 64-битного, то есть 8-байтного, типа с плавающей точкой, совместимого с IEEE 754.

enumerator NPY_LONGDOUBLE#

Значение перечисления для зависящего от платформы типа с плавающей точкой, размер которого не меньше NPY_DOUBLE, а на многих платформах больше.

enumerator NPY_CFLOAT#
enumerator NPY_COMPLEX64#

Значение перечисления для 64-битного (8-байтового) комплексного типа, состоящего из двух значений NPY_FLOAT.

enumerator NPY_CDOUBLE#
enumerator NPY_COMPLEX128#

Значение перечисления для 128-битного (16-байтового) комплексного типа, состоящего из двух значений NPY_DOUBLE.

enumerator NPY_CLONGDOUBLE#

Значение перечисления для зависящего от платформы комплексного типа с плавающей запятой, состоящего из двух значений NPY_LONGDOUBLE.

enumerator NPY_DATETIME#

Значение перечисления для типа, хранящего даты или дату и время с точностью, задаваемой выбранной единицей даты или времени.

enumerator NPY_TIMEDELTA#

Значение перечисления для типа данных, представляющего длительности целыми числами в выбранных единицах даты или времени.

enumerator NPY_STRING#

Значение перечисления для байтовых строк задаваемого размера, дополненных нулевыми байтами. В пределах одного массива максимальный размер строк фиксирован.

enumerator NPY_UNICODE#

Значение перечисления для строк UCS4 выбираемого размера. В пределах одного массива строки имеют фиксированную максимальную длину.

enumerator NPY_VSTRING#

Значение перечисления для строк переменной длины UTF-8. Этот dtype содержит массив ссылок, а строковые данные хранятся вне буфера массива. Для доступа к строке каждого элемента используйте C API строк NumPy переменной длины.

Примечание

Этот DType относится к новому API и не входит в NPY_NTYPES_LEGACY.

enumerator NPY_OBJECT#

Значение перечисления для ссылок на произвольные объекты Python.

enumerator NPY_VOID#

В основном используется для хранения структурированных dtype, но может содержать произвольные двоичные данные.

Некоторые полезные псевдонимы вышеперечисленных типов

enumerator NPY_INTP#

Значение перечисления для целого со знаком типа Py_ssize_t, совпадающего с ssize_t, если тот определён. Этот тип используется всеми массивами индексов.

Изменено в версии 2.0: Ранее этот тип совпадал с intptr_t и имел размер указателя. На практике различие проявляется лишь на очень редких платформах. Для обозначения типа, соответствующего указателю, можно использовать символьный код 'p'.

enumerator NPY_UINTP#

Значение перечисления для беззнакового целочисленного типа, идентичного size_t.

Изменено в версии 2.0: Ранее этот тип совпадал с uintptr_t и имел размер указателя. На практике различие проявляется лишь на очень редких платформах. Для обозначения типа, соответствующего указателю, можно использовать символьный код 'P'.

enumerator NPY_MASK#

Значение перечисления типа, используемого для масок, например, с флагом итератора NPY_ITER_ARRAYMASK. Это эквивалентно NPY_UINT8.

enumerator NPY_DEFAULT_TYPE#

Тип по умолчанию, используемый, когда dtype не задан явно, например при вызове np.zero(shape). Эквивалентен NPY_DOUBLE.

Другие полезные связанные константы:

NPY_NTYPES_LEGACY#

Число встроенных типов NumPy, реализованных с помощью прежней системы DType. Новые dtype NumPy будут использовать новый API DType и могут вести себя иначе. Этот макрос подходит, если для прежних DType нужны отдельные ветви кода либо если вы не хотите обновлять код, использующий NPY_NTYPES_LEGACY и некорректно работающий с новыми DType.

Примечание

Новые DType, такие как NPY_VSTRING, не будут учитываться в NPY_NTYPES_LEGACY.

NPY_NOTYPE#

Сигнальное значение, гарантированно не совпадающее с допустимым номером типа из перечисления.

NPY_USERDEF#

Начальный номер диапазона типов, используемого для пользовательских типов данных старого образца. Пользовательским DType нового образца сейчас не присваивается номер типа.

Примечание

Общее количество пользовательских типов ограничено значением ниже NPY_VSTRING. Более высокие номера зарезервированы для будущего использования DType нового стиля.

Символьные коды, обозначающие определённые типы, также входят в перечисление. Для обращения к символам типов, если это вообще требуется, всегда следует использовать эти константы перечисления. Они имеют вид NPY_{NAME}LTR, где {NAME} может принимать значения

BOOL , BYTE , UBYTE , SHORT , USHORT , INT , UINT , LONG , ULONG , LONGLONG , ULONGLONG , HALF , FLOAT , DOUBLE , LONGDOUBLE , CFLOAT , CDOUBLE , CLONGDOUBLE , DATETIME , TIMEDELTA , OBJECT , STRING , UNICODE , VSTRING , VOID

INTP , UINTP

GENBOOL , SIGNED , UNSIGNED , FLOATING , COMPLEX

Последняя группа {NAME}s соответствует буквам, используемым в спецификации строки типа интерфейса массива.

Определения препроцессора#

Максимальные и минимальные значения целых чисел#

NPY_MAX_INT{bits}, NPY_MAX_UINT{bits}, NPY_MIN_INT{bits}

Эти определения существуют для {bits} = 8, 16, 32, 64, 128 и 256 и задают максимальное или минимальное значение соответствующего целочисленного типа, в том числе беззнакового. Сам тип может быть доступен не на всех платформах: например, 128- и 256-битные целые редки.

NPY_MIN_{type}

Это определено для {type} = BYTE , SHORT , INT , LONG , LONGLONG , INTP

NPY_MAX_{type}

Определено для {type} = BYTE, UBYTE, SHORT, USHORT, INT, UINT, LONG, ULONG, LONGLONG, ULONGLONG, INTP, UINTP

Количество битов в типах данных #

Для всех констант NPY_SIZEOF_{CTYPE} определены соответствующие константы NPY_BITSOF_{CTYPE}. Константы NPY_BITSOF_{CTYPE} предоставляют количество битов в типе данных. В частности, доступные {CTYPE}s:

BOOL, CHAR, SHORT, INT, LONG, LONGLONG, FLOAT, DOUBLE, LONGDOUBLE

Обращение к номерам типов перечисления по разрядности#

Для всех числовых типов данных — целых, вещественных и комплексных — определены константы, соответствующие определённым номерам типов в перечислении. Какому именно типу перечисления соответствует тип заданной разрядности, зависит от платформы. Доступны константы PyArray_{NAME}{BITS}, где {NAME} — INT, UINT, FLOAT или COMPLEX, а {BITS} может быть 8, 16, 32, 64, 80, 96, 128, 160, 192, 256 или 512. Не все разрядности доступны на всех платформах для каждой категории числовых типов. Обычно доступны целые числа разрядности 8, 16, 32 и 64 бита, вещественные числа разрядности 32 и 64 бита и комплексные числа разрядности 64 и 128 бит.

Дополнительные псевдонимы целочисленных типов#

Константы NPY_INTP и NPY_UINTP соответствуют Py_ssize_t и size_t. Хотя на практике размеры этих типов обычно совпадают с размером указателя, строго говоря, это не гарантируется. Для целых чисел размером с указатель можно использовать символьные коды 'p' и 'P'. До NumPy 2 тип intp имел размер указателя — отсюда и название, хотя реальное использование этого типа почти никогда не требовало именно этого свойства.

Начиная с NumPy 2 дополнительно определён макрос NPY_DEFAULT_INT. Его значение зависит от используемой во время выполнения версии: для NumPy 2 и новее он соответствует NPY_INTP, для более ранних версий — NPY_LONG.

type npy_intp#

Py_ssize_t — целое со знаком того же размера, что и тип C size_t. Это подходящий целочисленный тип для длин и индексов. На практике его размер обычно равен размеру указателя, но это не гарантируется.

Примечание

До NumPy 2.0 этот тип совпадал с Py_intptr_t. Хотя это лучше соответствовало названию, на практике оно не отражало реального использования. В Python по-прежнему можно использовать np.dtype('p'), чтобы получить dtype, подходящий для хранения указателей, а символьный код n соответствует ssize_t.

Имена, указывающие разрядность#

Также определены псевдонимы типов (typedef) для целых чисел со знаком и без знака, вещественных и комплексных чисел с плавающей точкой заданной разрядности. Доступны следующие имена типов:

npy_int{bits}, npy_uint{bits}, npy_float{bits} и npy_complex{bits}

где {bits} — число битов типа: 8, 16, 32, 64, 128 и 256 для целых типов; 16, 32, 64, 80, 96, 128 и 256 для типов с плавающей точкой; 32, 64, 128, 160, 192 и 512 для комплексных типов. Доступная разрядность зависит от платформы. Выделенные полужирным значения обычно доступны на всех платформах.
