NpyString API #

Добавлено в версии 2.0.

Этот API позволяет получить доступ к данным строк UTF-8, хранящимся в массивах NumPy StringDType. См. NEP-55 для получения более подробной информации о дизайне StringDType.

Примеры#

Загрузка строки#

Предположим, мы пишем ufunc для StringDType. Если заданы указатель const char *buf на начало элемента массива StringDType и указатель PyArray_Descr * на дескриптор массива, доступ к строковым данным можно получить так:

npy_string_allocator *allocator = NpyString_acquire_allocator(
        (PyArray_StringDTypeObject *)descr);

npy_static_string sdata = {0, NULL};
npy_packed_static_string *packed_string = (npy_packed_static_string *)buf;
int is_null = 0;

is_null = NpyString_load(allocator, packed_string, &sdata);

if (is_null == -1) {
    // failed to load string, set error
    return -1;
}
else if (is_null) {
    // handle missing string
    // sdata->buf is NULL
    // sdata->size is 0
}
else {
    // sdata->buf is a pointer to the beginning of a string
    // sdata->size is the size of the string
}
NpyString_release_allocator(allocator);

Упаковка строки#

В этом примере показано, как упаковать новую строковую запись в массив:

char *str = "Hello world";
size_t size = 11;
npy_packed_static_string *packed_string = (npy_packed_static_string *)buf;

npy_string_allocator *allocator = NpyString_acquire_allocator(
        (PyArray_StringDTypeObject *)descr);

// copy contents of str into packed_string
if (NpyString_pack(allocator, packed_string, str, size) == -1) {
    // string packing failed, set error
    return -1;
}

// packed_string contains a copy of "Hello world"

NpyString_release_allocator(allocator);

Типы#

type npy_packed_static_string#

Непрозрачная структура, представляющая «упакованные» закодированные строки. Отдельные записи в буферах массива являются экземплярами этой структуры. Прямой доступ к данным в структуре не определен, и будущая версия библиотеки может изменить упакованное представление строк.

type npy_static_string#

Неупакованная строка, позволяющая получить доступ к данным строки UTF-8.

typedef struct npy_unpacked_static_string {
    size_t size;
    const char *buf;
} npy_static_string;
size_t size#

Размер строки в байтах.

const char *buf#

Строковый буфер. Содержит байты в кодировке UTF-8. Сейчас он не завершается нулевым байтом, но в будущем такое завершение может быть добавлено, поэтому не следует полагаться ни на его наличие, ни на отсутствие.

Обратите внимание: это буфер const. Чтобы изменить элемент массива, нужно создать новую строку и упаковать её в этот элемент.

type npy_string_allocator#

Непрозрачный указатель на объект, управляющий выделением памяти для строк. Перед использованием аллокатора необходимо захватить его блокировку, а после завершения работы с управляемыми им строками — освободить её.

type PyArray_StringDTypeObject#

Структура C, лежащая в основе экземпляров StringDType в Python. Атрибуты хранят настройки, заданные при создании объекта; экземпляр npy_string_allocator, управляющий выделением памяти строк для массивов, связанных с этим DType; и кэшированные сведения об объекте, обозначающем пропущенную строку, которые часто нужны при приведении типов и в циклах ufunc.

typedef struct {
    PyArray_Descr base;
    PyObject *na_object;
    char coerce;
    char has_nan_na;
    char has_string_na;
    char array_owned;
    npy_static_string default_string;
    npy_static_string na_name;
    npy_string_allocator *allocator;
} PyArray_StringDTypeObject;
PyArray_Descr base#

Базовый объект. Через это поле доступны поля, общие для всех объектов-дескрипторов.

PyObject *na_object#

Ссылка на объект, представляющий значение null. Если такое значение не задано (по умолчанию), здесь будет NULL.

char coerce#

1, если включено приведение к строкам; иначе 0.

char has_nan_na#

1, если объект-маркер отсутствующих строковых значений (если он задан) ведёт себя как NaN; иначе 0.

char has_string_na#

1, если объект, обозначающий пропущенную строку (при его наличии), является строкой; иначе 0.

char array_owned#

1 если массиву принадлежит экземпляр StringDType, 0 иначе.

npy_static_string default_string#

Строка по умолчанию для операций. Если объект, обозначающий пропущенную строку, сам является строкой, здесь содержатся её строковые данные.

npy_static_string na_name#

Имя объекта пропущенной строки, если он есть; иначе пустая строка.

npy_string_allocator allocator#

Распределитель памяти, связанный с массивом, владеющим этим экземпляром дескриптора. Напрямую обращаться к распределителю можно только после захвата allocator_lock; блокировку нужно освободить сразу, как распределитель больше не нужен.

Функции #

npy_string_allocator *NpyString_acquire_allocator(const PyArray_StringDTypeObject *descr)#

Захватывает мьютекс аллокатора, связанного с descr. Для аллокатора, возвращённого этой функцией, необходимо вызвать NpyString_release_allocator ровно один раз. Пока мьютекс аллокатора удерживается, нельзя вызывать функции, требующие GIL: это может привести к взаимной блокировке.

void NpyString_acquire_allocators(size_t n_descriptors, PyArray_Descr *const descrs[], npy_string_allocator *allocators[])#

Одновременно захватывает мьютексы, блокирующие распределители памяти нескольких дескрипторов. Для каждого дескриптора StringDType записывает указатель на его распределитель в соответствующий элемент массива allocators. Если дескриптор не является экземпляром StringDType, в этот элемент allocators записывается NULL.

n_descriptors — число дескрипторов в массиве descrs, которые нужно проверить. Дескрипторы после первых n_descriptors элементов игнорируются. Если массив descrs содержит меньше n_descriptors элементов, произойдёт переполнение буфера.

Если указатели на один дескриптор переданы несколько раз, мьютекс аллокатора захватывается только один раз, но одинаковые указатели на аллокатор устанавливаются во всех нужных местах. После возврата мьютексы нужно освободить; см. NpyString_release_allocators.

Пока мьютекс аллокатора удерживается, нельзя вызывать функции, требующие GIL: это может привести к взаимной блокировке.

void NpyString_release_allocator(npy_string_allocator *allocator)#

Освобождает мьютекс распределителя памяти. Функцию необходимо вызвать ровно один раз после захвата мьютекса, когда завершены все операции, требующие этого распределителя.

Для освобождения нескольких распределителей используйте NpyString_release_allocators: при нескольких ссылках на один распределитель она корректно освобождает его только один раз.

void NpyString_release_allocators(size_t length, npy_string_allocator *allocators[])#

Освобождает мьютексы, блокирующие N объектов выделения памяти. length — длина массива этих объектов. Элементы NULL игнорируются.

Если указатели на один и тот же распределитель памяти переданы несколько раз, его мьютекс освобождается только один раз.

int NpyString_load(npy_string_allocator *allocator, const npy_packed_static_string *packed_string, npy_static_string *unpacked_string)#

Извлекает упакованное содержимое packed_string в unpacked_string.

unpacked_string — представление данных packed_string только для чтения; изменять через него строковые данные нельзя. Если packed_string является строкой со значением null, unpacked_string.buf устанавливается в NULL. Возвращает -1 при ошибке распаковки строки, 1, если packed_string — строка со значением null, и 0 в остальных случаях.

Полезный приём — создать в стеке экземпляр npy_static_string, инициализированный значением {0, NULL}, и передать в эту функцию указатель на выделенную в стеке распакованную строку. Функция позволяет одновременно распаковать строку и определить, является ли она null-строкой.

int NpyString_pack_null(npy_string_allocator *allocator, npy_packed_static_string *packed_string)#

Упаковывает отсутствующую строку (null string) в packed_string. Возвращает 0 при успехе и -1 при неудаче.

int NpyString_pack(npy_string_allocator *allocator, npy_packed_static_string *packed_string, const char *buf, size_t size)#

Копирует и упаковывает первые size элементов буфера, на который указывает buf, в packed_string. Возвращает 0 при успехе и -1 при ошибке.
