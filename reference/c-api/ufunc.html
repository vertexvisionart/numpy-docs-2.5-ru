Макросы#

NPY_LOOP_BEGIN_THREADS#

Используется в коде универсальных функций для освобождения GIL Python только при ложном loop->obj, то есть когда цикл не обрабатывает массив OBJECT. Требует NPY_BEGIN_THREADS_DEF в области объявления переменных.

NPY_LOOP_END_THREADS#

Используется в коде универсальных функций для повторного захвата GIL Python после освобождения, если loop->obj имел ложное значение.

Типы#

type PyUFuncGenericFunction#

Указатели на функции со следующей сигнатурой, которые выполняют базовую поэлементную операцию \(N\) раз:

void loopfunc(char **args, npy_intp const *dimensions, npy_intp const *steps, void *data)#
Параметры:

  • args – массив указателей на фактические данные для входных и выходных массивов. Сначала приводятся входные аргументы, а затем выходные аргументы.

  • dimensions — указатель на размер измерения, по которому эта функция выполняет цикл.

  • steps — указатель на числа байтов, на которые нужно сдвинуться для перехода к следующему элементу вдоль этого измерения для каждого входного и выходного аргумента.

  • данные –

    Произвольные данные (дополнительные аргументы, имена функций и т. д.), которые можно хранить вместе с универсальной функцией и передавать при её вызове. Допускается NULL.

    Изменено в версии 1.23.0: принимается NULL в качестве data, а также массив значений NULL.

Пример func, специализированной для сложения значений double с результатом double.

static void
double_add(char **args,
           npy_intp const *dimensions,
           npy_intp const *steps,
           void *extra)
{
    npy_intp i;
    npy_intp is1 = steps[0], is2 = steps[1];
    npy_intp os = steps[2], n = dimensions[0];
    char *i1 = args[0], *i2 = args[1], *op = args[2];
    for (i = 0; i < n; i++) {
        *((double *)op) = *((double *)i1) +
                          *((double *)i2);
        i1 += is1;
        i2 += is2;
        op += os;
     }
}

Функции #

PyObject *PyUFunc_FromFuncAndData(PyUFuncGenericFunction *func, void *const *data, const char *types, int ntypes, int nin, int nout, int identity, const char *name, const char *doc, int unused)#

Создаёт универсальную функцию с поддержкой трансляции массивов из необходимых переменных. Каждая ufunc основана на поэлементной операции. Объект ufunc содержит указатели на одномерные циклы, реализующие базовую операцию для каждого поддерживаемого типа.

Примечание

Аргументы func, data, types, name и doc не копируются функцией PyUFunc_FromFuncAndData. Вызывающая сторона должна гарантировать, что память этих массивов не освобождается, пока существует объект универсальной функции.

Параметры:

  • func — должен указывать на массив из ntypes элементов типа PyUFuncGenericFunction.

  • data — NULL либо указатель на массив размера ntypes. Массив может содержать произвольные дополнительные данные, включая NULL, передаваемые соответствующей функции цикла из массива func.

  • типы –

    Массив длины (nin + nout) * ntypes из элементов char, кодирующих numpy.dtype.num только для встроенных типов, принимаемых соответствующей функцией массива func. Например, для ufunc сравнения с тремя ntypes, двумя nin и одним nout, где первая функция принимает numpy.int32, вторая — numpy.int64 и обе возвращают numpy.bool_, массив types будет равен (char[]) {5, 5, 0, 7, 7, 0}, поскольку NPY_INT32 равен 5, NPY_INT64 — 7, а NPY_BOOL — 0. Примечание переводчика: в оригинале ошибочно указано три ntypes. В примере описаны два цикла и приведены шесть кодов типов: при nin=2 и nout=1 это соответствует ntypes=2.

    При желании можно использовать и имена с указанием разрядности, например NPY_INT32 и NPY_COMPLEX128.

    Во время выполнения правила приведения типов используются для поиска первой функции func, подходящей для заданных входов и выходов.

  • ntypes — сколько различных функций, специфичных для типа данных, реализовано в ufunc.

  • nin – количество входов в эту операцию.

  • nout – количество выходов

  • identity — одно из значений PyUFunc_One, PyUFunc_Zero, PyUFunc_MinusOne или PyUFunc_None. Задаёт результат метода reduce универсальной функции для пустого массива. Специальное значение PyUFunc_IdentityValue допускается только с PyUFunc_FromFuncAndDataAndSignatureAndIdentity и позволяет использовать произвольный объект Python как нейтральный элемент.

  • name — имя ufunc в виде строки, завершающейся NULL. Имена «add» и «multiply» включают особое поведение целочисленных свёрток, когда dtype не задан. Если входной тип — целочисленный (или логический) и занимает меньше памяти, чем numpy.int_, внутри он повышается до типа numpy.int_ (или numpy.uint).

  • doc — строка документации, сохраняемая в ufunc. Она не должна содержать имя функции и сигнатуру вызова: они определяются динамически по объекту и доступны при обращении к атрибуту __doc__ универсальной функции.

  • unused — не используется; сохранено для обратной совместимости C API.

PyObject *PyUFunc_FromFuncAndDataAndSignature(PyUFuncGenericFunction *func, void *const *data, const char *types, int ntypes, int nin, int nout, int identity, const char *name, const char *doc, int unused, const char *signature)#

Эта функция очень похожа на описанную выше PyUFunc_FromFuncAndData, но принимает дополнительный аргумент signature для определения обобщённой универсальной функции. Обычные ufunc строятся на поэлементной операции, а обобщённые ufunc — на операции над подмассивами. Сигнатура определяет, какие подмассивы участвуют в операции.

Параметры:

  • signature — сигнатура новой gufunc. Значение NULL эквивалентно вызову PyUFunc_FromFuncAndData. Строка копируется, поэтому переданный буфер можно освободить.

PyObject *PyUFunc_FromFuncAndDataAndSignatureAndIdentity(PyUFuncGenericFunction *func, void **data, char *types, int ntypes, int nin, int nout, int identity, char *name, char *doc, int unused, char *signature, PyObject *identity_value)#

Функция похожа на PyUFunc_FromFuncAndDataAndSignature выше, но имеет дополнительный аргумент identity_value для задания произвольного нейтрального элемента ufunc, если аргументу identity передано значение PyUFunc_IdentityValue.

Параметры:

  • identity_value — нейтральный элемент новой обобщённой универсальной функции. Необходимо передать NULL, если аргумент identity не равен PyUFunc_IdentityValue. Значение NULL эквивалентно вызову PyUFunc_FromFuncAndDataAndSignature.

int PyUFunc_RegisterLoopForType(PyUFuncObject *ufunc, int usertype, PyUFuncGenericFunction function, int *arg_types, void *data)#

Эта функция регистрирует одномерный цикл в уже созданной универсальной функции. Он будет использоваться, когда любой из её входных аргументов имеет пользовательский тип данных. Это нужно для работы универсальных функций с пользовательскими типами данных. Тип должен быть заранее зарегистрирован в NumPy. Цикл передаётся как function. Он может принимать произвольные данные, переданные через data. Требуемые циклу типы данных передаются через arg_types — указатель на массив, содержащий не менее ufunc->nargs элементов. Примечание переводчика: в оригинале ошибочно сказано «со встроенными типами данных»; функция предназначена для пользовательских типов. Размер arg_types следует понимать как число элементов int, а не байтов.

int PyUFunc_RegisterLoopForDescr(PyUFuncObject *ufunc, PyArray_Descr *userdtype, PyUFuncGenericFunction function, PyArray_Descr **arg_dtypes, void *data)#

Похожа на PyUFunc_RegisterLoopForType выше, но позволяет регистрировать одномерный цикл с объектами PyArray_Descr вместо числовых кодов dtype. Так можно регистрировать циклы для структурированных и пользовательских типов данных, а не только для скалярных.

int PyUFunc_ReplaceLoopBySignature(PyUFuncObject *ufunc, PyUFuncGenericFunction newfunc, int *signature, PyUFuncGenericFunction *oldfunc)#

Заменяет одномерный цикл, соответствующий заданной сигнатуре signature в уже созданной универсальной функции ufunc, новым одномерным циклом newfunc. Возвращает прежнюю функцию одномерного цикла через oldfunc. При успехе возвращает 0, при ошибке — -1. Работает только со встроенными типами; для пользовательских типов используйте PyUFunc_RegisterLoopForType. Сигнатура — массив номеров типов данных для входов и затем выходов, ожидаемых одномерным циклом.

void PyUFunc_clearfperr()#

Сбрасывает флаги ошибок IEEE.

Общие функции #

В основе каждой универсальной функции лежит набор функций для конкретных типов, определяющих базовую операцию для каждого поддерживаемого типа. Эти функции должны вычислить базовую операцию \(N\geq1\) раз. Можно передать дополнительные данные для использования при вычислении. Это позволяет применять некоторые универсальные по назначению функции как базовые функции циклов. Такая функция содержит весь код для установки указателей переменных на нужные позиции и подготовки вызова. Она предполагает, что фактически вызываемая функция передана как дополнительные данные, и вызывает её с правильными значениями. Все эти функции можно непосредственно помещать в массив функций, хранящийся в члене functions структуры PyUFuncObject.

void PyUFunc_f_f_As_d_d(char **args, npy_intp const *dimensions, npy_intp const *steps, void *func)#
void PyUFunc_d_d(char **args, npy_intp const *dimensions, npy_intp const *steps, void *func)#
void PyUFunc_f_f(char **args, npy_intp const *dimensions, npy_intp const *steps, void *func)#
void PyUFunc_g_g(char **args, npy_intp const *dimensions, npy_intp const *steps, void *func)#
void PyUFunc_F_F_As_D_D(char **args, npy_intp const *dimensions, npy_intp const *steps, void *func)#
void PyUFunc_F_F(char **args, npy_intp const *dimensions, npy_intp const *steps, void *func)#
void PyUFunc_D_D(char **args, npy_intp const *dimensions, npy_intp const *steps, void *func)#
void PyUFunc_G_G(char **args, npy_intp const *dimensions, npy_intp const *steps, void *func)#
void PyUFunc_e_e(char **args, npy_intp const *dimensions, npy_intp const *steps, void *func)#
void PyUFunc_e_e_As_f_f(char **args, npy_intp const *dimensions, npy_intp const *steps, void *func)#
void PyUFunc_e_e_As_d_d(char **args, npy_intp const *dimensions, npy_intp const *steps, void *func)#

Основные одномерные функции ufunc для конкретных типов, в которых каждое вычисление выполняется вызовом функции с одним входным аргументом и одним результатом. Эта функция передаётся через func. Буквы соответствуют символьным кодам поддерживаемых типов данных: e — half, f — float, d — double, g — long double, F — cfloat, D — cdouble, G — clongdouble. Аргумент func должен поддерживать ту же сигнатуру. Варианты _As_X_X работают с ndarray одного типа, но приводят значения для вызова функции с другим типом. Например, PyUFunc_f_f_As_d_d использует ndarray типа NPY_FLOAT, но вызывает функцию C, принимающую и возвращающую double.

void PyUFunc_ff_f_As_dd_d(char **args, npy_intp const *dimensions, npy_intp const *steps, void *func)#
void PyUFunc_ff_f(char **args, npy_intp const *dimensions, npy_intp const *steps, void *func)#
void PyUFunc_dd_d(char **args, npy_intp const *dimensions, npy_intp const *steps, void *func)#
void PyUFunc_gg_g(char **args, npy_intp const *dimensions, npy_intp const *steps, void *func)#
void PyUFunc_FF_F_As_DD_D(char **args, npy_intp const *dimensions, npy_intp const *steps, void *func)#
void PyUFunc_DD_D(char **args, npy_intp const *dimensions, npy_intp const *steps, void *func)#
void PyUFunc_FF_F(char **args, npy_intp const *dimensions, npy_intp const *steps, void *func)#
void PyUFunc_GG_G(char **args, npy_intp const *dimensions, npy_intp const *steps, void *func)#
void PyUFunc_ee_e(char **args, npy_intp const *dimensions, npy_intp const *steps, void *func)#
void PyUFunc_ee_e_As_ff_f(char **args, npy_intp const *dimensions, npy_intp const *steps, void *func)#
void PyUFunc_ee_e_As_dd_d(char **args, npy_intp const *dimensions, npy_intp const *steps, void *func)#

Базовые одномерные функции для конкретных типов данных, используемые в универсальных функциях, где каждый результат вычисляется вызовом функции с двумя входами и одним выходом. Вызываемая функция передаётся как func. Буквы соответствуют символьным кодам поддерживаемых типов данных. Аргумент func должен соответствовать нужной сигнатуре. Варианты _As_XX_X рассчитаны на ndarray одного типа, но на каждом шаге приводят значения к другому типу, принимаемому базовой функцией.

void PyUFunc_O_O(char **args, npy_intp const *dimensions, npy_intp const *steps, void *func)#
void PyUFunc_OO_O(char **args, npy_intp const *dimensions, npy_intp const *steps, void *func)#

Базовые одномерные функции для типа данных NPY_OBJECT с одним входом и одним выходом либо двумя входами и одним выходом. Они управляют счётчиками ссылок и немедленно завершаются при ошибке. Вызываемая функция — func; она должна поддерживать сигнатуру (PyObject*) (PyObject*) для PyUFunc_O_O либо (PyObject*)(PyObject *, PyObject *) для PyUFunc_OO_O.

void PyUFunc_O_O_method(char **args, npy_intp const *dimensions, npy_intp const *steps, void *func)#

Эта универсальная одномерная базовая функция предполагает, что func — строка с именем метода входного объекта. На каждом шаге цикла из массива извлекается объект Python и вызывается его метод func, результат которого помещается в выходной массив.

void PyUFunc_OO_O_method(char **args, npy_intp const *dimensions, npy_intp const *steps, void *func)#

Эта универсальная одномерная базовая функция предполагает, что func — строка с именем метода входного объекта, принимающего один аргумент. Первый аргумент в args задаёт объект, метод которого вызывается; второй аргумент в args передаётся этому методу. Результат сохраняется в третьем элементе args. Примечание переводчика: в оригинале первый аргумент назван методом; фактически он задаёт объект, у которого вызывается метод с именем func.

void PyUFunc_On_Om(char **args, npy_intp const *dimensions, npy_intp const *steps, void *func)#

Это одномерная базовая функция, используемая динамическими универсальными функциями, создаваемыми вызовом umath.frompyfunc(function, nin, nout). Здесь func — указатель на структуру PyUFunc_PyFuncData, определённую так:

type PyUFunc_PyFuncData#
typedef struct {
    int nin;
    int nout;
    PyObject *callable;
} PyUFunc_PyFuncData;

На каждом шаге цикла nin входных объектов извлекаются из объектных массивов и помещаются в кортеж аргументов. Вызывается объект Python callable с этими аргументами, а nout результатов помещаются в соответствующие объектные массивы.

Импорт API #

PY_UFUNC_UNIQUE_SYMBOL#
NO_IMPORT_UFUNC#
int PyUFunc_ImportUFuncAPI(void)#

Гарантирует, что C API универсальных функций импортирован и доступен. Возвращает 0 при успехе или -1 с установленным исключением, если NumPy не удалось импортировать. Предпочтительно вызвать функцию один раз при инициализации модуля, однако повторные вызовы почти не создают накладных расходов.

Добавлено в версии 2.0: функция в основном проверяет PyUFunc_API == NULL, поэтому при необходимости её можно вручную перенести в старые версии.

import_ufunc(void)#

Эти константы и функции обеспечивают доступ к C API ufunc из модулей расширения точно так же, как к C API массивов. Функцию import_ufunc () необходимо всегда вызывать в подпрограмме инициализации модуля расширения. Для модуля из одного файла этого достаточно. Две другие константы нужны, если модуль состоит из нескольких файлов. В таком случае задайте PY_UFUNC_UNIQUE_SYMBOL уникальное для вашего кода имя. В исходных файлах без функции инициализации модуля, которым нужен доступ к API UFUNC, задайте PY_UFUNC_UNIQUE_SYMBOL то же имя и также определите NO_IMPORT_UFUNC.

C API фактически представляет собой массив указателей на функции. Этот массив создаётся вызовом import_ufunc, а глобальная переменная указывает на него. В зависимости от PY_UFUNC_UNIQUE_SYMBOL и NO_IMPORT_UFUNC глобальная переменная либо имеет статическую область видимости, либо доступна другим файлам.
