numpy.broadcast#

class numpy.broadcast(*arrays)[source]#

Создаёт объект, моделирующий трансляцию массивов (согласование форм).

Параметры:
in1, in2, …array_like

Параметры ввода.

Атрибуты:
index

текущий индекс в результате трансляции массивов

iters

кортеж итераторов по «компонентам» self.

nd

Число измерений результата трансляции массивов.

ndim

Число измерений результата трансляции массивов.

numiter

Число итераторов, используемых результатом трансляции массивов.

shape

Форма результата трансляции массивов.

size

Общее число элементов результата трансляции массивов.

Методы

reset()

Возвращает итераторы результата трансляции массивов в начальное состояние.
Возвращаемые значения:
bОбъект broadcast

Согласует входные параметры по правилам трансляции массивов и возвращает объект, содержащий результат. Среди прочего, у него есть свойства shape и nd; его также можно использовать как итератор.

См. также

broadcast_arrays
broadcast_to
broadcast_shapes

Примеры

Ручное сложение двух векторов с использованием трансляции массивов:

>>> import numpy as np
>>> x = np.array([[1], [2], [3]])
>>> y = np.array([4, 5, 6])
>>> b = np.broadcast(x, y)

>>> out = np.empty(b.shape)
>>> out.flat = [u+v for (u,v) in b]
>>> out
array([[5.,  6.,  7.],
       [6.,  7.,  8.],
       [7.,  8.,  9.]])

Сравните со встроенной трансляцией массивов (согласованием форм):

>>> x + y
array([[5, 6, 7],
       [6, 7, 8],
       [7, 8, 9]])
