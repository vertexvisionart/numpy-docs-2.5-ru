numpy.char.chararray#

class numpy.char.chararray(shape, itemsize=1, unicode=False, buffer=None, offset=0, strides=None, order=None)[source]#

Предоставляет удобное представление массивов строковых значений и значений Unicode.

Устарело с версии 2.5: chararray объявлен устаревшим. Вместо него используйте ndarray со строковым или байтовым типом данных.

Примечание

Класс chararray существует для обратной совместимости с Numarray и не рекомендуется для нового кода. Начиная с NumPy 1.4 для массивов строк рекомендуется использовать массивы с dtype, равным object_, bytes_ или str_, а для быстрых векторизованных строковых операций — отдельные функции модуля numpy.char.

По сравнению с массивом NumPy типа bytes_ или str_ этот класс предоставляет следующие дополнительные возможности:

  1. при получении значения по индексу завершающие пробельные символы автоматически удаляются

  2. при сравнении значений операторы сравнения автоматически удаляют пробельные символы в конце

  3. векторизованные операции со строками доступны в виде методов (например, endswith) и инфиксных операторов (например, "+", "*", "%")

Массивы chararray следует создавать с помощью numpy.char.array или numpy.char.asarray, а не прямым вызовом этого конструктора.

Этот конструктор создает массив, используя buffer (с offset и strides), если это не None. Если buffer - None, то он создает новый массив с strides в «порядке C», если только len(shape) >= 2 и order='F', в этом случае strides находится в «порядке Fortran».

Параметры:
shape кортеж

Форма массива.

itemsizeint, необязательный

Длина каждого элемента массива, в количестве символов. По умолчанию 1.

unicodebool, необязательно

Имеют ли элементы массива тип unicode (True) или string (False). По умолчанию False.

bufferобъект с буферным интерфейсом или str, необязательный

Адрес памяти начала массива данных.По умолчанию None, в этом случае создается новый массив.

offsetint, необязательный

Фиксированное смещение от начала оси? По умолчанию 0. Должно быть >=0.

stridesобъект array_like из целых чисел, необязательно

Шаги массива; полное описание см. в strides. По умолчанию None.

order{'C', 'F'}, необязательно

Порядок хранения данных массива в памяти: «C» — по строкам (по умолчанию), «F» — по столбцам (порядок Fortran).

fill(value)

Заполняет массив скалярным значением.

Для каждого элемента возвращает наименьший индекс в строке, где найдена подстрока sub.

flatten([order])

Возвращает копию массива, развёрнутую в одномерную.

getfield(dtype[, offset])

Возвращает поле заданного массива в виде указанного типа.

index(sub[, start, end])

Аналогична find, но возбуждает ValueError, если подстрока не найдена.

isalnum()

Для каждого элемента возвращает истину, если строка непуста и все её символы — буквы или цифры; иначе возвращает ложь.

isalpha()

Для каждого элемента возвращает true, если строка непустая и все её символы — буквы; иначе false.

isdecimal()

Для каждого элемента self возвращает True, если он состоит только из десятичных цифр.

isdigit()

Для каждого элемента возвращает true, если строка непустая и все её символы являются цифрами; иначе false.

islower()

Для каждого элемента возвращает True, если все символы строки, имеющие регистр, строчные и имеется хотя бы один такой символ; иначе возвращает False.

isnumeric()

Для каждого элемента в self возвращайте True, если в элементе есть только числовые символы.

isspace()

Для каждого элемента возвращает true, если строка непустая и состоит только из пробельных символов; иначе false.

istitle()

Для каждого элемента возвращает true, если строка непустая и имеет заглавный регистр слов (title case), иначе false.

isupper()

Для каждого элемента возвращает true, если все символы строки, имеющие регистр, прописные и есть хотя бы один такой символ; иначе false. Примечание переводчика: в оригинале условие существования хотя бы одного символа не уточняет, что этот символ должен иметь регистр. Строка из одних цифр даёт false.

item(*args)

Копирует элемент массива в стандартный скаляр Python и возвращает его.

Возвращает строку, полученную соединением строк из последовательности seq.

Возвращает массив со строками из self, выровненными по левому краю в строке длины width.

Возвращает массив с элементами self в нижнем регистре.

nonzero()

Возвращает индексы ненулевых элементов.

put(indices, values[, mode])

Выполняет a.flat[n] = values[n] для каждого n из indices.

ravel([order])

Возвращает массив, развёрнутый в одномерный.

repeat(repeats[, axis])

Повторяет элементы массива.

replace(old, new[, count])

Для каждого элемента в self верните копию строки со всеми встречающимися подстроками old, замененными new.

reshape(a.reshape)

Возвращает массив, содержащий те же данные, с новой формой.

resize(a.resize)

Изменяет форму и размер массива на месте.

rfind(sub[, start, end])

Для каждого элемента self возвращает наибольший индекс вхождения подстроки sub, при котором sub целиком содержится в диапазоне [start, end]. Примечание переводчика: правая граница end в действительности исключается, как в срезах Python; правильная запись диапазона — [start, end).

rindex(sub[, start, end])

Как rfind, но вызывает ValueError, если подстрока sub не найдена.

rjust(width[, fillchar])

Возвращает массив, в котором элементы self выровнены по правому краю в строках длины width.

rsplit([sep, maxsplit])

Для каждого элемента self возвращает список слов строки, используя sep как строку-разделитель.

rstrip([chars])

Для каждого элемента self возвращает копию с удалёнными символами в конце.

searchsorted(v[, side, sorter])

Находит индексы, по которым следует вставить элементы v в a, чтобы сохранить порядок.

setfield(val, dtype[, offset])

Поместите значение в указанное место в поле, определенном типом данных.

setflags([write, align, uic])

Устанавливает флаги массива WRITEABLE, ALIGNED и WRITEBACKIFCOPY соответственно.

sort([axis, kind, order, stable, descending])

Сортирует массив на месте.

split([sep, maxsplit])

Для каждого элемента self возвращает список слов строки, используя sep как строку-разделитель.

splitlines([keepends])

Для каждого элемента self возвращает список его строк, разделяя текст по границам строк.

squeeze([axis])

Удаляет из a оси длины 1.

startswith(prefix[, start, end])

Возвращает логический массив со значением True там, где строковый элемент self начинается с prefix, и False в остальных позициях.

strip([chars])

Для каждого элемента self возвращает копию с удалёнными начальными и конечными символами.

swapaxes(axis1, axis2, /)

Возвращает представление массива с переставленными осями axis1 и axis2.

swapcase()

Для каждого элемента self возвращает копию строки, в которой прописные буквы заменены строчными, а строчные — прописными.

take(indices[, axis, out, mode])

Возвращает массив из элементов a с заданными индексами.

title()

Для каждого элемента self возвращает строку, в которой каждое слово начинается с заглавной буквы, а все остальные буквы приведены к нижнему регистру.

tofile(fid, /[, sep, format])

Запишите массив в файл в виде текста или двоичного файла (по умолчанию).

tolist()

Возвращает массив в виде вложенного списка скаляров Python с глубиной вложенности a.ndim.

Для каждого элемента self возвращает копию строки: символы, перечисленные в необязательном аргументе deletechars, удаляются, а остальные заменяются по заданной таблице преобразования.

Возвращает представление массива с транспонированными осями.

upper()

Возвращает массив с элементами self, преобразованными в верхний регистр.

view([dtype][, type])

Новое представление массива с теми же данными.

zfill(width)

Возвращает числовую строку длины width, дополненную нулями слева.

Примеры

>>> import numpy as np
>>> charar = np.char.chararray((3, 3))
>>> charar[:] = 'a'
>>> charar
chararray([[b'a', b'a', b'a'],
           [b'a', b'a', b'a'],
           [b'a', b'a', b'a']], dtype='|S1')

>>> charar = np.char.chararray(charar.shape, itemsize=5)
>>> charar[:] = 'abc'
>>> charar
chararray([[b'abc', b'abc', b'abc'],
           [b'abc', b'abc', b'abc'],
           [b'abc', b'abc', b'abc']], dtype='|S5')
