numpy.dtype#

class numpy.dtype(dtype, align=False, copy=False, **kwargs)[source]#

–

dtype(dtype, align=False, copy=False, [metadata])

Создаёт объект типа данных.

Массив NumPy однороден и содержит элементы, описываемые объектом dtype. Объект dtype можно создать из разных комбинаций базовых числовых типов.

Параметры:
dtype

Объект для преобразования в объект типа данных.

alignbool, необязательно

Добавляет промежутки между полями, чтобы расположение данных соответствовало аналогичной структуре C, создаваемой компилятором. Значение True допустимо, только если obj — словарь или строка со значениями через запятую. При создании структурированного dtype также устанавливается сохраняемый флаг выравнивания isalignedstruct.

copybool, необязательно

Создайте новую копию объекта типа данных. Если False , результатом может быть просто ссылка на встроенный объект типа данных.

metadataсловарь, необязательный

Дополнительный словарь с метаданными dtype.

Атрибуты:
alignment

Выравнивание этого типа данных в байтах, требуемое компилятором.

base

Возвращает dtype базового элемента подмассивов независимо от их числа измерений и формы.

byteorder

Символ, указывающий порядок байтов этого объекта типа данных.

char

Уникальный символьный код для каждого из 21 встроенного типа.

descr

Описание типа данных в формате __array_interface__.

fields

Словарь названных полей, определенных для данного типа данных, или None.

flags

Бит-флаги, описывающие, как следует интерпретировать этот тип данных.

hasobject

Логическое значение, указывающее, содержит ли этот dtype объекты с подсчётом ссылок в каких-либо полях или вложенных типах.

isalignedstruct

Логическое значение, указывающее, является ли dtype структурой с соблюдением выравнивания полей.

isbuiltin

Целое число, указывающее, как этот dtype относится к встроенным типам.

isnative

Логическое значение, показывающее, совпадает ли порядок байтов этого dtype с системным.

itemsize

Размер элемента этого объекта типа данных.

kind

Символьный код (один из символов «biufcmMOSTUV»), обозначающий общий вид данных.

metadata

Либо None, либо доступный только для чтения словарь метаданных (mappingproxy).

name

Имя этого типа данных с указанием разрядности.

names

Упорядоченный список имен полей или None, если полей нет.

ndim

Число измерений подмассива, если этот тип данных описывает подмассив, и 0 в противном случае.

num

Уникальный номер каждого из 21 встроенного типа.

shape

Кортеж формы подмассива, если этот тип данных описывает подмассив; иначе ().

str

Строка описания этого типа данных в протоколе массивов.

subdtype

Кортеж (item_dtype, shape), если этот dtype описывает подмассив; иначе None.

тип

Методы

newbyteorder([new_order])

Возврат нового dtype с другим байт-порядком.

См. также

result_type

Примеры

Использование скалярного типа массива:

>>> import numpy as np
>>> np.dtype(np.int16)
dtype('int16')

Структурированный тип с одним полем «f1», содержащим int16:

>>> np.dtype([('f1', np.int16)])
dtype([('f1', '<i2')])

Структурированный тип с одним полем «f1», которое само содержит структурированный тип с одним полем:

>>> np.dtype([('f1', [('f1', np.int16)])])
dtype([('f1', [('f1', '<i2')])])

Структурированный тип с двумя полями: первое содержит беззнаковый int, второе — int32:

>>> np.dtype([('f1', np.uint64), ('f2', np.int32)])
dtype([('f1', '<u8'), ('f2', '<i4')])

Использование строк типов из протокола массива:

>>> np.dtype([('a','f8'),('b','S10')])
dtype([('a', '<f8'), ('b', 'S10')])

Использование форматов полей, разделенных запятыми. Форма (2,3):

>>> np.dtype("i4, (2,3)f8")
dtype([('f0', '<i4'), ('f1', '<f8', (2, 3))])

Использование кортежей. int — тип фиксированного размера, а 3 — форма поля. void — тип переменного размера, здесь размер равен 10:

>>> np.dtype([('hello',(np.int64,3)),('world',np.void,10)])
dtype([('hello', '<i8', (3,)), ('world', 'V10')])

Разделим int16 на два int8 с именами x и y. 0 и 1 — смещения в байтах:

>>> np.dtype((np.int16, {'x':(np.int8,0), 'y':(np.int8,1)}))
dtype((numpy.int16, [('x', 'i1'), ('y', 'i1')]))

Использование словарей. Два поля с именами «gender» и «age»:

>>> np.dtype({'names':['gender','age'], 'formats':['S1',np.uint8]})
dtype([('gender', 'S1'), ('age', 'u1')])

Смещения в байтах, в данном случае 0 и 25:

>>> np.dtype({'surname':('S25',0),'age':(np.uint8,25)})
dtype([('surname', 'S25'), ('age', 'u1')])
