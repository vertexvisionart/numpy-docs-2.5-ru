numpy.fft.fft#

fft.fft(a, n=None, axis=-1, norm=None, out=None)[source]#

Вычисляет одномерное дискретное преобразование Фурье.

Вычисляет одномерное дискретное преобразование Фурье (ДПФ) по n точкам с помощью эффективного алгоритма быстрого преобразования Фурье (БПФ) [CT].

Параметры:
aarray_like

Входной массив; может быть комплексным.

nint, необязательный

Длина преобразованной оси вывода. Если n меньше длины ввода, ввод обрезается. Если оно больше, входные данные дополняются нулями. Если n не указан, используется длина ввода вдоль оси, указанной axis.

axisint, необязательный

Ось, по которой вычисляется БПФ. Если не указано, используется последняя ось.

norm {"backward", "ortho", "forward"}, опциональный

Режим нормировки (см. numpy.fft). По умолчанию “backward”. Определяет, какое из прямого и обратного преобразований масштабируется и с каким нормирующим коэффициентом.

Добавлено в версии 1.20.0: добавлены значения “backward” и “forward”.

outкомплексный ndarray, необязательно

Если массив задан, результат помещается в него. Массив должен иметь подходящие форму и dtype.

Добавлено в версии 2.0.0.

Возвращаемые значения:
outкомплексный ndarray

Результат преобразования входного массива, усечённого или дополненного нулями, вдоль оси axis; если axis не задан, используется последняя ось.

Исключения:
IndexError

Если axis не является допустимой осью a.

См. также

numpy.fft

где приведены определение ДПФ и принятые соглашения.

ifft

Обратное преобразование для fft.

fft2

Двумерное БПФ.

fftn

n-мерное БПФ.

rfftn

n-мерное БПФ вещественных входных данных.

fftfreq

Частотные отсчёты для заданных параметров БПФ.

Примечания

БПФ (быстрое преобразование Фурье) — способ эффективного вычисления дискретного преобразования Фурье (ДПФ), использующий симметрии вычисляемых членов. Симметрия максимальна, когда n — степень двойки, поэтому преобразование наиболее эффективно для таких размеров.

Определение ДПФ с соглашениями, принятыми в этой реализации, приведено в документации модуля numpy.fft.

Источники

[CT]

Cooley, James W., and John W. Tukey, 1965, “An algorithm for the machine calculation of complex Fourier series” («Алгоритм машинного вычисления комплексных рядов Фурье»), Math. Comput. 19: 297-301.

Примеры

>>> import numpy as np
>>> np.fft.fft(np.exp(2j * np.pi * np.arange(8) / 8))
array([-2.33486982e-16+1.14423775e-17j,  8.00000000e+00-1.25557246e-15j,
        2.33486982e-16+2.33486982e-16j,  0.00000000e+00+1.22464680e-16j,
       -1.14423775e-17+2.33486982e-16j,  0.00000000e+00+5.20784380e-16j,
        1.14423775e-17+1.14423775e-17j,  0.00000000e+00+1.22464680e-16j])

В этом примере БПФ вещественных входных данных обладает эрмитовой симметрией: вещественная часть симметрична, а мнимая — антисимметрична, как описано в документации numpy.fft:

>>> import matplotlib.pyplot as plt
>>> t = np.arange(256)
>>> sp = np.fft.fft(np.sin(t))
>>> freq = np.fft.fftfreq(t.shape[-1])
>>> _ = plt.plot(freq, sp.real, freq, sp.imag)
>>> plt.show()
