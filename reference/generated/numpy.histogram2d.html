numpy.histogram2d#

numpy.histogram2d(x, y, bins=10, range=None, density=None, weights=None)[source]#

Вычисляет двумерную гистограмму двух выборок данных.

Параметры:
xarray_like формы (N,)

Массив, содержащий координаты x точек, подлежащих гистограммированию.

yarray_like формы (N,)

Массив, содержащий координаты y точек, подлежащих гистограммированию.

binsint, array_like, [int, int] или [array, array], необязательно

Задание интервалов:

  • Если это int, он задаёт число интервалов для обоих измерений (nx=ny=bins).

  • Если array_like, задаёт границы интервалов для обоих измерений (x_edges=y_edges=bins).

  • Если задано [int, int], это число интервалов по каждому измерению (nx, ny = bins).

  • Если [array, array], задаёт границы интервалов по каждому измерению (x_edges, y_edges = bins).

  • Сочетание [int, array] или [array, int], где int — число интервалов, а array — их границы.

rangeобъект типа array_like, форма (2, 2), необязательный

Крайняя левая и крайняя правая границы интервалов вдоль каждого измерения, если они не заданы явно параметрами bins: [[xmin, xmax], [ymin, ymax]]. Значения за пределами этих диапазонов считаются выбросами и не учитываются в гистограмме.

densitybool, необязательно

Если задано False (по умолчанию), возвращает число наблюдений в каждом интервале. Если задано True, возвращает значение функции плотности вероятности для интервала: bin_count / sample_count / bin_area.

weightsarray_like, форма (N,), необязательный параметр

Массив значений w_i, взвешивающий каждую выборку (x_i, y_i). Веса нормализуются до 1, если density равен True. Если density равен False, значения возвращаемой гистограммы равны сумме весов, принадлежащих выборкам, попадающим в каждый интервал.

Возвращаемые значения:
H ndarray, форма (nx, ny)

Двумерная гистограмма выборок x и y. Значения x группируются по интервалам первого измерения, а y — второго.

xedgesndarray, форма (nx+1,)

Границы интервалов вдоль первого измерения.

yedgesndarray формы (ny+1,)

Границы интервалов вдоль второго измерения.

См. также

histogram

Одномерная гистограмма

histogramdd

Многомерная гистограмма

Примечания

Когда density равен True , возвращаемая гистограмма представляет собой плотность выборки, определенную так, что сумма по интервалам произведения bin_value * bin_area равна 1.

Гистограмма не следует декартову соглашению, где x откладывается по оси абсцисс, а y — по оси ординат. Вместо этого x группируется вдоль первого, вертикального измерения массива, а y — вдоль второго, горизонтального. Это обеспечивает совместимость с histogramdd.

Примеры

>>> import numpy as np
>>> from matplotlib.image import NonUniformImage
>>> import matplotlib.pyplot as plt

Строим двумерную гистограмму с переменной шириной интервалов. Сначала задаём их границы:

>>> xedges = [0, 1, 3, 5]
>>> yedges = [0, 2, 3, 4, 6]

Затем создадим гистограмму H со случайными значениями в интервалах:

>>> x = np.random.normal(2, 1, 100)
>>> y = np.random.normal(1, 1, 100)
>>> H, xedges, yedges = np.histogram2d(x, y, bins=(xedges, yedges))
>>> # Histogram does not follow Cartesian convention (see Notes),
>>> # therefore transpose H for visualization purposes.
>>> H = H.T
Комментарии к примеру на русском
  • Гистограмма не следует декартову соглашению (см. примечания),
  • поэтому для визуализации транспонируем H.

В приведённом примере imshow показывает ячейки как квадратные. Примечание переводчика: утверждение оригинала «может отображать только квадратные ячейки» слишком узко. imshow отображает регулярную растровую сетку; размеры ячеек по горизонтали и вертикали можно менять через extent и aspect. Для произвольных неравномерных границ ячеек нужен другой способ отображения:

>>> fig = plt.figure(figsize=(7, 3))
>>> ax = fig.add_subplot(131, title='imshow: square bins')
>>> plt.imshow(H, interpolation='nearest', origin='lower',
...         extent=[xedges[0], xedges[-1], yedges[0], yedges[-1]])
<matplotlib.image.AxesImage object at 0x...>

pcolormesh может отображать фактические границы ячеек:

>>> ax = fig.add_subplot(132, title='pcolormesh: actual edges',
...         aspect='equal')
>>> X, Y = np.meshgrid(xedges, yedges)
>>> ax.pcolormesh(X, Y, H)
<matplotlib.collections.QuadMesh object at 0x...>

NonUniformImage позволяет отображать фактические границы интервалов с интерполяцией:

>>> ax = fig.add_subplot(133, title='NonUniformImage: interpolated',
...         aspect='equal', xlim=xedges[[0, -1]], ylim=yedges[[0, -1]])
>>> im = NonUniformImage(ax, interpolation='bilinear')
>>> xcenters = (xedges[:-1] + xedges[1:]) / 2
>>> ycenters = (yedges[:-1] + yedges[1:]) / 2
>>> im.set_data(xcenters, ycenters, H)
>>> ax.add_image(im)
>>> plt.show()

Можно также построить двумерную гистограмму без явного задания границ интервалов:

>>> # Generate non-symmetric test data
>>> n = 10000
>>> x = np.linspace(1, 100, n)
>>> y = 2*np.log(x) + np.random.rand(n) - 0.5
>>> # Compute 2d histogram. Note the order of x/y and xedges/yedges
>>> H, yedges, xedges = np.histogram2d(y, x, bins=20)
Комментарии к примеру на русском
  • Создаём несимметричные тестовые данные
  • Вычисляем двумерную гистограмму. Обратите внимание на порядок x/y и xedges/yedges

Теперь мы можем построить гистограмму с использованием pcolormesh и hexbin для сравнения.

>>> # Plot histogram using pcolormesh
>>> fig, (ax1, ax2) = plt.subplots(ncols=2, sharey=True)
>>> ax1.pcolormesh(xedges, yedges, H, cmap='rainbow')
>>> ax1.plot(x, 2*np.log(x), 'k-')
>>> ax1.set_xlim(x.min(), x.max())
>>> ax1.set_ylim(y.min(), y.max())
>>> ax1.set_xlabel('x')
>>> ax1.set_ylabel('y')
>>> ax1.set_title('histogram2d')
>>> ax1.grid()
Комментарии к примеру на русском
  • Строим гистограмму с помощью pcolormesh
>>> # Create hexbin plot for comparison
>>> ax2.hexbin(x, y, gridsize=20, cmap='rainbow')
>>> ax2.plot(x, 2*np.log(x), 'k-')
>>> ax2.set_title('hexbin')
>>> ax2.set_xlim(x.min(), x.max())
>>> ax2.set_xlabel('x')
>>> ax2.grid()
Комментарии к примеру на русском
  • Для сравнения строим диаграмму hexbin
>>> plt.show()
