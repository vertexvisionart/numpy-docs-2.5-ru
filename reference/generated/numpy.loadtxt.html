numpy.loadtxt#

numpy.loadtxt(fname, dtype=<class 'float'>, comments='#', delimiter=None, converters=None, skiprows=0, usecols=None, unpack=False, ndmin=0, encoding=None, max_rows=None, *, quotechar=None, like=None)[source]#

Загрузка данных из текстового файла.

Параметры:
fname файл, строка, pathlib.Path , список строк, генератор

Файл, имя файла, список или генератор для чтения. Если расширение файла — .gz или .bz2, он сначала распаковывается. Генераторы должны возвращать байтовые строки или строки. Элементы списка или строки, выдаваемые генератором, рассматриваются как строки входного текста.

dtypeтип данных, необязательный параметр

Тип данных результирующего массива; по умолчанию: float. Если это структурированный тип данных, результирующий массив будет 1-мерным, и каждая строка будет интерпретироваться как элемент массива. В этом случае количество используемых столбцов должно соответствовать количеству полей в типе данных.

commentsstr, последовательность str или None, необязательный

Символ или список символов, обозначающих начало комментария. None означает отсутствие комментариев. Для обратной совместимости байтовые строки декодируются как latin1. Значение по умолчанию — #.

delimiterstr, необязательно

Символ-разделитель значений. Для обратной совместимости байтовые строки декодируются как latin1. По умолчанию разделителями служат пробельные символы.

Изменено в версии 1.23.0: Поддерживаются только односимвольные разделители. Символы перевода строки нельзя использовать как разделитель.

convertersdict или вызываемый объект, необязательный

Функции преобразования для настройки разбора значений. Если converters — вызываемый объект, он применяется ко всем столбцам. Иначе это должен быть словарь, сопоставляющий номеру столбца функцию разбора. Подробнее см. примеры. По умолчанию None.

Изменено в версии 1.23.0: Добавлена возможность передать один вызываемый объект для применения ко всем столбцам.

skiprowsint, необязательный

Пропустите первые строки skiprows, включая комментарии; по умолчанию: 0.

usecols int или последовательность, необязательный

Какие столбцы читать, где 0 — первый. Например, usecols = (1,4,5) извлечет 2-й, 5-й и 6-й столбцы. Значение по умолчанию, None, приводит к чтению всех столбцов.

unpackbool, необязательно

При True возвращаемый массив транспонируется, чтобы его можно было распаковать как x, y, z = loadtxt(...). Для структурированного типа данных возвращается по массиву на каждое поле. По умолчанию False.

ndminint, необязательный

Возвращаемый массив имеет не менее ndmin измерений. Если это ограничение позволяет, оси единичной длины удаляются. Допустимые значения: 0 (по умолчанию), 1 или 2.

encodingstr, необязательно

Кодировка для декодирования входного файла. Не применяется к входным потокам. Специальное значение ‘bytes’ включает обходные механизмы обратной совместимости: по возможности результатом будут байтовые массивы, а преобразователям передаются строки в кодировке ‘latin1’. Измените это значение, чтобы получать массивы Unicode и передавать преобразователям строки. При None используется системная кодировка по умолчанию. Значение по умолчанию — None.

Изменено в версии 2.0: До NumPy 2 значением по умолчанию было 'bytes' для совместимости с Python 2. Теперь значение по умолчанию — None.

max_rowsint, необязательный

Прочитать max_rows строк данных после skiprows строк. По умолчанию читаются все строки. Строки без данных, например пустые строки и комментарии, не учитываются в max_rows, но учитываются в skiprows.

Изменено в версии 1.23.0: Строки без данных, включая комментарии (например, строки, начинающиеся с «#» или с символа, заданного через comments), не учитываются в max_rows.

quotecharсимвол Unicode или None, необязательный

Символ, обозначающий начало и конец элемента в кавычках. Внутри такого элемента разделители и символы начала комментария не имеют специального значения. По умолчанию quotechar=None: поддержка кавычек отключена.

Если внутри поля в кавычках встречаются два последовательных символа quotechar, первый считается символом экранирования. См. примеры.

Добавлено в версии 1.23.0.

likearray_like, необязательный параметр

Объект-образец, позволяющий создавать массивы других библиотек. Если объект, подобный массиву, переданный как like, поддерживает протокол __array_function__, результат определяется этим протоколом. В таком случае создаётся объект массива, совместимый с переданным образцом.

Добавлено в версии 1.20.0.

Возвращаемые значения:
outndarray

Данные, прочитанные из текстового файла.

См. также

load, fromstring, fromregex
genfromtxt

Загружает данные, обрабатывая пропущенные значения указанным способом.

Примечания

Эта функция предназначена для быстрого чтения файлов с простым форматом. Функция genfromtxt предоставляет более развитую обработку, например строк с пропущенными значениями.

Чтобы прочитать все значения, каждая строка входного текстового файла должна содержать одинаковое число значений. Если это не так, можно прочитать до n столбцов, указав их через usecols, где n — минимальное число значений среди всех строк.

Строки, созданные методом Python float.hex, можно использовать в качестве входных данных для чисел с плавающей запятой.

Примеры

>>> import numpy as np
>>> from io import StringIO   # StringIO behaves like a file object
>>> c = StringIO("0 1\n2 3")
>>> np.loadtxt(c)
array([[0., 1.],
       [2., 3.]])
Комментарии к примеру на русском
  • StringIO ведёт себя как файловый объект
>>> d = StringIO("M 21 72\nF 35 58")
>>> np.loadtxt(d, dtype={'names': ('gender', 'age', 'weight'),
...                      'formats': ('S1', 'i4', 'f4')})
array([(b'M', 21, 72.), (b'F', 35, 58.)],
      dtype=[('gender', 'S1'), ('age', '<i4'), ('weight', '<f4')])

>>> c = StringIO("1,0,2\n3,0,4")
>>> x, y = np.loadtxt(c, delimiter=',', usecols=(0, 2), unpack=True)
>>> x
array([1., 3.])
>>> y
array([2., 4.])

Аргумент converters задаёт функции предварительной обработки текста перед его разбором. converters может быть словарём, сопоставляющим каждому столбцу функцию предварительной обработки:

>>> s = StringIO("1.618, 2.296\n3.141, 4.669\n")
>>> conv = {
...     0: lambda x: np.floor(float(x)),  # conversion fn for column 0
...     1: lambda x: np.ceil(float(x)),  # conversion fn for column 1
... }
>>> np.loadtxt(s, delimiter=",", converters=conv)
array([[1., 3.],
       [3., 5.]])
Комментарии к примеру на русском
  • Функция преобразования столбца 0
  • Функция преобразования столбца 1

converters может быть вызываемым объектом вместо словаря, и в этом случае он применяется ко всем столбцам:

>>> s = StringIO("0xDE 0xAD\n0xC0 0xDE")
>>> import functools
>>> conv = functools.partial(int, base=16)
>>> np.loadtxt(s, converters=conv)
array([[222., 173.],
       [192., 222.]])

В этом примере converters используется для преобразования поля со знаком минус в конце в отрицательное число.

>>> s = StringIO("10.01 31.25-\n19.22 64.31\n17.57- 63.94")
>>> def conv(fld):
...     return -float(fld[:-1]) if fld.endswith("-") else float(fld)
...
>>> np.loadtxt(s, converters=conv)
array([[ 10.01, -31.25],
       [ 19.22,  64.31],
       [-17.57,  63.94]])

Вызываемый объект в качестве преобразователя особенно полезен для значений в разных форматах, например чисел с плавающей точкой, содержащих подчёркивания:

>>> s = StringIO("1 2.7 100_000")
>>> np.loadtxt(s, converters=float)
array([1.e+00, 2.7e+00, 1.e+05])

Эта идея может быть расширена для автоматической обработки значений, заданных во многих различных форматах, таких как шестнадцатеричные значения:

>>> def conv(val):
...     try:
...         return float(val)
...     except ValueError:
...         return float.fromhex(val)
>>> s = StringIO("1, 2.5, 3_000, 0b4, 0x1.4000000000000p+2")
>>> np.loadtxt(s, delimiter=",", converters=conv)
array([1.0e+00, 2.5e+00, 3.0e+03, 1.8e+02, 5.0e+00])

Или формат, в котором знак - стоит после числа:

>>> s = StringIO("10.01 31.25-\n19.22 64.31\n17.57- 63.94")
>>> conv = lambda x: -float(x[:-1]) if x.endswith("-") else float(x)
>>> np.loadtxt(s, converters=conv)
array([[ 10.01, -31.25],
       [ 19.22,  64.31],
       [-17.57,  63.94]])

Поддержка полей в кавычках включается параметром quotechar. Символы комментария и разделителя игнорируются внутри поля, заключённого в кавычки quotechar:

>>> s = StringIO('"alpha, #42", 10.0\n"beta, #64", 2.0\n')
>>> dtype = np.dtype([("label", "U12"), ("value", float)])
>>> np.loadtxt(s, dtype=dtype, delimiter=",", quotechar='"')
array([('alpha, #42', 10.), ('beta, #64',  2.)],
      dtype=[('label', '<U12'), ('value', '<f8')])

Поля в кавычках могут разделяться несколькими пробельными символами:

>>> s = StringIO('"alpha, #42"       10.0\n"beta, #64" 2.0\n')
>>> dtype = np.dtype([("label", "U12"), ("value", float)])
>>> np.loadtxt(s, dtype=dtype, delimiter=None, quotechar='"')
array([('alpha, #42', 10.), ('beta, #64',  2.)],
      dtype=[('label', '<U12'), ('value', '<f8')])

Два последовательных символа кавычек внутри поля в кавычках интерпретируются как один экранированный символ:

>>> s = StringIO('"Hello, my name is ""Monty""!"')
>>> np.loadtxt(s, dtype=np.str_, delimiter=",", quotechar='"')
array('Hello, my name is "Monty"!', dtype='<U26')

Чтение части столбцов, если строки содержат разное число значений:

>>> d = StringIO("1 2\n2 4\n3 9 12\n4 16 20")
>>> np.loadtxt(d, usecols=(0, 1))
array([[ 1.,  2.],
       [ 2.,  4.],
       [ 3.,  9.],
       [ 4., 16.]])
