numpy.ma.masked_array.sort#

метод

ma.masked_array.sort(axis=-1, kind=None, order=None, endwith=True, fill_value=None, *, stable=False, descending=False)[source]#

Сортировать массив, на месте

Параметры:
aarray_like

Массив для сортировки.

axisint, необязательный

Ось сортировки. Если None, перед сортировкой массив разворачивается в одномерный. По умолчанию -1: сортировка вдоль последней оси.

kind{‘quicksort’, ‘mergesort’, ‘heapsort’, ‘stable’}, необязательный параметр

Используемый алгоритм сортировки.

orderсписок, необязательный

Если a является структурированным массивом, этот аргумент указывает, какие поля сравниваются первыми, вторыми и т. д. Этот список не обязательно должен включать все поля.

endwith{True, False}, необязательный

Считать ли пропущенные значения, если они есть, наибольшими (True) или наименьшими (False). Если массив содержит немаскированные значения, которые при сортировке занимают те же крайние позиции типа данных, их порядок относительно замаскированных значений не определён.

fill_valueскаляр или None, необязательный

Значение, используемое внутри для замаскированных значений.Если fill_value не является None, то он заменяет endwith.

stablebool, необязательно

Только для совместимости с np.sort. Игнорируется.

descendingbool, необязательно

Только для совместимости с np.sort. Игнорируется.

См. также

numpy.ndarray.sort

Метод сортировки массива на месте.

argsort

Косвенная сортировка.

lexsort

Косвенная устойчивая сортировка по нескольким ключам.

searchsorted

Находит элементы в отсортированном массиве.

Примечания

Сведения о различных алгоритмах сортировки см. в sort.

Примеры

>>> import numpy as np
>>> a = np.ma.array([1, 2, 5, 4, 3],mask=[0, 1, 0, 1, 0])
>>> # Default
>>> a.sort()
>>> a
masked_array(data=[1, 3, 5, --, --],
             mask=[False, False, False,  True,  True],
       fill_value=999999)
Комментарии к примеру на русском
  • По умолчанию
>>> a = np.ma.array([1, 2, 5, 4, 3],mask=[0, 1, 0, 1, 0])
>>> # Put missing values in the front
>>> a.sort(endwith=False)
>>> a
masked_array(data=[--, --, 1, 3, 5],
             mask=[ True,  True, False, False, False],
       fill_value=999999)
Комментарии к примеру на русском
  • Помещаем пропущенные значения в начало
>>> a = np.ma.array([1, 2, 5, 4, 3],mask=[0, 1, 0, 1, 0])
>>> # fill_value takes over endwith
>>> a.sort(endwith=False, fill_value=3)
>>> a
masked_array(data=[1, --, --, 3, 5],
             mask=[False,  True,  True, False, False],
       fill_value=999999)
Комментарии к примеру на русском
  • fill_value имеет приоритет над endwith
