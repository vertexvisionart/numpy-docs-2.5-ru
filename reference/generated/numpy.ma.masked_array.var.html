numpy.ma.masked_array.var#

метод

ma.masked_array.var(axis=None, dtype=None, out=None, ddof=0, keepdims=<no value>, mean=<no value>)[source]#

Вычислите дисперсию вдоль указанной оси.

Возвращает дисперсию элементов массива — меру разброса распределения. По умолчанию дисперсия вычисляется по развёрнутому в одномерный массиву, иначе — вдоль указанной оси.

Параметры:
aarray_like

Массив чисел, дисперсию которых нужно вычислить. Если a не является массивом, выполняется попытка преобразования.

axisNone, int или кортеж целых чисел, необязательно

Ось или оси вычисления дисперсии. По умолчанию дисперсия вычисляется для всего массива, развёрнутого в одномерный. Если задан кортеж целых чисел, дисперсия вычисляется по нескольким осям, а не по одной или сразу по всем, как раньше.

dtypeтип данных, необязательный параметр

Тип для использования в вычислении дисперсии. Для массивов целочисленного типа по умолчанию float64; для массивов типов float он такой же, как и тип массива.

outndarray, необязательный параметр

Альтернативный выходной массив, в который можно поместить результат. Он должен иметь ту же форму, что и ожидаемый результат, но при необходимости тип преобразуется.

ddof{int, float}, необязательный

«Поправка к числу степеней свободы»: при вычислении используется делитель N - ddof, где N — число элементов. По умолчанию ddof равен нулю. Подробнее об использовании ddof см. в примечаниях.

keepdimsbool, необязательно

Если True, оси, по которым выполняется свёртка, сохраняются в результате как измерения размера 1. Благодаря этому результат корректно согласуется с входным массивом по правилам трансляции массивов.

Если передано значение по умолчанию, keepdims не передаётся методу var подклассов ndarray; любое другое значение передаётся. Если метод подкласса не поддерживает keepdims, возникшее исключение передаётся вызывающему коду.

whereобъект, подобный массиву, из bool; необязательный параметр

Элементы, включаемые в вычисление дисперсии. Подробности см. в reduce.

Добавлено в версии 1.20.0.

meanобъект, подобный массиву, необязательный параметр

Передайте среднее, чтобы избежать его повторного вычисления. Его форма должна быть такой, как если бы оно вычислялось с keepdims=True. Ось вычисления среднего должна совпадать с осью, используемой при вызове этой функции var.

Добавлено в версии 2.0.0.

correction{int, float}, необязательный

Совместимое с Array API имя для параметра ddof. Одновременно может быть предоставлен только один из них.

Добавлено в версии 2.0.0.

Возвращаемые значения:
variance ndarray см. параметр dtype выше

При out=None возвращается новый массив с дисперсией; иначе возвращается ссылка на выходной массив.

См. также

std, mean, nanmean, nanstd, nanvar
Определение типа вывода

Примечания

Есть несколько распространённых вариантов вычисления дисперсии массива. Если входной a — одномерный массив NumPy, а mean передано как аргумент или вычислено как a.mean(), NumPy вычисляет дисперсию массива следующим образом:

N = len(a)
d2 = abs(a - mean)**2  # abs is for complex `a`
var = d2.sum() / (N - ddof)  # note use of `ddof`
Комментарии к примеру на русском
  • abs нужен для комплексного `a`
  • Обратите внимание на использование `ddof`

Разные значения аргумента ddof полезны в разных контекстах. NumPy по умолчанию ddof=0 соответствует выражению:

\[\frac{\sum_i{|a_i - \bar{a}|^2 }}{N}\]

что в статистике иногда называют дисперсией генеральной совокупности: определение дисперсии применяется к a так, как если бы a содержал всю совокупность возможных наблюдений.

Многие другие библиотеки определяют дисперсию массива иначе, например:

\[\frac{\sum_i{|a_i - \bar{a}|^2}}{N - 1}\]

В статистике эту величину иногда называют «выборочной дисперсией»: если a — случайная выборка из большей генеральной совокупности, такой расчёт даёт несмещённую оценку её дисперсии. Использование \(N-1\) в знаменателе часто называют «поправкой Бесселя». Она устраняет смещение оценки в сторону меньших значений, возникающее при замене истинного среднего генеральной совокупности выборочным средним a. Для вычисления этой величины задайте ddof=1.

Для комплексных чисел перед возведением в квадрат берётся модуль, поэтому результат всегда действительный и неотрицательный.

Для входных данных с плавающей точкой дисперсия вычисляется с той же точностью, что и у самих данных. В зависимости от данных это может привести к неточным результатам, особенно для float32 (см. пример ниже). Проблему можно смягчить, задав параметром dtype более точный тип для накопления суммы.

Примеры

>>> import numpy as np
>>> a = np.array([[1, 2], [3, 4]])
>>> np.var(a)
1.25
>>> np.var(a, axis=0)
array([1.,  1.])
>>> np.var(a, axis=1)
array([0.25,  0.25])

При одинарной точности результат var() может быть неточным:

>>> a = np.zeros((2, 512*512), dtype=np.float32)
>>> a[0, :] = 1.0
>>> a[1, :] = 0.1
>>> np.var(a)
np.float32(0.20250003)

Вычисление дисперсии с типом float64 даёт более точный результат:

>>> np.var(a, dtype=np.float64)
0.20249999932944759 # may vary
>>> ((1-0.55)**2 + (0.1-0.55)**2)/2
0.2025
Комментарии к примеру на русском
  • Результат может отличаться

Указание аргумента where:

>>> a = np.array([[14, 8, 11, 10], [7, 9, 10, 11], [10, 15, 5, 10]])
>>> np.var(a)
6.833333333333333 # may vary
>>> np.var(a, where=[[True], [True], [False]])
4.0
Комментарии к примеру на русском
  • Результат может отличаться

Использование именованного аргумента mean для экономии времени вычислений:

>>> import numpy as np
>>> from timeit import timeit
>>>
>>> a = np.array([[14, 8, 11, 10], [7, 9, 10, 11], [10, 15, 5, 10]])
>>> mean = np.mean(a, axis=1, keepdims=True)
>>>
>>> g = globals()
>>> n = 10000
>>> t1 = timeit("var = np.var(a, axis=1, mean=mean)", globals=g, number=n)
>>> t2 = timeit("var = np.var(a, axis=1)", globals=g, number=n)
>>> print(f'Percentage execution time saved {100*(t2-t1)/t2:.0f}%')

Percentage execution time saved 32%
