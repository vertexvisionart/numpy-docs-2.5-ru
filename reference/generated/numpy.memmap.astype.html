numpy.memmap.astype#

метод

memmap.astype(dtype, order='K', casting='unsafe', subok=True, copy=True)#

Копия массива, приведенная к указанному типу.

Параметры:
dtypestr или dtype

Код типа или тип данных, к которому приводится массив.

order{‘C’, ‘F’, ‘A’, ‘K’}, необязательный параметр

Определяет расположение результата в памяти. ‘C’ — порядок C, ‘F’ — порядок Fortran, ‘A’ — порядок Fortran, если все массивы непрерывны в этом порядке, иначе C. ‘K’ максимально приближает результат к порядку элементов массивов в памяти. По умолчанию ‘K’.

casting{‘no’, ‘equiv’, ‘safe’, ‘same_kind’, ‘same_value’, ‘unsafe’}, необязательный

Задаёт допустимые правила приведения типов. Для обратной совместимости по умолчанию используется ‘unsafe’.

  • ‘no’ означает полный запрет приведения типов данных.

  • «equiv» означает, что разрешены только изменения порядка байтов.

  • ‘safe’ разрешает только приведения типов, сохраняющие значения.

  • ‘same_kind’ разрешает только безопасные приведения типов или приведения внутри одной категории, например из float64 в float32.

  • «unsafe» означает, что разрешены любые преобразования данных.

  • ‘same_value’ разрешает любые преобразования типов, сохраняющие значения: округление чисел с плавающей запятой и переполнение целых чисел не допускаются

Добавлено в версии 2.4: поддержка 'same_value'.

subokbool, необязательно

Если True (по умолчанию), подклассы сохраняются; иначе возвращаемый массив принудительно приводится к базовому классу.

copybool, необязательно

По умолчанию astype всегда возвращает новый массив. При значении false, если требования dtype, order и subok выполнены, вместо копии возвращается входной массив.

Возвращаемые значения:
arr_tndarray

Если только copy не равен False и не выполнены остальные условия возврата входного массива, описанные для параметра copy, arr_t — новый массив той же формы, что и входной, с типом данных и порядком, заданными dtype и order.

Исключения:
ComplexWarning

При приведении комплексного типа к float или int. Чтобы избежать этого, используйте a.real.astype(t).

ValueError

Если при приведении с использованием 'same_value' значения изменяются или возникает переполнение

Примеры

>>> import numpy as np
>>> x = np.array([1, 2, 2.5])
>>> x
array([1. ,  2. ,  2.5])

>>> x.astype(np.int_)
array([1, 2, 2])

>>> x.astype(np.int_, casting="same_value")
Traceback (most recent call last):
...
ValueError: could not cast 'same_value' double to long

>>> x[:2].astype(np.int_, casting="same_value")
array([1, 2])
