numpy.memmap.flags#

атрибут

memmap.flags#

Сведения о расположении массива в памяти.

Атрибуты:
C_CONTIGUOUS (C)

Данные находятся в одном непрерывном сегменте памяти в порядке C.

F_CONTIGUOUS (F)

Данные находятся в едином непрерывном сегменте памяти в порядке Fortran.

OWNDATA (O)

Массив владеет памятью, которую он использует, или заимствует ее у другого объекта.

WRITEABLE (W)

Данные доступны для записи. Значение False блокирует запись, оставляя только чтение. Представление, например срез, наследует WRITEABLE базового массива при создании, но затем его можно заблокировать, сохранив доступность базового массива для записи. Обратное неверно: представление заблокированного массива нельзя сделать доступным для записи. Однако блокировка базового объекта пока не блокирует уже существующие представления, поэтому через ранее созданное доступное для записи представление можно изменить содержимое заблокированного массива. Попытка изменить массив, недоступный для записи, вызывает RuntimeError. Примечание переводчика: при присваивании элементу массива с WRITEABLE=False NumPy 2.5 вызывает ValueError («assignment destination is read-only»); указание RuntimeError в оригинале устарело.

ALIGNED (A)

Данные и все элементы выровнены соответствующим образом для аппаратного обеспечения.

WRITEBACKIFCOPY (X)

Этот массив является копией другого массива. Перед освобождением нужно вызвать функцию C API PyArray_ResolveWritebackIfCopy, чтобы записать содержимое копии в базовый массив.

FNC

F_CONTIGUOUS установлен, а C_CONTIGUOUS — нет.

FORC

F_CONTIGUOUS или C_CONTIGUOUS (односегментный тест).

BEHAVED (B)

ALIGNED и WRITEABLE.

CARRAY (CA)

BEHAVED и C_CONTIGUOUS.

FARRAY (FA)

BEHAVED и F_CONTIGUOUS, но не C_CONTIGUOUS.

Примечания

К объекту flags можно обращаться как к словарю (a.flags['WRITEABLE']) или через имена атрибутов в нижнем регистре (a.flags.writeable). Краткие имена флагов поддерживаются только при обращении как к словарю.

Пользователь может изменять только флаги WRITEBACKIFCOPY, WRITEABLE и ALIGNED: прямым присваиванием атрибуту или элементу словаря либо вызовом ndarray.setflags.

Флаги массива не могут быть установлены произвольно:

  • WRITEBACKIFCOPY может быть установлен только False.

  • ALIGNED можно установить в True только для действительно выровненных данных.

  • WRITEABLE можно установить в True, только если массив владеет своей памятью либо её конечный владелец предоставляет буферный интерфейс с возможностью записи или является строкой.

Данные массива могут одновременно быть непрерывно расположены в порядке C и Fortran. Это очевидно для одномерных массивов, но возможно и при большем числе измерений.

Даже у непрерывно расположенного массива шаг arr.strides[dim] может быть произвольным, если arr.shape[dim] == 1 или массив пуст. В общем случае не гарантируется ни self.strides[-1] == self.itemsize для порядка C, ни self.strides[0] == self.itemsize для порядка Fortran.
