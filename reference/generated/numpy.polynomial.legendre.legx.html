ndarray(shape, dtype=None, buffer=None, offset=0, strides=None, order=None) –

ndarray(shape, dtype=np.float64, buffer=None, offset=0, strides=None, order=None)

Объект массива представляет собой многомерный однородный массив элементов фиксированного размера. Связанный объект типа данных описывает формат каждого элемента в массиве (его порядок байтов, сколько байтов он занимает в памяти, является ли это целым числом, числом с плавающей запятой или чем-то еще и т. д.).

Для создания массивов следует использовать array, zeros или empty (см. раздел «См. также» ниже). Описанные здесь параметры относятся к низкоуровневому способу создания массива — ndarray(…).

Для получения дополнительной информации обратитесь к модулю numpy и изучите методы и атрибуты массива.

Параметры:
(для метода __new__; см. примечания ниже)
shapeкортеж целых чисел

Форма созданного массива.

dtypeтип данных, необязательный параметр

Любой объект, интерпретируемый как тип данных NumPy. По умолчанию numpy.float64.

bufferобъект, предоставляющий буферный интерфейс, необязательно

Используется для заполнения массива данными.

offsetint, необязательный

Смещение данных массива в буфере.

stridesкортеж целых чисел, необязательно

Шаги данных в памяти.

order{'C', 'F'}, необязательно

Порядок по строкам (как в C) или по столбцам (как в Fortran).

Атрибуты:
Tndarray

Транспонированный массив.

data буфер

Элементы массива, в памяти.

dtypeобъект dtype

Описывает формат элементов массива.

flagsсловарь

Словарь со сведениями об использовании памяти, например «C_CONTIGUOUS», «OWNDATA», «WRITEABLE» и т. д.

flatобъект numpy.flatiter

Представление массива как одномерного итератора. Итератор поддерживает присваивания, например x.flat = 3; примеры см. в ndarray.flat (TODO).

imagndarray

Мнимая часть массива.

realndarray

Вещественная часть массива.

sizeint

Количество элементов в массиве.

itemsizeint

Объём памяти одного элемента массива в байтах.

nbytesint

Общее число байтов для хранения данных массива, то есть itemsize * size.

ndimint

Количество измерений массива.

shapeкортеж целых чисел

Форма массива.

stridesкортеж целых чисел

Шаг, необходимый для перехода между элементами в памяти. Например, непрерывно расположенный массив (3, 4) типа int16 в порядке C имеет шаги (8, 2). Это означает, что переход между соседними элементами в памяти требует смещения на 2 байта. Для перехода между строками нужно смещение на 8 байтов (2 * 4).

ctypesобъект ctypes

Класс со свойствами массива, необходимыми для взаимодействия с ctypes.

basendarray

Если массив является представлением другого массива, тот массив — его base, если сам не является представлением. Данные фактически хранятся в массиве base.

Примечания

Существует два режима создания массива с использованием __new__:

  1. Если buffer равен None, то используются только shape, dtype и order.

  2. Если buffer — объект с буферным интерфейсом, учитываются все именованные аргументы.

Метод __init__ не требуется, поскольку массив полностью инициализируется после метода __new__.

Примеры

Эти примеры иллюстрируют низкоуровневый конструктор ndarray. См. раздел See Also выше для более простых способов построения ndarray.

Первый режим: buffer равен None:

>>> import numpy as np
>>> np.ndarray(shape=(2,2), dtype=np.float64, order='F')
array([[0.0e+000, 0.0e+000], # random
       [     nan, 2.5e-323]])
Комментарии к примеру на русском
  • Случайный результат

Второй режим:

>>> np.ndarray((2,), buffer=np.array([1,2,3]),
...            offset=np.int_().itemsize,
...            dtype=np.int_) # offset = 1*itemsize, i.e. skip first element
array([2, 3])
Комментарии к примеру на русском
  • offset = 1*itemsize, то есть пропускаем первый элемент
