numpy.polynomial.polynomial.Polynomial.trim#

метод

polynomial.polynomial.Polynomial.trim(tol=0)[source]#

Удалить завершающие коэффициенты

Удаляет коэффициенты с конца, пока не встретится коэффициент с модулем больше tol или не будет достигнуто начало ряда. Если удалению подлежат все коэффициенты, ряд заменяется на [0]. Возвращается новый экземпляр ряда с новыми коэффициентами. Текущий экземпляр не изменяется.

Параметры:
tolнеотрицательное число.

Все концевые коэффициенты, меньшие tol по модулю, будут удалены.

Возвращаемые значения:
new_seriesряд

Новый экземпляр ряда с обрезанным массивом коэффициентов.
