numpy.set_printoptions#

numpy.set_printoptions(precision=None, threshold=None, edgeitems=None, linewidth=None, suppress=None, nanstr=None, infstr=None, formatter=None, sign=None, floatmode=None, *, legacy=None, override_repr=None)[source]#

Задаёт параметры вывода.

Эти параметры определяют способ отображения чисел с плавающей запятой, массивов и других объектов NumPy.

Параметры:
precisionint или None, необязательно

Число цифр точности при выводе чисел с плавающей точкой (по умолчанию 8). Если floatmode не равен fixed, можно задать None, чтобы выводить столько цифр, сколько нужно для однозначного представления значения.

thresholdint, необязательный

Число элементов массива, при превышении которого используется сокращённое, а не полное представление repr (по умолчанию 1000). Чтобы всегда выводить полное представление, передайте sys.maxsize.

edgeitemsint, необязательный

Число элементов массива, показываемых в начале и конце каждого измерения при сокращённом выводе (по умолчанию 3).

linewidthint, необязательный

Число символов в строке, по которому определяются места переноса строк (по умолчанию 75).

suppressbool, необязательно

При True числа с плавающей точкой всегда выводятся в записи с фиксированной точкой; числа, равные нулю при текущей точности, выводятся как ноль. При False используется экспоненциальная запись, если минимальное абсолютное значение меньше 1e-4 или отношение максимального абсолютного значения к минимальному больше 1e3. По умолчанию False.

nanstrstr, необязательно

Строковое представление значения NaN («не число») для чисел с плавающей точкой; по умолчанию nan.

infstrstr, необязательно

Строковое представление бесконечности с плавающей запятой (по умолчанию inf).

signстрока ‘-’, ‘+’ или ‘ ’ (пробел), необязательный параметр

Управляет выводом знака чисел с плавающей точкой. При «+» знак положительных значений всегда выводится. При « » на месте знака положительных значений всегда выводится пробел. При «-» знак положительных значений не выводится. По умолчанию «-».

Изменено в версии 2.0: Параметр sign теперь применим и к целочисленным типам; раньше поддерживались только типы с плавающей запятой.

formatterсловарь вызываемых объектов, необязательный параметр

Если значение не None, ключи должны указывать типы, к которым применяется соответствующая функция форматирования. Вызываемые объекты должны возвращать строку. Для типов, не указанных соответствующими ключами, используются стандартные средства форматирования. Отдельные типы, для которых можно задать функцию форматирования:

  • ‘bool’

  • «int»

  • ‘timedelta’: numpy.timedelta64

  • ‘datetime’: numpy.datetime64

  • ‘float’

  • longfloat: 128-битные числа с плавающей точкой

  • 'complexfloat'

  • longcomplexfloat: состоит из двух 128-битных чисел с плавающей точкой

  • «numpystr»: типы numpy.bytes_ и numpy.str_

  • ‘object’: массивы np.object_

Другие ключи для одновременной настройки группы типов:

  • ‘all’: задаёт все типы

  • «int_kind»: устанавливает «int»

  • ‘float_kind’: задаёт формат для ‘float’ и ‘longfloat’

  • ‘complex_kind’: задаёт ‘complexfloat’ и ‘longcomplexfloat’

  • ‘str_kind’: задаёт ‘numpystr’

floatmodestr, необязательно

Контролирует интерпретацию опции precision для типов с плавающей запятой. Может принимать следующие значения (по умолчанию maxprec_equal):

  • ‘fixed’: всегда выводить ровно precision цифр после десятичной точки,

    даже если при этом будет напечатано больше или меньше цифр, чем необходимо для однозначного указания значения.

  • «unique»: выводит минимально необходимое число цифр дробной части

    уникально представлять каждое значение. Разные элементы могут иметь разное количество цифр. Значение опции precision игнорируется.

  • ‘maxprec’: выводить не более precision цифр после десятичного разделителя, но если

    если для однозначного представления элемента достаточно меньшего числа цифр, выводить только это число цифр.

  • «maxprec_equal»: выводить не более precision цифр дробной части,

    но если каждый элемент массива можно однозначно представить одинаковым меньшим числом цифр, использовать это число цифр для всех элементов.

legacyстрока или False, необязательный параметр

Строка '1.13' включает прежний режим вывода версии 1.13. Он приближает вывод к NumPy 1.13, добавляя пробел на месте знака вещественных чисел и меняя поведение для нульмерных массивов. При этом также включается прежний режим вывода версии 1.21, описанный ниже.

Строковое значение '1.21' включает прежний режим вывода версии 1.21. Он воспроизводит вывод сложных структурированных dtype в NumPy 1.21, не вставляя пробелы после запятых, разделяющих поля, и после двоеточий.

Значение '1.25' приближает вывод к NumPy 1.25: главным образом это означает вывод числовых скаляров без сведений об их типе, например 3.0 вместо np.float64(3.0).

При значении '2.1' информация о форме не выводится при сокращённом отображении массивов, когда несколько элементов заменяются на ....

При значении '2.2' переход к экспоненциальной записи при выводе значений типов np.float16 и np.float32 может происходить при больших значениях или вовсе не происходить.

При настройке на False отключается унаследованный режим.

Для совместимости с будущими версиями нераспознанные строки игнорируются с предупреждением.

Изменено в версии 1.22.0.

Изменено в версии 2.2.

override_repr: вызываемый объект, необязательно

Если задана функция, она используется для формирования repr массивов. Остальные параметры игнорируются.

См. также

get_printoptions, printoptions, array2string

Примечания

  • formatter всегда сбрасывается с помощью вызова set_printoptions.

  • Используйте printoptions в качестве менеджера контекста для временной установки значений.

  • Эти параметры вывода применяются только к ndarray NumPy, а не к скалярам.

Примечание о параллельном выполнении: см. «Параметры форматирования текста»

Примеры

Можно задать точность вывода чисел с плавающей точкой:

>>> import numpy as np
>>> np.set_printoptions(precision=4)
>>> np.array([1.123456789])
[1.1235]

Длинные массивы можно выводить в сокращённом виде:

>>> np.set_printoptions(threshold=5)
>>> np.arange(10)
array([0, 1, 2, ..., 7, 8, 9], shape=(10,))

Небольшие результаты можно подавить:

>>> eps = np.finfo(float).eps
>>> x = np.arange(4.)
>>> x**2 - (x + eps)**2
array([-4.9304e-32, -4.4409e-16,  0.0000e+00,  0.0000e+00])
>>> np.set_printoptions(suppress=True)
>>> x**2 - (x + eps)**2
array([-0., -0.,  0.,  0.])

Собственная функция форматирования позволяет задать нужный вид элементов массива:

>>> np.set_printoptions(formatter={'all':lambda x: 'int: '+str(-x)})
>>> x = np.arange(3)
>>> x
array([int: 0, int: -1, int: -2])
>>> np.set_printoptions()  # formatter gets reset
>>> x
array([0, 1, 2])
Комментарии к примеру на русском
  • formatter сбрасывается

Чтобы вернуть опции по умолчанию, вы можете использовать:

>>> np.set_printoptions(edgeitems=3, infstr='inf',
... linewidth=75, nanstr='nan', precision=8,
... suppress=False, threshold=1000, formatter=None)

Также, чтобы временно переопределить параметры, используйте printoptions в качестве менеджера контекста:

>>> with np.printoptions(precision=2, suppress=True, threshold=5):
...     np.linspace(0, 10, 10)
array([ 0.  ,  1.11,  2.22, ...,  7.78,  8.89, 10.  ], shape=(10,))
