numpy.random.Generator.hypergeometric#

метод

random.Generator.hypergeometric(ngood, nbad, nsample, size=None)#

Генерирует выборку из гипергеометрического распределения.

Генерирует выборку из гипергеометрического распределения с параметрами ngood (число подходящих объектов), nbad (число неподходящих объектов) и nsample (число выбираемых объектов, не превышающее ngood + nbad).

Параметры:
ngoodint или объект array_like с целыми числами

Количество успешных вариантов выбора. Должно быть неотрицательным и меньше 10**9.

nbadint или объект array_like с целыми числами

Количество способов сделать неправильный выбор. Должно быть неотрицательным и меньше 10**9.

nsampleint или объект array_like с целыми числами

Количество отобранных предметов должно быть неотрицательным и меньше ngood + nbad.

sizeint или кортеж int, необязательный

Форма результата. Если задана, например, форма (m, n, k), генерируется m * n * k случайных значений. Если size равен None (по умолчанию), а ngood, nbad и nsample — скаляры, возвращается одно значение. В противном случае генерируется np.broadcast(ngood, nbad, nsample).size значений.

Возвращаемые значения:
outndarray или скаляр

Выборка из гипергеометрического распределения с заданными параметрами. Каждое значение — число подходящих объектов в случайно выбранном подмножестве размера nsample из совокупности, содержащей ngood подходящих и nbad неподходящих объектов.

Примечания

Функция вероятностей (PMF) гипергеометрического распределения имеет вид

\[P(x) = \frac{\binom{g}{x}\binom{b}{n-x}}{\binom{g+b}{n}},\]

где \(0 \le x \le n\) и \(n-b \le x \le g\)

где P(x) — вероятность x успешных результатов в выборке, g = ngood, b = nbad, n = nsample.

Рассмотрим урну с чёрными и белыми шарами: ngood чёрных и nbad белых. Если извлечь nsample шаров без возвращения, гипергеометрическое распределение описывает число чёрных шаров в выборке.

Это распределение очень похоже на биномиальное, но здесь выборка выполняется без возвращения, а в биномиальном случае — с возвращением (либо генеральная совокупность бесконечна). При увеличении размера генеральной совокупности это распределение приближается к биномиальному.

Аргументы ngood и nbad должны быть каждый меньше 10**9. При чрезвычайно больших значениях алгоритм генерации выборки [4] перестаёт работать корректно из-за потери точности вычислений с плавающей точкой. Для таких значений, если nsample не слишком велико, распределение можно приближённо заменить биномиальным: binomial(n=nsample, p=ngood/(ngood + nbad)).

Примеры

Сгенерируем выборку из распределения:

>>> rng = np.random.default_rng()
>>> ngood, nbad, nsamp = 100, 2, 10
# number of good, number of bad, and number of samples
>>> s = rng.hypergeometric(ngood, nbad, nsamp, 1000)
>>> from matplotlib.pyplot import hist
>>> hist(s)
#   note that it is very unlikely to grab both bad items
Комментарии к примеру на русском
  • Число хороших объектов, плохих объектов и извлекаемых объектов
  • Вероятность извлечь оба плохих объекта очень мала

Предположим, у вас есть урна с 15 белыми и 15 черными шариками. Если вы наугад вытащите 15 шариков, насколько вероятно, что 12 или более из них одного цвета?

>>> s = rng.hypergeometric(15, 15, 15, 100000)
>>> sum(s>=12)/100000. + sum(s<=3)/100000.
#   answer = 0.003 ... pretty unlikely!
Комментарии к примеру на русском
  • Ответ = 0.003… весьма маловероятно!
