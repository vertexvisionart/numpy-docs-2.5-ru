  • numpy.random.RandomState.standard_normal

numpy.random.RandomState.standard_normal#

метод

random.RandomState.standard_normal(size=None)#

Генерирует выборку из стандартного нормального распределения (среднее=0, стандартное отклонение=1).

Примечание

В новом коде используйте метод standard_normal экземпляра Generator; см. Быстрое начало работы.

Параметры:
sizeint или кортеж int, необязательный

Форма результата. Например, при форме (m, n, k) генерируется m * n * k случайных значений. По умолчанию None: возвращается одно значение.

Возвращаемые значения:
out float или ndarray

Массив сгенерированных случайных значений с плавающей точкой формы size либо одно значение, если size не задан.

См. также

normal

Эквивалентная функция с дополнительными аргументами loc и scale для установки среднего и стандартного отклонения.

random.Generator.standard_normal

который должен быть использован для нового кода.

Примечания

Чтобы получить случайную выборку из нормального распределения со средним mu и стандартным отклонением sigma, используйте один из вариантов:

mu + sigma * np.random.standard_normal(size=...)
np.random.normal(mu, sigma, size=...)

Примеры

>>> np.random.standard_normal()
2.1923875335537315 #random
Комментарии к примеру на русском
  • Случайный результат
>>> s = np.random.standard_normal(8000)
>>> s
array([ 0.6888893 ,  0.78096262, -0.89086505, ...,  0.49876311,  # random
       -0.38672696, -0.4685006 ])                                # random
>>> s.shape
(8000,)
>>> s = np.random.standard_normal(size=(3, 4, 2))
>>> s.shape
(3, 4, 2)
Комментарии к примеру на русском
  • Случайный результат

Массив 2 на 4 из нормального распределения со средним 3 и стандартным отклонением 2.5:

>>> 3 + 2.5 * np.random.standard_normal(size=(2, 4))
array([[-4.49401501,  4.00950034, -1.81814867,  7.29718677],   # random
       [ 0.39924804,  4.68456316,  4.99394529,  4.84057254]])  # random
