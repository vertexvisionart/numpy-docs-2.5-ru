Генерация случайных выборок#

Быстрый запуск #

Модуль numpy.random реализует генераторы псевдослучайных чисел (PRNG, или RNG), позволяющие получать выборки из различных вероятностных распределений. Обычно создают экземпляр Generator с помощью default_rng, а затем вызывают его методы для генерации выборок из нужных распределений.

>>> import numpy as np
>>> rng = np.random.default_rng()

Сгенерировать одно случайное число с плавающей точкой, равномерно распределённое в диапазоне \([0, 1)\):

>>> rng.random()  
0.06369197489564249  # may vary
Комментарии к примеру на русском
  • Результат может отличаться

Создаём массив из 10 чисел со стандартным нормальным распределением:

>>> rng.standard_normal(10)  
array([-0.31018314, -1.8922078 , -0.3628523 , -0.63526532,  0.43181166,  # may vary
        0.51640373,  1.25693945,  0.07779185,  0.84090247, -2.13406828])
Комментарии к примеру на русском

Создайте массив из 5 целых чисел равномерно в диапазоне \([0, 10)\) :

>>> rng.integers(low=0, high=10, size=5)  
array([8, 7, 6, 2, 0])  # may vary
Комментарии к примеру на русском

Наши генераторы выдают детерминированные последовательности, воспроизводимые по целому начальному значению, задающему состояние. Если оно не указано, default_rng использует недетерминированные данные ОС и при каждом запуске генерирует другие числа. Псевдослучайные последовательности практически независимы — по крайней мере для задач, которым изначально подходит качество этих генераторов.

>>> import numpy as np
>>> rng1 = np.random.default_rng()
>>> rng1.random()  
0.6596288841243357  # may vary
>>> rng2 = np.random.default_rng()
>>> rng2.random()  
0.11885628817151628  # may vary

Предупреждение

Реализованные в этом модуле генераторы псевдослучайных чисел предназначены для статистического моделирования и симуляции. Они не подходят для целей безопасности или криптографии. См. модуль secrets из стандартной библиотеки для таких случаев использования.

Начальные значения генератора должны быть большими положительными целыми числами. default_rng принимает положительные целые числа любого размера. Рекомендуется использовать очень большие уникальные числа, чтобы ваше начальное значение отличалось от чужих. Это помогает обеспечить статистическую независимость ваших результатов от чужих, кроме случаев, когда вы намеренно пытаетесь воспроизвести чужой результат. Удобный способ получить такое начальное значение — с помощью secrets.randbits получить произвольное 128-битное целое число.

>>> import numpy as np
>>> import secrets
>>> secrets.randbits(128)  
122807528840384100672342137672332424406  # may vary
>>> rng1 = np.random.default_rng(122807528840384100672342137672332424406)
>>> rng1.random()
0.5363922081269535
>>> rng2 = np.random.default_rng(122807528840384100672342137672332424406)
>>> rng2.random()
0.5363922081269535
Комментарии к примеру на русском

Дополнительные способы управления начальным значением в особых случаях описаны в документации default_rng и SeedSequence.

Generator и связанная с ним инфраструктура появились в NumPy 1.17.0. Многие программы по-прежнему используют старый RandomState и функции из numpy.random. Хотя пока их удаление не планируется, мы рекомендуем по возможности переходить на Generator: его алгоритмы быстрее, гибче и будут развиваться дальше. В большинстве случаев Generator можно использовать вместо RandomState. Сведения о прежней инфраструктуре приведены в разделе Прежний механизм генерации случайных чисел, о переходе — в разделе Что нового и что изменилось, а причины перехода объясняются в NEP 19.

Архитектура#

Пользователи в основном работают с экземплярами Generator. Каждый экземпляр Generator содержит экземпляр BitGenerator, реализующий основной алгоритм генерации случайных чисел. У BitGenerator ограниченный круг задач: он управляет состоянием и предоставляет функции для получения случайных чисел double, а также 32- и 64-битных беззнаковых целых чисел.

Generator получает поток от генератора битов и преобразует его в более полезные распределения, например в нормально распределённые случайные значения. Такая организация позволяет использовать другие генераторы битов почти без дублирования кода.

NumPy предоставляет несколько классов BitGenerator с разными алгоритмами генерации случайных чисел. Сейчас default_rng использует PCG64 как BitGenerator по умолчанию. Его статистические свойства и производительность лучше, чем у алгоритма MT19937 из прежнего RandomState. О поддерживаемых алгоритмах подробнее см. Генераторы битов.

default_rng и генераторы BitGenerator внутри делегируют преобразование начальных значений в состояния генератора объекту SeedSequence. SeedSequence реализует сложный алгоритм, связывающий пользовательские данные с внутренними особенностями каждого алгоритма BitGenerator, которым может требоваться разное число битов состояния. Он позволяет смешивать в состоянии генератора целые числа произвольного размера и произвольные последовательности таких чисел. Это полезный базовый механизм для построения гибкой схемы параллельных потоков случайных чисел.

Для обратной совместимости мы по-прежнему поддерживаем прежний класс RandomState. По умолчанию он использует алгоритм MT19937, а старые начальные значения seed воспроизводят прежние результаты. Вспомогательные функции numpy.random остаются псевдонимами методов единственного глобального экземпляра RandomState. Подробности см. в разделе «Генерация случайных чисел с прежним API». В разделе «Что нового и что изменилось» приведено подробное сравнение Generator и RandomState.

Параллельная генерация#

Включенные генераторы можно использовать в параллельных распределенных приложениях несколькими способами:

  • Порождение дочерних SeedSequence

  • Последовательность целочисленных начальных значений

  • Независимые потоки

  • Скачкообразное продвижение состояния BitGenerator

Пользователям с очень высокой степенью параллелизма следует ознакомиться с разделом Замена PCG64 на PCG64DXSM.
