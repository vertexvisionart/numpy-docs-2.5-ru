Производительность #

Рекомендация #

Для общего использования рекомендуется генератор PCG64, а при интенсивном распараллеливании — его улучшенный вариант PCG64DXSM. Оба обеспечивают высокое статистическое качество, полный набор возможностей и высокую скорость на большинстве платформ, но несколько медленнее в сборках для 32-битных процессов. В разделе Переход с PCG64 на PCG64DXSM объясняется, когда масштаб параллельных вычислений требует использования PCG64DXSM.

Philox работает довольно медленно, но обладает очень качественными статистическими свойствами и позволяет легко получать заведомо независимые потоки с помощью уникальных ключей. Если вы хотите организовать параллельные потоки именно так или переносите код из системы с таким подходом, выбирайте Philox.

SFC64 обеспечивает высокое статистическое качество и очень большую скорость, но не поддерживает скачки состояния. Если они не нужны, а важна скорость, в том числе в 32-битных процессах, выбирайте его.

MT19937 не проходит некоторые статистические тесты и не особенно быстр по сравнению с современными PRNG. По этим причинам мы по большей части не рекомендуем использовать его отдельно, только через устаревший RandomState для воспроизведения старых результатов. Тем не менее, он имеет очень долгую историю использования по умолчанию во многих системах.

Измерения времени#

Ниже указано время в наносекундах для генерации одного случайного значения из конкретного распределения. Исходный генератор MT19937 значительно медленнее, поскольку для получения результата того же объёма, что у более быстрых генераторов, ему нужны два 32-битных значения.

По производительности генерации целых чисел наблюдается аналогичный порядок.

Для других, более сложных генераторов картина аналогична. Устаревший генератор RandomState значительно медленнее генерирует нормально распределённые значения, поскольку использует преобразование Бокса — Мюллера вместо метода «зиккурат». Разрыв в скорости генерации экспоненциально распределённых значений также велик: для обращения функции распределения требуется вычислять логарифм. В столбце, названном в оригинале MT19973, используется тот же 32-битный генератор, что и в RandomState, но случайные значения формируются с помощью Generator. Примечание переводчика: MT19973 — опечатка в названии MT19937.

Производительность в различных операционных системах #

Производительность различается между платформами из-за различий компиляторов и доступных аппаратных возможностей (например, разрядности регистров). Генератор битов по умолчанию выбран с расчётом на хорошую производительность на 64-битных платформах. В 32-битных операционных системах производительность существенно отличается.

Сообщенные значения нормализуются относительно скорости MT19937 в каждой таблице. Значение 100 указывает на то, что производительность соответствует MT19937. Более высокие значения указывают на улучшенную производительность. Эти значения не могут быть сопоставлены между таблицами.
