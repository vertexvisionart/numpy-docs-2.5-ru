Функции создания массивов#

См. также

Создание массивов

Создание по форме или значению#

empty(shape[, dtype, order, device, like])

Возвратить новый массив заданной формы и типа, без инициализации записей.

empty_like(prototype, /[, dtype, order, ...])

Возвращает новый массив той же формы и типа, что и заданный массив.

eye(N[, M, k, dtype, order, device, like])

Возвращает двумерный массив с единицами по диагонали и нулями в других местах.

identity(n[, dtype, like])

Возвращает единичную матрицу.

ones(shape[, dtype, order, device, like])

Возвращает новый массив заданной формы и типа, заполненный единицами.

ones_like(a[, dtype, order, subok, shape, ...])

Возвращает массив единиц той же формы и типа, что и заданный массив.

zeros(shape[, dtype, order, device, like])

Возвратить новый массив заданной формы и типа, заполненный нулями.

zeros_like(a[, dtype, order, subok, shape, ...])

Возвращает массив нулей той же формы и типа, что заданный массив.

full(shape, fill_value[, dtype, order, ...])

Возвращает новый массив заданной формы и типа, заполненный значением fill_value.

full_like(a, fill_value[, dtype, order, ...])

Возвращает массив, заполненный заданным значением, с той же формой и типом, что и исходный.

Из существующих данных#

array(object[, dtype, copy, order, subok, ...])

Создайте массив.

asarray(a[, dtype, order, device, copy, like])

Преобразует входные данные в массив.

asanyarray(a[, dtype, order, device, copy, like])

Преобразует входные данные в ndarray, сохраняя объекты подклассов ndarray без изменения.

ascontiguousarray(a[, dtype, like])

Возвращает массив (ndim >= 1), непрерывно расположенный в памяти в порядке C.

asmatrix(data[, dtype])

Интерпретирует входные данные как матрицу.

astype(x, dtype, /, *[, copy, device])

Копирует массив в определенный тип данных.

copy(a[, order, subok])

Возвращает копию заданного объекта в виде массива.

frombuffer(buffer[, dtype, count, offset, like])

Интерпретирует буфер как одномерный массив.

from_dlpack(x, /, *[, device, copy])

Создаёт массив NumPy из объекта, реализующего протокол __dlpack__.

fromfile(file[, dtype, count, sep, offset, like])

Создаёт массив из данных текстового или двоичного файла.

fromfunction(function, shape, *[, dtype, like])

Постройте массив, выполняя функцию над каждой координатой.

fromiter(iter, dtype[, count, like])

Создаёт новый одномерный массив из итерируемого объекта.

fromstring(string[, dtype, count, like])

Новый одномерный массив, инициализированный текстовыми данными из строки.

loadtxt(fname[, dtype, comments, delimiter, ...])

Загрузка данных из текстового файла.

Создание массивов записей #

Примечание

О массивах записей см. Массивы записей.

rec.array(obj[, dtype, shape, offset, ...])

Создаёт массив записей из разнообразных объектов.

rec.fromarrays(arrayList[, dtype, shape, ...])

Создаёт массив записей из плоского списка массивов

rec.fromrecords(recList[, dtype, shape, ...])

Создаёт recarray из списка записей в текстовом виде.

rec.fromstring(datastring[, dtype, shape, ...])

Создаёт массив записей из двоичных данных

rec.fromfile(fd[, dtype, shape, offset, ...])

Создаёт массив из данных двоичного файла

Создание массивов символов (numpy.char) #

Примечание

numpy.char используется для создания массивов символов.

char.array(obj[, itemsize, copy, unicode, order])

Создайте chararray.

char.asarray(obj[, itemsize, unicode, order])

Конвертируйте ввод в chararray, копируя данные только при необходимости.

Численные диапазоны #

arange([start,] stop[, step,][, dtype, ...])

Возвращает равномерно расположенные значения в пределах заданного интервала.

linspace(start, stop[, num, endpoint, ...])

Возвращает равноотстоящие числа на заданном интервале.

logspace(start, stop[, num, endpoint, base, ...])

Возвращает числа, равномерно расположенные в логарифмической шкале.

geomspace(start, stop[, num, endpoint, ...])

Возвращает числа, расположенные равномерно в логарифмическом масштабе (геометрическая прогрессия).

meshgrid(*xi[, copy, sparse, indexing])

Возвращает кортеж координатных матриц, построенных из координатных векторов.

mgrid

Экземпляр, возвращающий плотную многомерную координатную сетку meshgrid.

ogrid

Экземпляр, возвращающий открытую многомерную координатную сетку.

Построение матриц#

diag(v[, k])

Извлеките диагональ или создайте диагональную матрицу.

diagflat(v[, k])

Создаёт двумерный массив, на диагонали которого расположены элементы входного массива, развёрнутого в одномерный.

tri(N[, M, k, dtype, like])

Массив с единицами на данной диагонали и ниже и нулями в других местах.

tril(m[, k])

Нижняя треугольная часть массива.

triu(m[, k])

Верхняя треугольная часть массива.

vander(x[, N, increasing])

Создаёт матрицу Вандермонда.

Класс matrix#

bmat(obj[, ldict, gdict])

Создаёт объект матрицы из строки, вложенной последовательности или массива.
