Устаревшие средства работы со строками фиксированной длины#

Прежние возможности

Этот подмодуль считается устаревшим и больше не обновляется; в будущих версиях NumPy он может быть удалён. Строковые операции модуля планируется объявить устаревшими, а класс numpy.char.chararray уже объявлен устаревшим в NumPy 2.5. Вместо него используйте numpy.strings.

Модуль numpy.char предоставляет векторизованные строковые операции для массивов типа numpy.str_ или numpy.bytes_. Например:

>>> import numpy as np
>>> np.char.capitalize(["python", "numpy"])
array(['Python', 'Numpy'], dtype='<U6')
>>> np.char.add(["num", "doc"], ["py", "umentation"])
array(['numpy', 'documentation'], dtype='<U13')

Методы в этом модуле основаны на методах в string.

Операции со строками#

add(x1, x2, /[, out, where, casting, order, ...])

Складывает аргументы поэлементно.

multiply(a, i)

Поэлементно возвращает (a * i), то есть строку, повторённую i раз.

mod(a, values)

Поэлементно возвращает (a % i) для пары объектов array_like со строками str или unicode, то есть выполняет форматирование строк (интерполяцию) в стиле Python до версии 2.6.

capitalize(a)

Возвращает копию a, в которой только первый символ каждого элемента переведён в верхний регистр.

center(a, width[, fillchar])

Верните копию a с элементами, центрированными в строке длины width.

decode(a[, encoding, errors])

Поэлементно вызывает bytes.decode.

encode(a[, encoding, errors])

Поэлементно вызывает str.encode.

expandtabs(a[, tabsize])

Возвращает копию каждого строкового элемента, заменяя все символы табуляции одним или несколькими пробелами.

join(sep, seq)

Возвращает строку, полученную соединением строк из последовательности seq.

ljust(a, width[, fillchar])

Возвращает массив со строками из a, выровненными по левому краю в строке длины width.

lower(a)

Возвращает массив с элементами, преобразованными в нижний регистр.

lstrip(a[, chars])

Для каждого элемента a возвращает копию с удалёнными начальными символами.

partition(a, sep)

Разбивает каждый элемент a на части относительно разделителя sep.

replace(a, old, new[, count])

Для каждого элемента a возвращает копию строки, в которой вхождения подстроки old заменены на new.

rjust(a, width[, fillchar])

Возвращает массив, в котором элементы a выровнены по правому краю в строках длины width.

rpartition(a, sep)

Разбивает каждый элемент на части по самому правому разделителю.

rsplit(a[, sep, maxsplit])

Для каждого элемента a возвращает список слов строки, используя sep как строку-разделитель.

rstrip(a[, chars])

Для каждого элемента a возвращает копию с удалёнными символами в конце.

split(a[, sep, maxsplit])

Для каждого элемента a возвращает список слов строки, используя sep как строку-разделитель.

splitlines(a[, keepends])

Для каждого элемента a возвращает список его строк, разделяя текст по границам строк.

strip(a[, chars])

Для каждого элемента a возвращает копию с удалёнными начальными и конечными символами.

swapcase(a)

Поэлементно возвращает копию строки, в которой прописные буквы заменены строчными и наоборот.

title(a)

Поэлементно возвращает строку или строку Unicode, в которой каждое слово начинается с заглавной буквы, а остальные буквы приведены к нижнему регистру.

translate(a, table[, deletechars])

Для каждого элемента a возвращает копию строки: символы, перечисленные в необязательном аргументе deletechars, удаляются, а остальные заменяются по заданной таблице преобразования.

upper(a)

Возвращает массив, элементы которого преобразованы в верхний регистр.

zfill(a, width)

Возвращает числовую строку, дополненную нулями слева.

Сравнение #

В отличие от стандартных операторов сравнения numpy, операторы в модуле char перед выполнением сравнения удаляют конечные пробельные символы.

equal(x1, x2)

Возвращает (x1 == x2) поэлементно.

not_equal(x1, x2)

Возвращает (x1 != x2) поэлементно.

greater_equal(x1, x2)

Поэлементно возвращает (x1 >= x2).

less_equal(x1, x2)

Поэлементно возвращает (x1 <= x2).

greater(x1, x2)

Поэлементно возвращает (x1 > x2).

less(x1, x2)

Поэлементно возвращает (x1 < x2).

compare_chararrays(a1, a2, cmp, rstrip)

Поэлементно сравнивает два строковых массива с помощью оператора сравнения cmp.

Сведения о строках#

count(a, sub[, start, end])

Возвращает массив с числом неперекрывающихся вхождений подстроки sub в диапазоне [start, end).

endswith(a, suffix[, start, end])

Возвращает булевой массив, который является True, где элемент строки в a заканчивается suffix, иначе False.

find(a, sub[, start, end])

Для каждого элемента возвращает наименьший индекс в строке, по которому найдена подстрока sub, причём sub должна целиком находиться в диапазоне [start, end).

index(a, sub[, start, end])

Аналогична find, но возбуждает ValueError, если подстрока не найдена.

isalpha(x, /[, out, where, casting, order, ...])

Для каждого элемента возвращает истину, если все символы данных, интерпретируемых как строка, являются буквами и строка содержит хотя бы один символ; иначе возвращает ложь.

isalnum(x, /[, out, where, casting, order, ...])

Для каждого элемента возвращает истину, если строка непуста и все её символы — буквы или цифры; иначе возвращает ложь.

isdecimal(x, /[, out, where, casting, ...])

Для каждого элемента возвращайте True, если в элементе есть только десятичные символы.

isdigit(x, /[, out, where, casting, order, ...])

Для каждого элемента возвращает true, если строка непустая и все её символы являются цифрами; иначе false.

islower(x, /[, out, where, casting, order, ...])

Для каждого элемента возвращает True, если все символы строки, имеющие регистр, строчные и имеется хотя бы один такой символ; иначе возвращает False.

isnumeric(x, /[, out, where, casting, ...])

Для каждого элемента возвращает True, если он состоит только из числовых символов.

isspace(x, /[, out, where, casting, order, ...])

Для каждого элемента возвращает true, если строка непустая и состоит только из пробельных символов; иначе false.

istitle(x, /[, out, where, casting, order, ...])

Для каждого элемента возвращает true, если строка непустая и имеет заглавный регистр слов (title case), иначе false.

isupper(x, /[, out, where, casting, order, ...])

Для каждого элемента возвращает true, если все символы с регистром являются прописными и имеется хотя бы один такой символ; иначе false. Примечание переводчика: в оригинале сказано просто «хотя бы один символ», но строка только из цифр, например “123”, возвращает false.

rfind(a, sub[, start, end])

Для каждого элемента возвращает наибольший индекс вхождения подстроки sub, при котором sub целиком содержится в диапазоне [start, end).

rindex(a, sub[, start, end])

Как rfind, но вызывает ValueError, если подстрока sub не найдена.

startswith(a, prefix[, start, end])

Возвращает логический массив со значением True там, где строковый элемент a начинается с prefix, и False в остальных позициях.

str_len(x, /[, out, where, casting, order, ...])

Возвращает длину каждого элемента.

Вспомогательный класс#

array(obj[, itemsize, copy, unicode, order])

Создайте chararray.

asarray(obj[, itemsize, unicode, order])

Конвертируйте ввод в chararray, копируя данные только при необходимости.

chararray(shape[, itemsize, unicode, ...])

Предоставляет удобное представление массивов строковых значений и значений Unicode.
