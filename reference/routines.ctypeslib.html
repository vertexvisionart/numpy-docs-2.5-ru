Интерфейс вызова внешних функций ctypes (numpy.ctypeslib)#

numpy.ctypeslib.as_array(obj, shape=None)[source]#

Создайте numpy массив из массива ctypes или POINTER.

Массив NumPy совместно использует память с объектом ctypes.

При преобразовании из ctypes POINTER параметр shape обязателен. При преобразовании из массива ctypes параметр shape игнорируется.

Примеры

Преобразование целочисленного массива ctypes:

>>> import ctypes
>>> ctypes_array = (ctypes.c_int * 5)(0, 1, 2, 3, 4)
>>> np_array = np.ctypeslib.as_array(ctypes_array)
>>> np_array
array([0, 1, 2, 3, 4], dtype=int32)

Преобразование ctypes POINTER:

>>> import ctypes
>>> buffer = (ctypes.c_int * 5)(0, 1, 2, 3, 4)
>>> pointer = ctypes.cast(buffer, ctypes.POINTER(ctypes.c_int))
>>> np_array = np.ctypeslib.as_array(pointer, (5,))
>>> np_array
array([0, 1, 2, 3, 4], dtype=int32)
numpy.ctypeslib.as_ctypes(obj)[source]#

Создаёт и возвращает объект ctypes из массива NumPy. На самом деле принимается любой объект, предоставляющий __array_interface__.

Примеры

Создание объекта ctypes из np.array с автоматически определённым целочисленным типом:

>>> inferred_int_array = np.array([1, 2, 3])
>>> c_int_array = np.ctypeslib.as_ctypes(inferred_int_array)
>>> type(c_int_array)
<class 'c_long_Array_3'>
>>> c_int_array[:]
[1, 2, 3]

Создайте объект ctypes из явно заданного 8-битного беззнакового целого np.array:

>>> exp_int_array = np.array([1, 2, 3], dtype=np.uint8)
>>> c_int_array = np.ctypeslib.as_ctypes(exp_int_array)
>>> type(c_int_array)
<class 'c_ubyte_Array_3'>
>>> c_int_array[:]
[1, 2, 3]
numpy.ctypeslib.as_ctypes_type(dtype)[source]#

Преобразовать dtype в тип ctypes.

Параметры:
dtypedtype

Преобразуемый dtype

Возвращаемые значения:
ctype

Скаляр, объединение, массив или структура ctypes

Исключения:
NotImplementedError

Если преобразование невозможно

Примечания

Эта функция не гарантирует преобразование туда и обратно без потерь ни в одном направлении.

np.dtype(as_ctypes_type(dt)) будет:

  • вставить поля заполнения

  • переупорядочивает поля по возрастанию смещения

  • отбросить дополнительные названия полей

as_ctypes_type(np.dtype(ctype)) будет:

  • не сохраняет имена классов ctypes.Structure и ctypes.Union

  • преобразовывать одноэлементные объекты ctypes.Union в одноэлементные объекты ctypes.Structure

  • вставить поля заполнения

Примеры

Преобразование простого dtype:

>>> dt = np.dtype(np.int8)
>>> ctype = np.ctypeslib.as_ctypes_type(dt)
>>> ctype
<class 'ctypes.c_byte'>

Преобразование структурированного dtype:

>>> dt = np.dtype([('x', 'i4'), ('y', 'f4')])
>>> ctype = np.ctypeslib.as_ctypes_type(dt)
>>> ctype
<class 'struct'>
numpy.ctypeslib.load_library(libname, loader_path)[source]#

Можно загрузить библиотеку с помощью

>>> lib = ctypes.cdll[<full_path_name>]

Однако нужно учитывать различия платформ, например расширения файлов библиотек и то, что Windows загружает первую найденную библиотеку с нужным именем. Для удобства NumPy предоставляет функцию load_library.

Изменено в версии 1.20.0: libname и loader_path могут принимать любой объект пути.

Параметры:
libname Path-like

Название библиотеки, которая может иметь «lib» в качестве приставки, но без расширения.

loader_path Path-like

Где можно найти библиотеку.

Возвращаемые значения:
ctypes.cdll[libpath]объект библиотеки

Объект библиотеки ctypes

Исключения:
OSError

Если нет библиотеки с ожидаемым расширением, или библиотека неисправна и не может быть загружена.

numpy.ctypeslib.ndpointer(dtype=None, ndim=None, shape=None, flags=None)[source]#

restype/argtypes с проверкой массивов.

Экземпляр ndpointer описывает ndarray в спецификациях restypes и argtypes. Это гибче, чем, например, POINTER(c_double): можно задать ограничения, проверяемые при вызове функции ctypes, включая тип данных, число измерений, форму и флаги. Если массив им не соответствует, возникает TypeError.

Параметры:
dtypeтип данных, необязательный параметр

Тип данных массива.

ndimint, необязательный

Число измерений массива.

shapeкортеж целых чисел, необязательно

Форма массива.

flagsstr или кортеж строк

Флаги массива; могут быть одним или несколькими из:

  • C_CONTIGUOUS / C / CONTIGUOUS

  • F_CONTIGUOUS / F / FORTRAN

  • OWNDATA / O

  • WRITEABLE / W

  • ALIGNED / A

  • WRITEBACKIFCOPY / X

Возвращаемые значения:
klassобъект типа ndpointer

Объект типа, представляющий собой экземпляр _ndtpr, содержащий информацию о dtype, ndim, форме и флагах.

Исключения:
TypeError

Если данный массив не удовлетворяет указанным ограничениям.

Примеры

>>> clib.somefunc.argtypes = [np.ctypeslib.ndpointer(dtype=np.float64,
...                                                  ndim=1,
...                                                  flags='C_CONTIGUOUS')]
... 
>>> clib.somefunc(np.array([1, 2, 3], dtype=np.float64))
...
class numpy.ctypeslib.c_intp#

Знаковый целочисленный тип ctypes того же размера, что и numpy.intp.

В зависимости от платформы это может быть псевдоним c_int, c_long или c_longlong.
