Классы типов данных (numpy.dtypes) #

Этот модуль содержит функциональность, относящуюся к конкретным типам данных, и их классы. Общую информацию о типах данных см. также в numpy.dtype и разделе Объекты типов данных (dtype).

Подобно встроенному модулю types, этот подмодуль определяет типы (классы), которые широко не используются непосредственно.

Добавлено в NumPy: 1.25

Модуль dtypes появился в NumPy 1.25. Ранее классы DType были доступны лишь косвенно.

Классы DType #

Ниже приведены классы соответствующих экземпляров dtype и скалярных типов NumPy. Эти классы можно использовать в проверках isinstance, создавать их экземпляры или применять напрямую. Обычно прямое использование не требуется: подходят скалярные аналоги, например np.float64, или строки вроде "float64".

Функции для разработчиков DType#

register_dlpack_dtype(dlpack_key, dtype, /)

Зарегистрируйте NumPy dtype для пары DLPack (code, bits), чтобы numpy.from_dlpack мог импортировать его, а ndarray.__dlpack__ — экспортировать.
