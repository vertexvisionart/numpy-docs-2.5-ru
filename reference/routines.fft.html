Дискретное преобразование Фурье#

Модуль SciPy scipy.fft предоставляет более широкий набор возможностей, чем numpy.fft, включающий только базовые функции.

Стандартные БПФ#

fft(a[, n, axis, norm, out])

Вычисляет одномерное дискретное преобразование Фурье.

ifft(a[, n, axis, norm, out])

Вычисляет одномерное обратное дискретное преобразование Фурье.

fft2(a[, s, axes, norm, out])

Вычисляет двумерное дискретное преобразование Фурье.

ifft2(a[, s, axes, norm, out])

Вычисляет двумерное обратное дискретное преобразование Фурье.

fftn(a[, s, axes, norm, out])

Вычисляет N-мерное дискретное преобразование Фурье.

ifftn(a[, s, axes, norm, out])

Вычисляет N-мерное обратное дискретное преобразование Фурье.

БПФ действительных данных#

rfft(a[, n, axis, norm, out])

Вычисляет одномерное дискретное преобразование Фурье для вещественных входных данных.

irfft(a[, n, axis, norm, out])

Вычисляет преобразование, обратное rfft.

rfft2(a[, s, axes, norm, out])

Вычисляет двумерное БПФ вещественного массива.

irfft2(a[, s, axes, norm, out])

Вычисляет преобразование, обратное rfft2.

rfftn(a[, s, axes, norm, out])

Вычисляет N-мерное дискретное преобразование Фурье для вещественных входных данных.

irfftn(a[, s, axes, norm, out])

Вычисляет преобразование, обратное rfftn.

Эрмитовы БПФ#

hfft(a[, n, axis, norm, out])

Вычисляет БПФ эрмитово-симметричного сигнала, спектр которого вещественный.

ihfft(a[, n, axis, norm, out])

Вычисляет обратное БПФ сигнала с эрмитовой симметрией.

Вспомогательные процедуры#

fftfreq(n[, d, device])

Возвращает частоты отсчётов дискретного преобразования Фурье.

rfftfreq(n[, d, device])

Возвращает частоты отсчётов дискретного преобразования Фурье для использования с rfft и irfft.

fftshift(x[, axes])

Перемещает компоненту нулевой частоты в центр спектра.

ifftshift(x[, axes])

Обратное преобразование для fftshift.

Справочная информация #

Анализ Фурье позволяет представить функцию в виде суммы периодических составляющих и восстановить её по этим составляющим. Если и функция, и её преобразование Фурье заменены дискретными аналогами, говорят о дискретном преобразовании Фурье (DFT). Оно стало одним из основных инструментов численных вычислений отчасти благодаря очень быстрому алгоритму — быстрому преобразованию Фурье (FFT). Этот алгоритм был известен Гауссу ещё в 1805 году, а в современном виде его представили Кули и Тьюки [CT]. Доступное введение в анализ Фурье и его приложения можно найти у Press и соавторов [NR].

Дискретное преобразование Фурье раскладывает входные данные на составляющие, соответствующие дискретным частотам, поэтому широко применяется в цифровой обработке сигналов, например для фильтрации. В этом контексте дискретизированные входные данные обычно называют сигналом во временной области. Результат называют спектром или преобразованием; он относится к частотной области.

Подробности реализации#

Существует множество определений ДПФ, различающихся знаком показателя экспоненты, нормировкой и другими соглашениями. В этой реализации ДПФ определяется как

\[A_k = \sum_{m=0}^{n-1} a_m \exp\left\{-2\pi i{mk \over n}\right\} \qquad k = 0,\ldots,n-1.\]

В общем случае ДПФ определено для комплексных входных и выходных данных. Одночастотная составляющая с обычной частотой \(f\) представляется комплексной экспонентой \(a_m = \exp\{2\pi i\,f m\Delta t\}\), где \(\Delta t\) — интервал дискретизации.

Значения результата расположены в так называемом стандартном порядке. Если A = fft(a, n), то A[0] содержит компоненту нулевой частоты (сумму сигнала), всегда чисто вещественную для вещественного входа. Затем A[1:n/2] содержит положительные частоты, а A[n/2+1:] — отрицательные, от более отрицательных к менее отрицательным. Для чётного числа входных точек A[n/2] представляет и положительную, и отрицательную частоту Найквиста и также является чисто вещественным для вещественного входа. Для нечётного числа точек A[(n-1)/2] содержит наибольшую положительную частоту, а A[(n+1)/2] — отрицательную частоту с наибольшим модулем. Функция np.fft.fftfreq(n) возвращает частоты, соответствующие элементам результата. Функция np.fft.fftshift(A) сдвигает преобразования и их частоты так, чтобы компоненты нулевой частоты оказались в центре; np.fft.ifftshift(A) отменяет этот сдвиг.

Когда входной a является сигналом временной области и A = fft(a), np.abs(A) является его амплитудным спектром, а np.abs(A)**2 - его спектром мощности. Фазовый спектр получается np.angle(A).

Обратное ДПФ определяется как

\[a_m = \frac{1}{n}\sum_{k=0}^{n-1}A_k\exp\left\{2\pi i{mk\over n}\right\} \qquad m = 0,\ldots,n-1.\]

Оно отличается от прямого преобразования знаком аргумента экспоненты и нормирующим множителем \(1/n\) по умолчанию.

Повышение типов#

numpy.fft повышает точность массивов float32 и complex64, преобразуя их в массивы float64 и complex128 соответственно. Реализацию БПФ без такого преобразования входных массивов см. в scipy.fftpack.

Нормировка#

Аргумент norm задаёт, какое из прямого и обратного преобразований масштабируется и с каким коэффициентом нормировки. При стандартной нормировке "backward" прямое преобразование не масштабируется, а обратное умножается на \(1/n\). Для унитарных преобразований задайте аргументу norm значение "ortho": тогда оба направления масштабируются на \(1/\sqrt{n}\). При norm, равном "forward", прямое преобразование умножается на \(1/n\), а обратное не масштабируется — противоположно стандартному "backward". Для обратной совместимости None служит псевдонимом стандартного варианта "backward".

Вещественные и эрмитовы преобразования#

Для чисто вещественных входных данных преобразование обладает эрмитовой симметрией: компонента частоты \(f_k\) комплексно сопряжена с компонентой частоты \(-f_k\). Поэтому отрицательные частоты не содержат информации, которой уже нет в положительных. Семейство rfft предназначено для вещественных данных и использует эту симметрию, вычисляя только положительные частоты до частоты Найквиста включительно. Из n входных точек получается n/2+1 комплексных выходных точек. Обратные преобразования этого семейства предполагают такую же симметрию и для получения n точек используют n/2+1 входных точек.

Аналогично, если спектр чисто вещественный, сигнал обладает эрмитовой симметрией. Семейство функций hfft использует это свойство, принимая n/2+1 комплексных точек во входной временной области для n вещественных точек в частотной области.

Многомерные БПФ применяются, например, для анализа и фильтрации изображений. Благодаря вычислительной эффективности БПФ может ускорять и вычисление больших свёрток: свёртка во временной области эквивалентна поэлементному умножению в частотной области.

Большее число измерений#

В двух измерениях ДПФ определяется как

\[A_{kl} = \sum_{m=0}^{M-1} \sum_{n=0}^{N-1} a_{mn}\exp\left\{-2\pi i \left({mk\over M}+{nl\over N}\right)\right\} \qquad k = 0, \ldots, M-1;\quad l = 0, \ldots, N-1,\]

что очевидным образом обобщается на большее число измерений; обратные преобразования обобщаются таким же образом.
