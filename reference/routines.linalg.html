Линейная алгебра #

Функции линейной алгебры NumPy используют BLAS и LAPACK для эффективного выполнения стандартных алгоритмов на низком уровне. NumPy может предоставлять эти библиотеки сам, используя версии C части эталонных реализаций, но по возможности предпочтительны оптимизированные библиотеки, задействующие специальные возможности процессора: OpenBLAS, MKL (TM) и ATLAS. Они многопоточны и зависят от процессора, поэтому для управления числом потоков или выбора архитектуры могут понадобиться переменные окружения и внешние пакеты, например threadpoolctl.

Библиотека SciPy также содержит подмодуль linalg, чьи возможности частично совпадают с соответствующим подмодулем NumPy. SciPy предоставляет функции, отсутствующие в numpy.linalg: разложения LU и Шура, несколько способов вычисления псевдообратной матрицы и трансцендентные матричные функции, например матричный логарифм. Некоторые общие функции имеют расширенные возможности в scipy.linalg: например, scipy.linalg.eig принимает вторую матрицу для решения обобщённой задачи на собственные значения. Однако некоторые функции NumPy гибче поддерживают трансляцию массивов. Например, numpy.linalg.solve обрабатывает стопки массивов, а scipy.linalg.solve принимает первым аргументом только один квадратный массив.

Примечание

Термин матрица на этой странице обозначает двумерный объект numpy.array, а не объект numpy.matrix. Последний больше не рекомендуется даже для линейной алгебры. Подробнее см. документацию объекта matrix.

Оператор @#

Для матричного умножения двумерных массивов предпочтителен оператор @, появившийся в NumPy 1.10.0. Функция numpy.matmul реализует оператор @.

Матричные и векторные произведения#

dot(a, b[, out])

Скалярное произведение двух массивов.

linalg.multi_dot(arrays, *[, out])

Вычисляет произведение двух или более массивов одним вызовом, автоматически выбирая самый быстрый порядок вычислений.

vdot(a, b, /)

Возвращает скалярное произведение двух векторов.

vecdot(x1, x2, /[, out, casting, order, ...])

Скалярное произведение векторов двух массивов.

linalg.vecdot(x1, x2, /, *[, axis])

Вычисляет скалярное произведение векторов.

inner(a, b, /)

Скалярное произведение двух массивов.

outer(a, b[, out])

Вычисляет внешнее произведение двух векторов.

linalg.outer(x1, x2, /)

Вычисляет внешнее произведение двух векторов.

matmul(x1, x2, /[, out, casting, order, ...])

Матричное произведение двух массивов.

linalg.matmul(x1, x2, /)

Вычисляет матричное произведение.

matvec(x1, x2, /[, out, casting, order, ...])

Матрично-векторное произведение двух массивов.

vecmat(x1, x2, /[, out, casting, order, ...])

Произведение вектора на матрицу для двух массивов.

tensordot(a, b[, axes])

Вычисляет тензорную свёртку по указанным осям.

linalg.tensordot(x1, x2, /, *[, axes])

Вычисляет тензорную свёртку по указанным осям.

einsum(subscripts, *operands[, out, dtype, ...])

Выполняет над операндами суммирование по соглашению Эйнштейна.

einsum_path(subscripts, *operands[, optimize])

Определяет порядок свёрток с наименьшими затратами для выражения einsum, учитывая создание промежуточных массивов.

linalg.matrix_power(a, n)

Возводит квадратную матрицу в целую степень n.

kron(a, b)

Кронекеровское произведение двух массивов.

linalg.cross(x1, x2, /, *[, axis])

Возвращает векторное произведение трёхэлементных векторов.

Разложения#

linalg.cholesky(a, /, *[, upper])

Разложение Холецкого.

linalg.qr(a[, mode])

Вычисляет QR-разложение матрицы.

linalg.svd(a[, full_matrices, compute_uv, ...])

Сингулярное разложение.

linalg.svdvals(x, /)

Возвращает сингулярные значения матрицы (или стопки матриц) x.

Собственные значения матрицы#

linalg.eig(a)

Вычисляет собственные значения и правые собственные векторы квадратного массива.

linalg.eigh(a[, UPLO])

Возвращает собственные значения и собственные векторы комплексной эрмитовой (сопряженной симметричной) или действительной симметричной матрицы.

linalg.eigvals(a)

Вычисляет собственные значения произвольной матрицы.

linalg.eigvalsh(a[, UPLO])

Вычисляет собственные значения комплексной эрмитовой или вещественной симметричной матрицы.

Нормы и другие числа#

linalg.norm(x[, ord, axis, keepdims])

Норма матрицы или вектора.

linalg.matrix_norm(x, /, *[, keepdims, ord])

Вычисляет матричную норму матрицы (или стопки матриц) x.

linalg.vector_norm(x, /, *[, axis, ...])

Вычисляет норму вектора или набора векторов x.

linalg.cond(x[, p])

Вычисляет число обусловленности матрицы.

linalg.det(a)

Вычисляет определитель массива.

linalg.matrix_rank(A[, tol, hermitian, rtol])

Возвращает ранг матрицы, представленной массивом, используя метод SVD

linalg.slogdet(a)

Вычисляет знак определителя массива и натуральный логарифм его модуля. Примечание переводчика: в кратком описании оригинала опущено уточнение «модуля»; возвращается именно log(abs(det)), что позволяет работать и с отрицательным определителем.

trace(a[, offset, axis1, axis2, dtype, out])

Возвращает суммы элементов диагоналей массива.

linalg.trace(x, /, *[, offset, dtype])

Возвращает сумму по указанным диагоналям матрицы или набора матриц x.

Решение уравнений и обращение матриц#

linalg.solve(a, b)

Решает линейное матричное уравнение или систему линейных скалярных уравнений.

linalg.tensorsolve(a, b[, axes])

Решает тензорное уравнение a x = b относительно x.

linalg.lstsq(a, b[, rcond])

Возвращает решение линейного матричного уравнения методом наименьших квадратов.

linalg.inv(a)

Вычисляет обратную матрицу.

linalg.pinv(a[, rcond, hermitian, rtol])

Вычисляет псевдообратную матрицу Мура — Пенроуза.

linalg.tensorinv(a[, ind])

Вычисляет «обратный» N-мерный массив.

Другие матричные операции #

diagonal(a[, offset, axis1, axis2])

Возвращает указанные диагонали.

linalg.diagonal(x, /, *[, offset])

Возвращает заданные диагонали матрицы (или стопки матриц) x.

Линейная алгебра на нескольких матрицах одновременно #

Некоторые из перечисленных выше функций линейной алгебры могут вычислять результаты сразу для нескольких матриц, собранных в один массив.

Это указывается в документации в описании входных параметров, например a : (..., M, M) array_like. Так, входной массив с a.shape == (N, M, M) интерпретируется как «стопка» из N матриц размера M на M. Аналогичные обозначения применяются и к возвращаемым значениям: например, определитель имеет описание det : (...), и в этом случае результат удовлетворяет det(a).shape == (N,). Этот подход распространяется на операции линейной алгебры с массивами большей размерности: последние одно или два измерения многомерного массива интерпретируются как векторы или матрицы в зависимости от операции.
