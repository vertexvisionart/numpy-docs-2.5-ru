Операции с массивами с маской#

Константы #

ma.MaskType

псевдоним bool

Создание #

Из существующих данных#

ma.masked_array

псевдоним MaskedArray

ma.array(data[, dtype, copy, order, mask, ...])

Класс массива с возможными замаскированными значениями.

ma.copy(a.copy)

Возвращает копию массива.

ma.frombuffer(buffer[, dtype, count, ...])

Интерпретирует буфер как одномерный массив.

ma.fromfunction(function, shape, *[, dtype, ...])

Постройте массив, выполняя функцию над каждой координатой.

ma.MaskedArray.copy([order])

Возвращает копию массива.

ma.diagflat(v[, k])

Создаёт двумерный массив, на диагонали которого расположены элементы входного массива, развёрнутого в одномерный.

Единицы и нули#

ma.empty(shape[, dtype, order, device, like])

Возвратить новый массив заданной формы и типа, без инициализации записей.

ma.empty_like(prototype, /[, dtype, order, ...])

Возвращает новый массив той же формы и типа, что и заданный массив.

ma.masked_all(shape[, dtype])

Массив с маской с неинициализированными данными, в котором замаскированы все элементы.

ma.masked_all_like(arr)

Массив с маской с неинициализированными данными и свойствами существующего массива.

ma.ones(shape[, dtype, order, device, like, ...])

Возвращает новый массив заданной формы и типа, заполненный единицами.

ma.ones_like(a[, dtype, order, subok, ...])

Возвращает массив единиц той же формы и типа, что и заданный массив.

ma.zeros(shape[, dtype, order, device, like])

Возвратить новый массив заданной формы и типа, заполненный нулями.

ma.zeros_like(a[, dtype, order, subok, ...])

Возвращает массив нулей той же формы и типа, что заданный массив.

Проверка массива #

ma.all(self[, axis, out, keepdims])

Возвращает True, если все элементы истинны.

ma.any(self[, axis, out, keepdims])

Возвращает True, если хотя бы один элемент a имеет истинное логическое значение.

ma.count(self[, axis, keepdims])

Подсчитывает немаскированные элементы массива вдоль заданной оси.

ma.count_masked(arr[, axis])

Подсчитывает замаскированные элементы вдоль заданной оси.

ma.getmask(a)

Возвращает маску маскированного массива или nomask.

ma.getmaskarray(arr)

Возвращает маску массива с маской либо логический массив, целиком заполненный False.

ma.getdata(a[, subok])

Возвращает данные массива с маской как ndarray.

ma.nonzero(self)

Возвращает индексы ненулевых незамаскированных элементов.

ma.shape(obj)

Возвращает форму массива.

ma.size(obj[, axis])

Возвращает число элементов вдоль заданной оси.

ma.is_masked(x)

Определяет, есть ли во входных данных замаскированные значения.

ma.is_mask(m)

Возвращает True, если m — допустимая стандартная маска.

ma.isMaskedArray(x)

Проверяет, являются ли входные данные экземпляром MaskedArray.

ma.isMA(x)

Проверяет, являются ли входные данные экземпляром MaskedArray.

ma.isarray(x)

Проверяет, являются ли входные данные экземпляром MaskedArray.

ma.isin(element, test_elements[, ...])

Вычисляет element in test_elements, выполняя трансляцию только по element.

ma.in1d(ar1, ar2[, assume_unique, invert])

Проверьте, присутствует ли каждый элемент массива во втором массиве.

ma.unique(ar1[, return_index, return_inverse])

Находит уникальные элементы массива.

ma.MaskedArray.all([axis, out, keepdims])

Возвращает True, если все элементы истинны.

ma.MaskedArray.any([axis, out, keepdims])

Возвращает True, если хотя бы один элемент a имеет истинное логическое значение.

ma.MaskedArray.count([axis, keepdims])

Подсчитывает немаскированные элементы массива вдоль заданной оси.

ma.MaskedArray.nonzero()

Возвращает индексы ненулевых незамаскированных элементов.

ma.shape(obj)

Возвращает форму массива.

ma.size(obj[, axis])

Возвращает число элементов вдоль заданной оси.

ma.MaskedArray.data

Возвращает исходные данные как представление маскированного массива.

ma.MaskedArray.mask

Текущая маска.

ma.MaskedArray.recordmask

Получает или задаёт маску массива, если у него нет именованных полей.

Операции с MaskedArray#

Изменение формы #

ma.ravel(self[, order])

Возвращает одномерную версию self, по возможности как представление. Примечание переводчика: оригинал безусловно обещает представление, однако при необходимости ravel создаёт копию.

ma.reshape(a, new_shape[, order])

Возвращает массив, содержащий те же данные, с новой формой.

ma.resize(x, new_shape)

Возвращает новый замаскированный массив с заданными размером и формой.

ma.MaskedArray.flatten([order])

Возвращает копию массива, развёрнутую в одномерную.

ma.MaskedArray.ravel([order])

Возвращает одномерную версию self, по возможности как представление. Примечание переводчика: оригинал безусловно обещает представление, однако при необходимости ravel создаёт копию.

ma.MaskedArray.reshape(*s, **kwargs)

Возвращает маскированный массив с изменённой формой, сохраняя его данные.

ma.MaskedArray.resize(newshape[, refcheck, ...])

Изменение осей#

ma.swapaxes(a.swapaxes)

Возвращает представление массива с переставленными осями axis1 и axis2.

ma.transpose(a[, axes])

Переставляет измерения массива.

ma.MaskedArray.swapaxes(axis1, axis2, /)

Возвращает представление массива с переставленными осями axis1 и axis2.

ma.MaskedArray.transpose(*axes)

Возвращает представление массива с транспонированными осями.

Изменение числа измерений#

ma.atleast_1d(*arys)

Преобразует входные данные в массивы с хотя бы одним измерением.

ma.atleast_2d(*arys)

Представляет входные данные как массивы как минимум с двумя измерениями.

ma.atleast_3d(*arys)

Представляет входные данные как массивы не менее чем с тремя измерениями.

ma.expand_dims(a, axis)

Расширяет форму массива, добавляя оси.

ma.squeeze(a[, axis, fill_value, hardmask])

Удаляет из a оси длины 1.

ma.MaskedArray.squeeze([axis])

Удаляет из a оси длины 1.

ma.stack(arrays[, axis, out, dtype, casting])

Объединяет последовательность массивов вдоль новой оси.

ma.column_stack(tup)

Объединяет одномерные массивы в столбцы двумерного массива.

ma.concatenate(arrays[, axis])

Соединяет последовательность массивов вдоль указанной оси.

ma.dstack(tup)

Объединяет последовательность массивов по глубине (вдоль третьей оси).

ma.hstack(tup, *[, dtype, casting])

Объединяет последовательность массивов по горизонтали (по столбцам).

ma.hsplit(ary, indices_or_sections)

Разбивает массив на несколько подмассивов по горизонтали, то есть по столбцам.

ma.mr_

Преобразует объекты срезов в объединение вдоль первой оси.

ma.vstack(tup, *[, dtype, casting])

Объединяет последовательность массивов вертикально, по строкам.

Операции с масками#

Создание маски #

ma.make_mask(m[, copy, shrink, dtype])

Создаёт булеву маску из массива.

ma.make_mask_none(newshape[, dtype])

Возвращает логическую маску заданной формы, заполненную False.

ma.mask_or(m1, m2[, copy, shrink])

Объедините две маски с оператором logical_or.

ma.make_mask_descr(ndtype)

Создаёт список описания dtype по заданному dtype.

Доступ к маске #

ma.getmask(a)

Возвращает маску маскированного массива или nomask.

ma.getmaskarray(arr)

Возвращает маску массива с маской либо логический массив, целиком заполненный False.

ma.masked_array.mask

Текущая маска.

Поиск замаскированных данных #

ma.ndenumerate(a[, compressed])

Итератор многомерных индексов.

ma.flatnotmasked_contiguous(a)

Находит непрерывные участки немаскированных данных в массиве с маской.

ma.flatnotmasked_edges(a)

Находит индексы первого и последнего незамаскированных значений.

ma.notmasked_contiguous(a[, axis])

Находит непрерывные участки незамаскированных данных в массиве с маской вдоль заданной оси.

ma.notmasked_edges(a[, axis])

Находит индексы первого и последнего незамаскированных значений по оси.

ma.clump_masked(a)

Возвращает список срезов, соответствующих непрерывным замаскированным участкам одномерного массива.

ma.clump_unmasked(a)

Возвращает список срезов, соответствующих непрерывным группам незамаскированных элементов одномерного массива.

Модификация маски #

ma.mask_cols(a[, axis])

Маскирует столбцы двумерного массива, содержащие замаскированные значения.

ma.mask_or(m1, m2[, copy, shrink])

Объедините две маски с оператором logical_or.

ma.mask_rowcols(a[, axis])

Маскирует строки и/или столбцы двумерного массива, содержащие замаскированные значения.

ma.mask_rows(a[, axis])

Маскирует строки двумерного массива, содержащие маскированные значения.

ma.harden_mask(self)

Делает маску жёсткой, запрещая снимать маскирование присваиванием.

ma.soften_mask(self)

Делает маску мягкой (по умолчанию), позволяя снимать маскирование присваиванием.

ma.MaskedArray.harden_mask()

Делает маску жёсткой, запрещая снимать маскирование присваиванием.

ma.MaskedArray.soften_mask()

Делает маску мягкой (по умолчанию), позволяя снимать маскирование присваиванием.

ma.MaskedArray.shrink_mask()

Заменяет маску на nomask, когда это возможно.

ma.MaskedArray.unshare_mask()

Копирует маску и устанавливает флаг sharedmask в False.

Операции преобразования#

> в замаскированный массив#

Преобразует входные данные в маскированный массив заданного типа данных.
