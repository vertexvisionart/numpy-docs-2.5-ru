Математические функции#

Тригонометрические функции #

sin(x, /[, out, where, casting, order, ...])

Тригонометрический синус поэлементно.

cos(x, /[, out, where, casting, order, ...])

Вычисляет косинус поэлементно.

tan(x, /[, out, where, casting, order, ...])

Поэлементно вычисляет тангенс.

arcsin(x, /[, out, where, casting, order, ...])

Арксинус, поэлементно.

asin(x, /[, out, where, casting, order, ...])

Арксинус, поэлементно.

arccos(x, /[, out, where, casting, order, ...])

Поэлементный арккосинус.

acos(x, /[, out, where, casting, order, ...])

Поэлементный арккосинус.

arctan(x, /[, out, where, casting, order, ...])

Поэлементный арктангенс.

atan(x, /[, out, where, casting, order, ...])

Поэлементный арктангенс.

hypot(x1, x2, /[, out, where, casting, ...])

Возвращает гипотенузу прямоугольного треугольника по его катетам.

arctan2(x1, x2, /[, out, where, casting, ...])

Поэлементный арктангенс x1/x2 с правильным выбором квадранта.

atan2(x1, x2, /[, out, where, casting, ...])

Поэлементный арктангенс x1/x2 с правильным выбором квадранта.

degrees(x, /[, out, where, casting, order, ...])

Преобразует углы из радианов в градусы.

radians(x, /[, out, where, casting, order, ...])

Преобразует углы из градусов в радианы.

unwrap(p[, discont, axis, period])

Устраняет скачки, заменяя большие разности их дополнениями относительно периода.

deg2rad(x, /[, out, where, casting, order, ...])

Преобразует углы из градусов в радианы.

rad2deg(x, /[, out, where, casting, order, ...])

Преобразует углы из радианов в градусы.

sinh(x, /[, out, where, casting, order, ...])

Гиперболический синус, поэлементно.

cosh(x, /[, out, where, casting, order, ...])

Гиперболический косинус, поэлементно.

tanh(x, /[, out, where, casting, order, ...])

Поэлементный гиперболический тангенс.

arcsinh(x, /[, out, where, casting, order, ...])

Обратный гиперболический синус поэлементно.

asinh(x, /[, out, where, casting, order, ...])

Обратный гиперболический синус поэлементно.

arccosh(x, /[, out, where, casting, order, ...])

Обратный гиперболический косинус поэлементно.

acosh(x, /[, out, where, casting, order, ...])

Обратный гиперболический косинус поэлементно.

arctanh(x, /[, out, where, casting, order, ...])

Поэлементно вычисляет обратный гиперболический тангенс.

atanh(x, /[, out, where, casting, order, ...])

Поэлементно вычисляет обратный гиперболический тангенс.

Округление #

round(a[, decimals, out])

Округляет до заданного числа десятичных знаков; значения, находящиеся ровно посередине, округляются к ближайшему чётному.

around(a[, decimals, out])

Округление массива до заданного числа десятичных знаков.

rint(x, /[, out, where, casting, order, ...])

Округляет элементы массива до ближайшего целого числа.

fix(x[, out])

Округляем до ближайшего целого числа в сторону нуля.

floor(x, /[, out, where, casting, order, ...])

Поэлементно округляет входные значения вниз до целого.

ceil(x, /[, out, where, casting, order, ...])

Поэлементно округляет входные значения вверх до целого.

trunc(x, /[, out, where, casting, order, ...])

Поэлементно возвращает значения входных данных, усечённые до целой части.

Суммы, произведения, разности#

prod(a[, axis, dtype, out, keepdims, ...])

Возвращает произведение элементов массива вдоль заданной оси.

sum(a[, axis, dtype, out, keepdims, ...])

Сумма элементов массива по заданной оси.

nanprod(a[, axis, dtype, out, keepdims, ...])

Возвращает произведение элементов массива вдоль заданной оси, считая значения NaN единицами.

nansum(a[, axis, dtype, out, keepdims, ...])

Возвращает сумму элементов массива вдоль заданной оси, считая значения NaN нулевыми.

cumulative_sum(x, /, *[, axis, dtype, out, ...])

Возвращает накопленную сумму элементов вдоль заданной оси.

cumulative_prod(x, /, *[, axis, dtype, out, ...])

Возвращает накопленное произведение элементов вдоль заданной оси.

cumprod(a[, axis, dtype, out])

Возвращает накопленное произведение элементов вдоль заданной оси.

cumsum(a[, axis, dtype, out])

Возвращает накопленную сумму элементов вдоль заданной оси.

nancumprod(a[, axis, dtype, out])

Возвращает накопленное произведение элементов массива вдоль заданной оси, считая NaN равными единице.

nancumsum(a[, axis, dtype, out])

Возвращает накопленную сумму элементов массива вдоль заданной оси, считая значения NaN нулями.

diff(a[, n, axis, prepend, append])

Вычисляет дискретную разность n-го порядка вдоль заданной оси.

ediff1d(ary[, to_end, to_begin])

Разности между последовательными элементами массива.

gradient(f, *varargs[, axis, edge_order])

Возвращает градиент N-мерного массива.

cross(a, b[, axisa, axisb, axisc, axis])

Возвращает векторное произведение двух векторов или массивов векторов.

trapezoid(y[, x, dx, axis])

Интегрирует вдоль заданной оси составным методом трапеций.

Показательные функции и логарифмы#

exp(x, /[, out, where, casting, order, ...])

Вычисляет экспоненту каждого элемента входного массива.

expm1(x, /[, out, where, casting, order, ...])

Вычисляет exp(x) - 1 для всех элементов массива.

exp2(x, /[, out, where, casting, order, ...])

Вычислите 2**p для всех p во входном массиве.

log(x, /[, out, where, casting, order, ...])

Натуральный логарифм поэлементно.

log10(x, /[, out, where, casting, order, ...])

Возвращает логарифм по основанию 10 входного массива поэлементно.

log2(x, /[, out, where, casting, order, ...])

Логарифм x по основанию 2.

log1p(x, /[, out, where, casting, order, ...])

Поэлементно возвращает натуральный логарифм суммы единицы и входного массива.

logaddexp(x1, x2, /[, out, where, casting, ...])

Логарифм суммы экспонент входных значений.

logaddexp2(x1, x2, /[, out, where, casting, ...])

Двоичный логарифм суммы степеней двойки с показателями, равными входным значениям.

Другие специальные функции #

i0(x)

Модифицированная функция Бесселя первого рода, порядок 0.

sinc(x)

Возвращает нормированную функцию sinc.

Функции для чисел с плавающей точкой#

signbit(x, /[, out, where, casting, order, ...])

Поэлементно возвращает True там, где установлен знаковый бит. В оригинале это поясняется как «меньше нуля». Примечание переводчика: знаковый бит установлен и у -0.0, хотя -0.0 < 0 ложно; в NumPy 2.5.4 signbit(-0.0) возвращает True.

copysign(x1, x2, /[, out, where, casting, ...])

Поэлементно меняет знак x1 на знак x2.

frexp(x[, out1, out2], / [[, out, where, ...])

Разлагает элементы x на мантиссу и показатель степени двойки.

ldexp(x1, x2, /[, out, where, casting, ...])

Возвращает x1 * 2**x2 поэлементно.

nextafter(x1, x2, /[, out, where, casting, ...])

Поэлементно возвращает следующее представимое число с плавающей точкой после x1 в направлении x2.

spacing(x, /[, out, where, casting, order, ...])

Возвращает расстояние между x и ближайшим соседним числом.

Рациональные подпрограммы #

lcm(x1, x2, /[, out, where, casting, order, ...])

Возвращает наименьшее общее кратное |x1| и |x2|

gcd(x1, x2, /[, out, where, casting, order, ...])

Возвращает наибольший общий делитель |x1| и |x2|.

Арифметические операции #

add(x1, x2, /[, out, where, casting, order, ...])

Складывает аргументы поэлементно.

reciprocal(x, /[, out, where, casting, ...])

Возвращает обратное значение аргумента поэлементно.

positive(x, /[, out, where, casting, order, ...])

Поэлементный унарный плюс.

negative(x, /[, out, where, casting, order, ...])

Поэлементная смена знака числа.

multiply(x1, x2, /[, out, where, casting, ...])

Поэлементно перемножает аргументы.

divide(x1, x2, /[, out, where, casting, ...])

Делит аргументы поэлементно.

power(x1, x2, /[, out, where, casting, ...])

Элементы первого массива возводятся в степени из второго массива поэлементно.

pow(x1, x2, /[, out, where, casting, order, ...])

Элементы первого массива возводятся в степени из второго массива поэлементно.

subtract(x1, x2, /[, out, where, casting, ...])

Вычитает аргументы поэлементно.

true_divide(x1, x2, /[, out, where, ...])

Делит аргументы поэлементно.

floor_divide(x1, x2, /[, out, where, ...])

Возвращает наибольшее целое число, не превышающее частное входных значений.

float_power(x1, x2, /[, out, where, ...])

Элементы первого массива возводятся в степени из второго массива поэлементно.

fmod(x1, x2, /[, out, where, casting, ...])

Возвращает поэлементный остаток деления.

mod(x1, x2, /[, out, where, casting, order, ...])

Возвращает поэлементный остаток деления.

modf(x[, out1, out2], / [[, out, where, ...])

Возвращает дробную и целую части массива поэлементно.

remainder(x1, x2, /[, out, where, casting, ...])

Возвращает поэлементный остаток деления.

divmod(x1, x2[, out1, out2], / [[, out, ...])

Поэлементно возвращает одновременно частное от деления нацело и остаток.

Обработка комплексных чисел #

angle(z[, deg])

Возвращает аргумент комплексного числа.

real(val)

Возвращает действительную часть комплексного аргумента.

imag(val)

Возвращает мнимую часть комплексного аргумента.

conj(x, /[, out, where, casting, order, ...])

Возвращает комплексно-сопряжённые значения поэлементно.

conjugate(x, /[, out, where, casting, ...])

Возвращает комплексно-сопряжённые значения поэлементно.

Поиск экстремумов#

maximum(x1, x2, /[, out, where, casting, ...])

Поэлементный максимум элементов массива.

max(a[, axis, out, keepdims, initial, where])

Возвращает максимум массива либо максимумы вдоль оси.

amax(a[, axis, out, keepdims, initial, where])

Возвращает максимум массива либо максимумы вдоль оси.

fmax(x1, x2, /[, out, where, casting, ...])

Поэлементный максимум элементов массива.

nanmax(a[, axis, out, keepdims, initial, where])

Верните максимум массива или максимум по оси, игнорируя любые NaN.

minimum(x1, x2, /[, out, where, casting, ...])

Поэлементный минимум элементов массивов.

min(a[, axis, out, keepdims, initial, where])

Возвращает минимум массива или минимумы вдоль оси.

amin(a[, axis, out, keepdims, initial, where])

Возвращает минимум массива или минимумы вдоль оси.

fmin(x1, x2, /[, out, where, casting, ...])

Поэлементный минимум элементов массивов.

nanmin(a[, axis, out, keepdims, initial, where])

Возвращает минимум массива или минимумы вдоль оси, игнорируя NaN.

Разное #

convolve(a, v[, mode])

Возвращает дискретную линейную свертку двух одномерных последовательностей.

clip(a[, a_min, a_max, out, min, max])

Ограничивает значения в массиве заданными границами.

sqrt(x, /[, out, where, casting, order, ...])

Поэлементно возвращает неотрицательный квадратный корень значений массива.

cbrt(x, /[, out, where, casting, order, ...])

Поэлементно вычисляет кубический корень элементов массива.

square(x, /[, out, where, casting, order, ...])

Возвращает поэлементные квадраты входных значений.

absolute(x, /[, out, where, casting, order, ...])

Поэлементно вычисляет абсолютное значение.

fabs(x, /[, out, where, casting, order, ...])

Вычисляет абсолютные значения поэлементно.

sign(x, /[, out, where, casting, order, ...])

Поэлементно возвращает знак числа.

heaviside(x1, x2, /[, out, where, casting, ...])

Вычисляет ступенчатую функцию Хевисайда.

nan_to_num(x[, copy, nan, posinf, neginf])

Заменяет NaN нулём, а бесконечности — большими конечными числами (поведение по умолчанию) либо значениями, заданными пользователем через именованные аргументы nan, posinf и/или neginf.

real_if_close(a[, tol])

Если входные данные комплексные и все мнимые части близки к нулю, возвращает вещественные части.

interp(x, xp, fp[, left, right, period])

Одномерная линейная интерполяция для монотонно возрастающих координат узлов.
