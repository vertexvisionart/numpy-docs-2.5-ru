numpy.polynomial#

Подпакет для эффективной работы с полиномами.

В документации этого подпакета «конечный степенной ряд», то есть многочлен (также называемый просто «рядом»), представляется одномерным массивом NumPy с коэффициентами в порядке возрастания степени. Например, array([1,2,3]) представляет P_0 + 2*P_1 + 3*P_2, где P_n — базисный многочлен степени n, соответствующий конкретному модулю, например polynomial (работающему со «стандартным» базисом) или chebyshev. Для наилучшей производительности все операции с многочленами, включая вычисление значения при заданном аргументе, реализованы как операции с коэффициентами. Дополнительные сведения о конкретном модуле приведены в его строке документации.

Этот пакет предоставляет удобные классы для каждого из шести видов многочленов:

Эти вспомогательные классы предоставляют единообразный интерфейс для создания многочленов в разных базисах, работы с ними и аппроксимации данных. Они являются предпочтительным интерфейсом пакета polynomial и доступны в пространстве имён numpy.polynomial. Поэтому обращаться к соответствующим подмодулям не требуется: например, можно использовать np.polynomial.Polynomial и np.polynomial.Chebyshev вместо np.polynomial.polynomial.Polynomial и np.polynomial.chebyshev.Chebyshev соответственно. Интерфейс классов более согласован и краток, чем интерфейс функций для отдельных видов многочленов, определённых в подмодулях. Например, для аппроксимации многочленом Чебышёва степени 1 данных, заданных массивами xdata и ydata, используется метод класса fit:

>>> from numpy.polynomial import Chebyshev
>>> xdata = [1, 2, 3, 4]
>>> ydata = [1, 4, 9, 16]
>>> c = Chebyshev.fit(xdata, ydata, deg=1)

предпочтительнее функции chebyshev.chebfit из модуля np.polynomial.chebyshev:

>>> from numpy.polynomial.chebyshev import chebfit
>>> c = chebfit(xdata, ydata, deg=1)

Подробнее см. Использование классов удобного интерфейса.

Классы удобного интерфейса#

Ниже перечислены константы и методы, общие для всех классов различных видов многочленов. Обозначение Poly означает любой из классов удобного интерфейса (например, Polynomial, Chebyshev, Hermite и т. д.), а строчная буква p обозначает экземпляр класса многочленов.

Константы #

  • Poly.domain — область определения по умолчанию

  • Poly.window — окно по умолчанию

  • Poly.basis_name — строка, обозначающая базис

  • Poly.maxpower - максимальное значение n, такое, что p**n допускается

Создание #

Методы создания объектов многочленов.

  • Poly.basis(degree) – базовый полином данной степени

  • Poly.identity() – p, где p(x) = x для всех x

  • Poly.fit(x, y, deg) — полином p степени deg с коэффициентами, полученными аппроксимацией данных x, y методом наименьших квадратов

  • Poly.fromroots(roots) — p с заданными корнями

  • p.copy() – Создать копию p.

Преобразование#

Методы преобразования экземпляра многочлена одного вида в другой.

  • p.cast(Poly) — преобразует p в экземпляр типа Poly

  • p.convert(Poly) — преобразовать p в экземпляр класса Poly либо изменить отображение между domain и window

Математический анализ#

  • p.deriv() — Возьмите производную от p

  • p.integ() — интегрирование p

Проверка #

  • Poly.has_samecoef(p1, p2) - Проверьте, совпадают ли коэффициенты

  • Poly.has_samedomain(p1, p2) — проверяет совпадение областей определения

  • Poly.has_sametype(p1, p2) - Проверьте, совпадают ли типы

  • Poly.has_samewindow(p1, p2) — проверяет совпадение окон

Разное#

  • p.linspace() – Возвращает x, p(x) в равноотстоящих точках в domain.

  • p.mapparms() — возвращает параметры для линейного отображения между domain и window.

  • p.roots() – Возвращает корни p.

  • p.trim() — удаляет конечные коэффициенты.

  • p.cutdeg(degree) – усечение p до заданной степени

  • p.truncate(size) — обрезать p до заданного размера
