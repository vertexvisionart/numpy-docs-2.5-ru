Универсальные функции (ufunc) #

См. также

Основы универсальных функций (ufunc)

Универсальная функция, или сокращённо ufunc, поэлементно работает с ndarrays, поддерживая трансляцию массивов, приведение типов и ряд других стандартных возможностей. То есть ufunc — векторизованная обёртка для функции с фиксированным числом определённых входов и выходов. Подробнее см. Основы универсальных функций (ufunc).

Существуют также обобщённые универсальные функции, которые работают с векторами (или массивами), а не только с отдельными скалярами.

ufunc#

numpy.ufunc()

Функции, выполняющие поэлементные операции над целыми массивами.

Необязательные именованные аргументы#

Все ufunc принимают необязательные именованные аргументы. Большинство из них предназначено для расширенных сценариев и обычно не требуется.

out

Первый выходной аргумент можно передать позиционно или по имени. Именованный аргумент out несовместим с позиционными выходными аргументами.

Именованный аргумент ‘out’ должен быть кортежем с одним элементом на каждый выходной массив. Элемент может быть None, если массив должна выделить сама универсальная функция. Для функции с единственным выходом также можно передать один массив вместо кортежа из одного массива.

Если out равен None (по умолчанию), создаётся неинициализированный выходной массив, который заполняется универсальной функцией. В конце этот массив возвращается; если же он нульмерный, его предварительно преобразуют в скаляр. Чтобы избежать такого преобразования, передайте out=.... Можно также написать out=Ellipsis, если такая запись кажется понятнее.

Выходной массив заполняется только в тех позициях, где параметр where после трансляции массивов равен True. Если where — скаляр True (значение по умолчанию), заполняются все элементы выходного массива. В остальных случаях элементы, которые не были явно заполнены, сохраняют неинициализированные значения.

Операции ufunc, в которых входные и выходные операнды перекрываются в памяти, определены так, чтобы давать тот же результат, что и эквивалентные операции без перекрытия. При необходимости создаются временные копии, устраняющие зависимость между данными. Поскольку точное обнаружение таких случаев требует больших вычислительных затрат, используется эвристика, которая изредка может создавать лишние временные копии. Если зависимость достаточно проста и эвристика определяет, что копия не нужна, она не создаётся даже при перекрытии массивов. Например, np.add(a, b, out=a) выполняется без копирования.

где

Принимает логический массив, согласуемый с операндами по правилам трансляции массивов. Значение True означает вычисление универсальной функции в данной позиции, False — сохранение прежнего значения в выходном массиве. Аргумент не поддерживается обобщёнными универсальными функциями, поскольку их входы не скалярные.

Если создан неинициализированный выходной массив, позиции, соответствующие False, останутся неинициализированными.

axes

Список кортежей с индексами осей, по которым должна работать обобщённая универсальная функция. Например, для сигнатуры (i,j),(j,k)->(i,k), соответствующей умножению матриц, базовые элементы — двумерные матрицы, расположенные вдоль двух последних осей каждого аргумента. Соответствующее значение именованного аргумента axes: [(-2, -1), (-2, -1), (-2, -1)]. Для удобства у обобщённых универсальных функций, работающих с одномерными массивами (векторами), вместо кортежа из одного элемента допускается целое число. Если все результаты функции — скаляры, кортежи для выходов можно опустить.

axis

Одна ось, вдоль которой должна работать обобщённая универсальная функция. Это сокращение для функций, работающих с одним общим базовым измерением: оно эквивалентно передаче axes с элементом (axis,) для каждого аргумента с одним базовым измерением и () для остальных. Например, при сигнатуре (i),(i)->() это эквивалентно передаче axes=[(axis,), (axis,), ()].

keepdims

При True оси, по которым выполняется свёртка, сохраняются в результате с длиной 1, чтобы результат корректно согласовывался с входными массивами при трансляции. Параметр доступен только для обобщённых универсальных функций, у которых все входные массивы имеют одинаковое число основных измерений, а выходные массивы не имеют основных измерений, например при сигнатурах (i),(i)->() или (m,m)->(). Положение измерений результата можно задавать через axes и axis.

приведение типов

Допустимые значения: «no», «equiv», «safe», «same_kind» и «unsafe». Их описание см. в can_cast.

Задаёт допустимые виды приведения типов. Для совместимости с прежними версиями в NumPy < 1.7 по умолчанию используется «unsafe». В NumPy 1.7 начат переход к «same_kind»: универсальные функции выдают DeprecationWarning для вызовов, допускаемых правилами «unsafe», но запрещённых «same_kind». Начиная с NumPy 1.10, значение по умолчанию — «same_kind».

order

Задаёт порядок обхода при вычислении и размещение выходного массива в памяти. По умолчанию — ‘K’. При ‘C’ результат непрерывно расположен в памяти в порядке C; при ‘F’ — в порядке Fortran. При ‘A’ используется порядок Fortran, если все входные массивы непрерывно расположены в порядке Fortran, иначе — C. При ‘K’ порядок элементов по возможности соответствует входным массивам. Примечание переводчика: в оригинале условие для ‘A’ содержит противоречивое двойное отрицание относительно C-contiguous. Здесь приведено поведение реализации, проверенное в NumPy 2.5.4, включая входы, одновременно непрерывные в порядках C и Fortran.

dtype

Переопределяет DType выходных массивов так же, как signature, обеспечивая нужную точность вычисления. Конкретные вычислительные DType могут зависеть от ufunc; для вычисления входные данные могут приводиться к этому DType.

subok

По умолчанию — True. При значении False результат всегда будет массивом базового типа, а не его подкласса.

signature

DType, кортеж DType или специальная строка сигнатуры с типами входов и выходов универсальной функции.

Этот аргумент позволяет явно задать DType для вычисления. При необходимости выполняется приведение типов. Фактический DType входного массива учитывается только в том случае, если в signature для этого массива указано None.

Когда все DType заданы, выбирается конкретный цикл вычисления; если подходящего цикла нет, возникает ошибка. Если некоторые DType не заданы и имеют значение None, поведение может зависеть от универсальной функции. В настоящее время список доступных сигнатур предоставляется атрибутом types универсальной функции. (В этом списке могут отсутствовать DType, определённые за пределами NumPy.)

signature задаёт только класс или тип DType. Например, он может указать, что операция должна выполняться с datetime64 или float64. Он не задаёт единицу времени datetime64 или порядок байтов float64.

Для обратной совместимости этот аргумент можно передавать под именем sig, хотя полная форма предпочтительнее. Его не следует путать с сигнатурой обобщённой универсальной функции, хранящейся в атрибуте signature объекта функции.

Атрибуты#

У универсальных функций есть информационные атрибуты. Изменять их значения нельзя.

__doc__

Строка документации каждой универсальной функции. Первая часть динамически формируется из числа выходов, имени и числа входов. Вторая задаётся при создании и хранится вместе с функцией.

__name__

Название ufunc.

__signature__

Сигнатура вызова ufunc в виде объекта inspect.Signature.

ufunc.nin

Количество входов.

ufunc.nout

Количество выходов.

ufunc.nargs

Количество аргументов.

ufunc.ntypes

Количество типов.

ufunc.types

Возвращает список типов, сгруппированных в порядке входы → выходы.

ufunc.identity

Нейтральный элемент.

ufunc.signature

Определение основных элементов, над которыми работает обобщённая универсальная функция.

Методы #

ufunc.reduce(array[, axis, dtype, out, ...])

Уменьшает число измерений array на единицу, применяя универсальную функцию вдоль одной оси.

ufunc.accumulate(array[, axis, dtype, out])

Накапливает результаты последовательного применения оператора ко всем элементам.

ufunc.reduceat(array, indices[, axis, ...])

Выполняет локальную свёртку по заданным срезам вдоль одной оси.

ufunc.outer(A, B, /, **kwargs)

Применяет универсальную функцию op ко всем парам (a, b), где a — элемент A, а b — элемент B.

ufunc.at(a, indices[, b])

Выполняет операцию без буферизации с изменением операнда a на месте для элементов, заданных indices.

Предупреждение

Если при свёртке массива диапазон типа данных слишком мал для результата, переполнение произойдёт без предупреждения с циклическим переходом через границу диапазона. Используйте dtype, чтобы выполнять свёртку в типе большей разрядности.

Доступные универсальные функции#

В numpy определено более 60 универсальных функций для одного или нескольких типов данных, охватывающих широкий круг операций. Некоторые ufunc автоматически вызываются для массивов при использовании соответствующей инфиксной записи: например, add(a, b) вызывается внутри при записи a + b, если a или b является ndarray. Тем не менее ufunc можно вызывать и явно, чтобы через необязательные выходные аргументы поместить результат или результаты в выбранные вами объекты.

Напомним, что каждая универсальная функция работает поэлементно. Поэтому каждая скалярная ufunc описывается так, словно она принимает набор скалярных входов и возвращает набор скалярных выходов.

Примечание

ufunc по-прежнему возвращает свои выходные данные, даже если вы используете необязательные выходные аргументы.

Совет

Необязательные выходные аргументы помогают экономить память при больших вычислениях. Для больших массивов сложные выражения могут выполняться дольше необходимого из-за создания и последующего удаления временных областей памяти. Например, G = A * B + C эквивалентно T1 = A * B; G = T1 + C; del T1. Быстрее выполнить G = A * B; add(G, C, G), что равнозначно G = A * B; G += C.

Поэлементно вычисляет побитовое ИЛИ двух массивов.

bitwise_xor(x1, x2, /[, out, where, ...])

Вычисляет побитовое исключающее ИЛИ двух массивов поэлементно.

invert(x, /[, out, where, casting, order, ...])

Вычисляет поэлементную побитовую инверсию, то есть побитовое НЕ.

left_shift(x1, x2, /[, out, where, casting, ...])

Сдвигает биты целого числа влево.

right_shift(x1, x2, /[, out, where, ...])

Сдвигает биты целого числа вправо.

Функции сравнения #

greater(x1, x2, /[, out, where, casting, ...])

Возвращает результат сравнения (x1 > x2) поэлементно.

greater_equal(x1, x2, /[, out, where, ...])

Поэлементно возвращает истинностное значение (x1 >= x2).

less(x1, x2, /[, out, where, casting, ...])

Поэлементно возвращает логическое значение (x1 < x2).

less_equal(x1, x2, /[, out, where, casting, ...])

Поэлементно возвращает истинностное значение (x1 <= x2).

not_equal(x1, x2, /[, out, where, casting, ...])

Возвращает (x1 != x2) поэлементно.

equal(x1, x2, /[, out, where, casting, ...])

Возвращает (x1 == x2) поэлементно.

Предупреждение

Не используйте ключевые слова Python and и or для объединения логических выражений над массивами. Они проверяют истинность всего массива, а не отдельных элементов. Вместо них используйте побитовые операторы & и |.

logical_and(x1, x2, /[, out, where, ...])

Поэлементно вычисляет логическое И для x1 и x2.

logical_or(x1, x2, /[, out, where, casting, ...])

Поэлементно вычисляет логическое x1 OR x2.

logical_xor(x1, x2, /[, out, where, ...])

Поэлементно вычисляет логическое исключающее ИЛИ x1 XOR x2.

logical_not(x, /[, out, where, casting, ...])

Поэлементно вычисляет логическое НЕ для x.

Предупреждение

Побитовые операторы & и | являются правильным способом выполнения поэлементного сравнения массивов. Убедитесь, что вы понимаете приоритет операторов: (a > 2) & (a < 5) — правильный синтаксис, поскольку a > 2 & a < 5 приведет к ошибке из-за того, что 2 & a вычисляется первым.

maximum(x1, x2, /[, out, where, casting, ...])

Поэлементный максимум элементов массива.

Совет

Функция Python max() находит максимум одномерного массива, но использует более медленный интерфейс последовательностей. Метод reduce универсальной функции maximum гораздо быстрее. Кроме того, метод max() даёт неожиданные результаты для массивов с числом измерений больше одного. Метод reduce функции minimum также позволяет найти общий минимум массива.

minimum(x1, x2, /[, out, where, casting, ...])

Поэлементный минимум элементов массивов.

Предупреждение

поведение maximum(a, b) отличается от max(a, b). Будучи ufunc, maximum(a, b) поэлементно сравнивает a и b и выбирает для каждой позиции результата большее из соответствующих значений двух массивов. Напротив, max(a, b) рассматривает объекты a и b целиком, оценивает общее логическое значение a > b и в зависимости от него возвращает либо a, либо b целиком. Такое же различие есть между minimum(a, b) и min(a, b).

fmax(x1, x2, /[, out, where, casting, ...])

Поэлементный максимум элементов массива.

fmin(x1, x2, /[, out, where, casting, ...])

Поэлементный минимум элементов массивов.

Функции для чисел с плавающей запятой#

Все эти функции поэлементно обрабатывают массив и возвращают массив. В описании подробно рассматривается только одна операция.

isfinite(x, /[, out, where, casting, order, ...])

Поэлементно проверяет конечность значений: они не должны быть ни бесконечностью, ни NaN.

isinf(x, /[, out, where, casting, order, ...])

Поэлементно проверяет, равно ли значение положительной или отрицательной бесконечности.

isnan(x, /[, out, where, casting, order, ...])

Поэлементно проверяет наличие NaN и возвращает результат в виде булева массива.

isnat(x, /[, out, where, casting, order, ...])

Поэлементно проверяет наличие NaT (не является временем) и возвращает логический массив.

fabs(x, /[, out, where, casting, order, ...])

Вычисляет абсолютные значения поэлементно.

signbit(x, /[, out, where, casting, order, ...])

Поэлементно возвращает True там, где установлен знаковый бит. В оригинале это поясняется как «меньше нуля». Примечание переводчика: знаковый бит установлен и у -0.0, хотя -0.0 < 0 ложно; в NumPy 2.5.4 signbit(-0.0) возвращает True.

copysign(x1, x2, /[, out, where, casting, ...])

Поэлементно меняет знак x1 на знак x2.

nextafter(x1, x2, /[, out, where, casting, ...])

Поэлементно возвращает следующее представимое число с плавающей точкой после x1 в направлении x2.

spacing(x, /[, out, where, casting, order, ...])

Возвращает расстояние между x и ближайшим соседним числом.

modf(x[, out1, out2], / [[, out, where, ...])

Возвращает дробную и целую части массива поэлементно.

ldexp(x1, x2, /[, out, where, casting, ...])

Возвращает x1 * 2**x2 поэлементно.

frexp(x[, out1, out2], / [[, out, where, ...])

Разлагает элементы x на мантиссу и показатель степени двойки.

fmod(x1, x2, /[, out, where, casting, ...])

Возвращает поэлементный остаток деления.

floor(x, /[, out, where, casting, order, ...])

Поэлементно округляет входные значения вниз до целого.

ceil(x, /[, out, where, casting, order, ...])

Поэлементно округляет входные значения вверх до целого.

trunc(x, /[, out, where, casting, order, ...])

Поэлементно возвращает значения входных данных, усечённые до целой части.
