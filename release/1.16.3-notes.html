Историческая справка: страница описывает NumPy 1.16.3. Слова «сейчас», «раньше» и «будет» относятся ко времени этого выпуска; описанное поведение может отличаться от NumPy 2.5.

Примечания к выпуску NumPy 1.16.3#

NumPy 1.16.3 исправляет ошибки выпуска 1.16.2 и переносит из master несколько улучшений, уместных для последней серии с поддержкой Python 2.7. Пакеты wheel на PyPI связаны с OpenBLAS v0.3.4+, что должно устранить известные проблемы многопоточности предыдущих версий OpenBLAS.

Разработчики, создающие этот релиз, должны использовать Cython >= 0.29.2 и, при использовании OpenBLAS, OpenBLAS > v0.3.4.

Самое заметное изменение этого выпуска: десериализацию объектных массивов с помощью pickle при загрузке файлов *.npy и *.npz теперь нужно явно разрешать. Это нарушение обратной совместимости связано с уязвимостью CVE-2019-6446.

Примечания о совместимости#

Десериализацию pickle при загрузке нужно явно разрешать#

Функции np.load и np.lib.format.read_array принимают именованный аргумент allow_pickle, значение которого по умолчанию теперь равно False в связи с уязвимостью CVE-2019-6446.

Улучшения#

Ковариация в random.mvnormal приводится к double#

Это должно сделать допуск при проверке сингулярных значений ковариационной матрицы более обоснованным.

Изменения#

Смещение __array_interface__ теперь работает согласно документации#

Интерфейс может использовать значение offset, которое ранее было ошибочно проигнорировано.
