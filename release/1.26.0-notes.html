  • Примечания к выпуску NumPy 1.26.0

Историческая справка: страница описывает NumPy 1.26.0. Слова «сейчас», «раньше» и «будет» относятся ко времени этого выпуска; описанное поведение может отличаться от NumPy 2.5.

Примечания к выпуску NumPy 1.26.0#

Выпуск NumPy 1.26.0 продолжает цикл выпусков 1.25.x и добавляет поддержку Python 3.12.0. Из Python 3.12 удалён distutils, поэтому для поддержки этой версии пришлось заменить использовавшуюся в NumPy систему сборки на основе setup.py/distutils. Мы выбрали Meson, и это первый выпуск NumPy с его поддержкой. Также впервые добавлена поддержка Cython 3.0 при сохранении совместимости с 0.29.X. Поддержка этих двух обновлений потребовала большой работы: в этом выпуске изменено более 100 файлов. Журнал изменений не отражает всего объёма проделанного. Особая благодарность Ralf Gommers, Sayed Adel, Stéfan van der Walt и Matti Picus, выполнившим значительную часть работы в основной ветке разработки.

Основные изменения в этом выпуске:

  • Поддержка Python 3.12.0.

  • Совместимость с Cython 3.0.0

  • Использование системы сборки Meson

  • Обновленная поддержка SIMD

  • Исправления f2py, поддержка meson и bind(x)

  • Поддержка обновленной библиотеки Accelerate BLAS/LAPACK

В этом выпуске поддерживаются версии Python: 3.9–3.12.

Новые возможности #

Поддержка Array API v2022.12 в numpy.array_api #

  • numpy.array_api теперь полностью поддерживает версию v2022.12 стандарта Array API. Необязательное расширение fft пока не включено.

( gh-23789 )

Поддержка обновленной библиотеки Accelerate BLAS/LAPACK #

Добавлена поддержка обновленной библиотеки Accelerate BLAS/LAPACK, включая поддержку ILP64 (64-битное целое число) в macOS 13.3. Это обеспечивает поддержку arm64 и значительные улучшения производительности до 10x для обычно используемых операций линейной алгебры. Когда Accelerate выбирается во время сборки, версия 13.3+ будет автоматически использоваться, если она доступна.

(gh-24053)

Бэкенд meson для f2py#

f2py в режиме компиляции (то есть f2py -c) теперь принимает параметр --backend meson. Он используется по умолчанию начиная с Python 3.12. В более старых версиях по умолчанию по-прежнему используется --backend distutils.

Для поддержки практических сценариев в режиме компиляции f2py принимает флаг --dep один или несколько раз. Он соответствует вызовам dependency() в механизме сборки meson и ничего не делает в distutils.

Для использующих f2py только как генератор кода, то есть без -c, ничего не меняется.

(gh-24532)

Поддержка bind(c) в f2py#

Функции и подпрограммы можно снабжать аннотацией bind(c). f2py обеспечивает правильное сопоставление типов и сохраняет уникальное имя для других интерфейсов C.

Примечание: bind(c, name = 'routine_name_other_than_fortran_routine') намеренно не учитывается обёртками f2py: конструкция bind(c) с параметром name гарантирует совпадение имён только в C и Fortran, а не в Python и Fortran.

(gh-24555)

Улучшения#

Поддержка iso_c_binding в f2py#

Ранее пользователям приходилось создавать собственный файл f2cmap для использования сопоставлений типов, определённых встроенным модулем iso_c_binding стандарта Fortran 2003. Теперь эти сопоставления типов поддерживаются непосредственно в f2py.

(gh-24555)

Изменения в системе сборки#

В этом выпуске NumPy перешёл на систему сборки Meson и бэкенд meson-python. Установить NumPy или собрать пакет wheel можно стандартными средствами, например pip и pypa/build. Поддерживаются следующие возможности:

  • Обычная установка: pip install numpy либо, в клонированном репозитории, pip install .

  • Сборка wheel: python -m build (предпочтительно) или pip wheel .

  • Редактируемые установки: pip install -e . --no-build-isolation

  • Сборка при разработке выполняется через специальный интерфейс командной строки на основе spin: spin build.

Все обычные флаги pip и pypa/build, например --no-build-isolation, должны работать как ожидается.

Специальные настройки сборки NumPy#

Многие способы настройки сборки, специфичные для NumPy, изменились. Переменные окружения NPY_* для управления BLAS/LAPACK, SIMD, потоками и другими параметрами больше не поддерживаются, как и файл site.cfg для выбора BLAS и LAPACK. Вместо них предусмотрены флаги командной строки, передаваемые сборке через интерфейс config-settings в pip/build. Все флаги перечислены в файле meson_options.txt в корне репозитория. Подробная документация появится до окончательного выпуска 1.26.0; пока см. документацию SciPy по сборке из исходного кода, поскольку большинство настроек сборки в SciPy и NumPy работают почти одинаково.

Зависимости для сборки#

Зависимости NumPy во время выполнения не изменились, но зависимости сборки изменены. Поскольку мы временно включаем копии Meson и meson-python в исходники, появилось несколько новых зависимостей; подробнее см. раздел [build-system] в pyproject.toml.

Устранение неполадок#

Это крупное изменение системы сборки. При неожиданных проблемах в качестве временного обходного решения ещё можно использовать сборку на основе setup.py (для Python 3.9–3.11, но не 3.12), скопировав pyproject.toml.setuppy в pyproject.toml. При этом создайте issue с подробностями в трекере NumPy. Мы планируем как можно скорее отказаться от сборок setup.py, поэтому хотим выявить все препятствия в начале цикла выпуска 1.26.0.
