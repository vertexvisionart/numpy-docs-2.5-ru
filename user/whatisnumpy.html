Что такое NumPy?#

NumPy — основной пакет для научных вычислений на Python. Эта библиотека предоставляет объект многомерного массива, различные производные объекты, например маскированные массивы и матрицы, а также набор функций для быстрых операций над массивами. Среди них — математические и логические операции, изменение формы, сортировка, выборка элементов, ввод и вывод, дискретные преобразования Фурье, базовые операции линейной алгебры и статистики, случайное моделирование и многое другое.

В основе NumPy лежит объект ndarray. Он представляет n-мерный массив элементов одного типа. Для высокой производительности многие операции выполняются скомпилированным кодом. Массивы NumPy существенно отличаются от стандартных последовательностей Python:

  • Размер массива NumPy задаётся при создании, в отличие от списка Python, который может динамически расти. Примечание переводчика: далее оригинал утверждает, что изменение размера ndarray обязательно создаёт новый массив и удаляет старый. Это слишком общее утверждение: метод ndarray.resize при допустимых условиях меняет размер того же объекта, а np.resize возвращает другой массив. Эти операции нужно различать.

  • Все элементы массива NumPy должны иметь один тип данных и, следовательно, одинаковый размер в памяти. Исключение — массивы объектов Python, в том числе объектов NumPy: сами эти объекты могут иметь разные размеры.

  • Массивы NumPy облегчают сложные математические и другие типы операций на большом количестве данных.Как правило, такие операции выполняются более эффективно и с меньшим количеством кода, чем это возможно с использованием встроенных последовательностей Python.

  • Всё больше научных и математических пакетов Python используют массивы NumPy. Обычно они принимают и последовательности Python, но перед обработкой преобразуют их в массивы NumPy и часто возвращают такие же массивы. Поэтому для эффективной работы со значительной частью современного научного и математического ПО на Python, возможно даже с большинством пакетов, недостаточно знать встроенные последовательности Python: нужно уметь пользоваться массивами NumPy.

Размер последовательностей и скорость обработки особенно важны в научных вычислениях. Рассмотрим простой пример: умножение каждого элемента одномерной последовательности на соответствующий элемент другой последовательности той же длины. Если данные хранятся в двух списках Python, a и b, можно перебрать элементы в цикле:

c = []
for i in range(len(a)):
    c.append(a[i]*b[i])

Результат будет верным, но если a и b содержат миллионы чисел, мы столкнёмся с накладными расходами цикла Python. На C ту же задачу можно выполнить намного быстрее следующим образом; для наглядности опустим объявления и инициализацию переменных, выделение памяти и прочие детали:

for (i = 0; i < rows; i++) {
  c[i] = a[i]*b[i];
}

Это устраняет все накладные расходы на интерпретацию кода Python и обработку объектов Python, но лишает преимуществ программирования на Python. Кроме того, с ростом числа измерений данных увеличивается объём необходимого кода. Например, для двумерного массива код C, сокращённый как и прежде, принимает вид

for (i = 0; i < rows; i++) {
  for (j = 0; j < columns; j++) {
    c[i][j] = a[i][j]*b[i][j];
  }
}

NumPy сочетает преимущества обоих подходов: при участии ndarray операции по умолчанию выполняются поэлементно, а сами вычисления быстро выполняет заранее скомпилированный код C. В NumPy:

c = a * b

делает то же, что и предыдущие примеры, со скоростью, близкой к C, сохраняя простоту кода, ожидаемую от Python. Более того, запись на NumPy ещё проще! Этот пример показывает две возможности, лежащие в основе многих преимуществ NumPy: векторизацию и трансляцию массивов.

Почему NumPy работает быстро?#

Векторизация означает отсутствие явных циклов, индексации и подобных действий в коде. Конечно, эти действия выполняются, но внутри оптимизированного, заранее скомпилированного кода C. У векторизованного кода много преимуществ, в том числе:

  • векторизованный код более лаконичен и его легче читать

  • меньше строк кода обычно означает меньше ошибок

  • Код более похож на стандартную математическую нотацию (что облегчает, как правило, правильное кодирование математических конструкций).

  • Векторизация делает код более естественным для Python. Без неё код был бы заполнен медленными и трудночитаемыми циклами for.

Трансляция (broadcasting) — это неявное согласование форм при поэлементных операциях. Оно применяется не только к арифметическим, но и к логическим, побитовым и многим другим операциям NumPy. В приведённом выше примере a и b могут быть многомерными массивами одной формы, скаляром и массивом либо массивами разных, но совместимых форм. Их формы должны однозначно расширяться по правилам трансляции. Примечание переводчика: формулировка оригинала про расширение меньшего массива до формы большего охватывает не все случаи. Например, формы (2, 1) и (1, 3) обе расширяются до новой формы (2, 3). Подробные правила приведены в разделе Трансляция.

Кто еще использует NumPy ? #

NumPy полностью поддерживает объектно-ориентированный подход, снова начиная с ndarray. Например, ndarray — класс с многочисленными методами и атрибутами. Многим его методам соответствуют функции в основном пространстве имён NumPy, поэтому программист может выбирать удобную парадигму. Благодаря этой гибкости принятые в NumPy способы работы с массивами и класс ndarray стали де-факто языком обмена многомерными данными в Python.
